# Рабочие контексты Game и Plan

Один Git checkout, два frontend-проекта Codex. Общие пакеты и API остаются
доступны по относительным путям; это разделение контекста, не песочница доступа.

| Проект | Рабочий каталог относительно репозитория | Первый документ |
|---|---|---|
| ТВОЙ ХОД | `frontend-react/` | [Game](../game/README.md) |
| ТВОЙ ПЛАН | `apps/plan-web/` | [Plan](../plan/README.md) |

Локальные инструкции подхватываются по цепочке от корня к cwd согласно
[официальному описанию AGENTS.md](https://developers.openai.com/cookbook/examples/gpt-5/codex_prompting_guide#using-agentsmd).
В чатах из корня нужно явно читать AGENTS выбранного приложения. Смена каталога
через shell не очищает уже накопленный контекст чата.

Для новой работы используй отдельный чат нужного продукта. Общая библиотека,
CI или межпродуктовый контракт — отдельная задача из корня с явно указанными
потребителями. Существующие чаты и изменения не переносить автоматически.

Старт Game: «Рабочий каталог frontend-react. Прочитай AGENTS.md приложения и
docs/game/README.md; выполни задачу … в контексте ТВОЙ ХОД».
Старт Plan: «Рабочий каталог apps/plan-web. Прочитай AGENTS.md приложения и
docs/plan/README.md; выполни задачу … в контексте ТВОЙ ПЛАН».

На момент начала среза 08.11.2026 оба сохранённых проекта имели cwd корня.
Имена проектов сами по себе не задают изоляцию. Фактическое изменение cwd
проверяется через список проектов клиента, а не наличием этого документа.

Позже в том же срезе список проектов подтвердил основной путь Plan
`apps/plan-web/`; корень сохранён дополнительной исходной папкой для API,
пакетов и документации. Диалог доверия Plan не считается закрытым:
автоматическая проверка безопасности отклонила последующее действие у него.
Game пока сохраняет основной путь корня. Завершение настройки Game и
подтверждение доверия конкретным подпапкам ожидают разрешения владельца.
Стартовые чаты созданы до смены пути и сохраняют исходный cwd корня;
они явно используют frontend workdir и уже прочитали локальные инструкции.

Проверки: локальные unit/build в каждом приложении;
[общий UI-контракт](../../tests/shared-ui/README.md) отдельно.
