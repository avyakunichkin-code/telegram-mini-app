# Перенос атласа B2 / C1 · 2026-11-07

Основание: [утверждение владельца](../../../design-lab/plan-checkup/atlas-report-round/APPROVED.md) и последующее поручение «Отлично, переносим». Это перенос интерфейса отчёта в отдельный Plan, не деплой и не изменение финансовых правил.

## Состав

`apps/plan-web/src/screens/atlas/AtlasReport.jsx` — React-композиция отчёта; `atlas.css` и локальные Manrope — оформление. `Report.jsx` сохраняет прежний импорт как re-export. `ReportDetails.jsx` содержит адаптеры реальных метрик и три карточки стратегий. `App.jsx` передаёт существующие session/return/history callbacks. `StepActions.jsx` сохраняет серверное владение отметками и получает раскрытое представление для нового шага.

Канон Plan — собственный `screens/atlas`, не MQX игры. Ввод, авторизация, анкета, финансовые формулы и API не менялись. Существовавшие изменения в App, Report, StepActions и остальных файлах сохранены при переносе.

## Паритет и адаптация данных

- Компактный ответ на выбранный вопрос; боковой маршрут и нижняя мобильная панель; одна открытая область, keyboard Arrow/Home/End, touch ≥44 px.
- C1: тёмный вывод, две спокойные метрики, явный лаймовый триггер шага; остальные шаги и подробные метрики по раскрытию.
- Динамический отчёт: суммы, сценарии, пороги запаса, ставки, действия и сроки приходят из API. Демонстрационный fixture не входит в приложение.
- Для overview при положительном остатке и резерве ниже цели — короткий вывод о недостатке запаса; исходный текст API остаётся в подробностях. Остальные входные вопросы используют ответ API без переосмысления правил.
- Выполненный шаг отмечается по `status=done`, в том числе после ручного завершения; текст StepActions различает ручное завершение и все выполненные действия. Частичный счётчик виден. После серверного «Вернуть в работу» badge исчезает. Прямое снятие checkbox на done, допустимое в lab, заменено существующим серверным возвратом; API-контракт не менялся.
- Предыдущие шаги/цели сохранены. История использует существующий History и сохранённые версии; ошибки открытия старого отчёта видимы. Старый отчёт не перезаписывает текущий; есть возврат.
- Прогноз: реальные серии, различимые подписи/пунктир, таблица 12 месяцев; текущий график отдельно от альтернатив досрочного погашения. Стресс-тест показывает первый месяц дефицита и минимум, а не только конечный остаток.
- Офлайн: существующая защищённая копия последнего итогового отчёта, дата, запрет записи и истории. Черновые действия заблокированы до завершения чекапа.
