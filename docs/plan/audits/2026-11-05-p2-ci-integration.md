strict=false. Изменение подтверждено повторным GET GitHub API; rulesets ранее
не содержали дополнительных обязательных статусов. Секреты/credentials не читались.

Для CI подготовлена отдельная ветка от `ee1ba5f6` (main с уже влитым PR #23 P3).
Основное рабочее дерево с параллельными задачами не переносилось целиком и не
откатывалось. P2 patch применён трёхсторонним слиянием, новые файлы скопированы
только из явно выбранных исходников P2. SSH origin недоступен; сетевые Git-операции
используют HTTPS и существующий credential helper gh без изменения remote/config.

## Scope

- Общий ButtonBase, реальные адаптеры Game/Plan, native browser contract fixtures.
- Утверждённый отчёт M1/F2/A2/S1; сохранены R2/G2 и логика P3 из main.
- Регрессии дубликатов ID, финансовых связей семьи, просроченного долга,
  сохранения разделов и очистки истёкшей сессии.

  командой; это предотвращает конфликт параллельных SSR harness Vite.
- Plan lab self-contained; lab-base.css обновляется генератором. Игровые дизайн-
  изменения других задач не включены. Баланс и финансовые правила не менялись.
