# План P3 — «ТВОЙ ПЛАН» v1 продукт

Срезы этапа P3 из [`../ROADMAP.md`](../ROADMAP.md): шаги-сценарии, цели, рекомендации, аналитика по [`SPEC_plan-v1.md`](../specs/SPEC_plan-v1.md). **Код P3 — после закрытия P2** (SPL-402…405 и решения по SPL-403 ui-kit и SPL-404 lab). Реальные пользователи — только после юриста ([ADR-017](../../decisions/ADR-017-plan-p2-without-game-gate.md) п.2).
