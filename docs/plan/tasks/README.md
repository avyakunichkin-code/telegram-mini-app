# ТВОЙ ПЛАН · задачи владельца

Задачи также перенесены на [доску Trello «ТВОИ ЗАДАЧИ»](https://trello.com/b/2iitpNYi).
Карточки отмечены префиксом `[ТВОЙ ПЛАН]` и ID `PLAN-OWNER-*`.
Ссылки на все 15 карточек — в `trello-import.json`. Перенос выполнен 07.11.2026;
автоматической синхронизации статусов с этой локальной страницей нет.

В каждой создаваемой или обновляемой карточке обязателен готовый
**«Промпт для начала чата»** — для выполнения задачи или обсуждения её результата.
Состав и правила обновления: [формат карточек Trello](../../DOCUMENTATION_SYSTEM.md#карточки-задач-в-trello-готовый-промпт).

**[Открыть страницу задач](index.html)** — поиск, фильтры, сортировка и отметка
«В работе». Это отдельный раздел ПЛАНА, не Design Lab ТВОЙ ХОД.

Срез 07.11.2026. Здесь собраны решения, организация исследований и поручения,
которые нужны от владельца. Исходные spec/планы/отчёты сохранены на своих местах:
карточки ссылаются на них, а не создают копии канона. Страница — навигация и
личная очередь; изменение отметки не является approval, деплоем или закрытием gate.

В папке:

- `tasks.json` — единый редактируемый реестр задач владельца.
- `items/PLAN-OWNER-*.md` — отдельное описание каждой задачи со ссылками.
- `index.html` — автономная страница, открывается напрямую без сервера.
- `build.mjs` — генерация страницы и карточек из реестра: `node docs/plan/tasks/build.mjs`.

По умолчанию завершённые решения скрыты. Можно искать по тексту/ID, фильтровать
тип, статус и приоритет, сортировать. Личные отметки сохраняются только в этом
браузере при доступном localStorage; при отказе хранилища работает текущая вкладка.
Страница не читает токены Plan и не меняет приложение. JSON-экспорт сохраняет
вашу очередь, импорт восстанавливает только известные ID и разрешённые статусы.
Не записывайте здесь реальные анкеты или контакты участников.

В первую очередь: организовать сессии, подготовить пакет юристу, поручить сверку
состава первого релиза. Неназначенные сроки не выдуманы. «Можно начать» означает,
что можно готовить задачу, а не запускать реальные данные или публикацию.

Не включены как личные задачи: самостоятельное написание кода, миграции, benchmark,
написание тестов, нормализация JSON и перевод fincore на Decimal. Это инженерные
работы, которые уточняются в выбранных срезах, а не обязательные действия владельца.
