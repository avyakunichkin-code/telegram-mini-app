# Документация ТВОЙ ПЛАН

Эта ветка принадлежит Plan. Вход — [README](README.md), очередь —
[ROADMAP](ROADMAP.md), поведение — код/тесты → [spec](specs/SPEC_plan-v1.md)
→ утверждённая идея. Backlog и аудит не заменяют spec.
Документы Plan создавай здесь по слоям: `vision/`, `specs/`, `plans/`,
`research/`, `tasks/`; дизайн — [DESIGN](DESIGN.md).
Не помещай требования Plan в игровые foundation/specs/handbook.
Общие ADR и правила документации остаются в `docs/decisions/` и корне `docs/`.
Канон Game и игровые навыки не применять к Plan по умолчанию.
