# Brief: новые цепочки и замена family_money (2026-10-21)

Статус: **черновик для PO**, YAML не пишем до согласования. Основа — разбор цепочек mvp11 от 2026-10-21
и решения PO: 2 обычных события за период, продолжения цепочек — сверх лимита, цель цепочки — показать,
как прошлый выбор повлиял на итог; цена событий — доля зарплаты (`cash_pct_salary`); цена «времени» 0.5.

Общий каркас (как в `freelance_project`): старт в `period_choice`, продолжения в `chain_followup`
(в `CHAIN_FOLLOWUP_EXCLUDE_FROM_RANDOM_POOL`), ветки через `requires_chain_branch`, эпилог `informational`
с одинаковыми кнопками и «откатом» в `description` («N периодов назад вы … → …»).

## A. Перестройка активов (Профи / Руководитель / Предприниматель)

### A1. «Вторая машина — лишняя» (Руководитель, Предприниматель)

| | |
|---|---|
| Педагогика | Актив, который только ест деньги, — это скрытый долг. Продажа → гашение дорогого долга → свободный поток |
| Триггер | `active_asset_kinds_all: [car_personal]` + `min_active_liabilities: 1`; второй автомобиль в blueprint есть у обоих |
| Шаг 1 (N) | «Вторая машина простаивает»: продать сейчас (−10% к рынку, срочно) / выставить и ждать (рынок, через 2 пер.) / оставить |
| Шаг 2 (N+2, только «ждать») | Покупатель торгуется: уступить 5% / держать цену (риск: ещё 2 периода обслуживания) |
| Шаг 3 (сразу после продажи) | Куда деньги: досрочно в кредитную карту / ипотеку / в подушку |
| Эпилог (N+4…6) | «Пять периодов назад вы продали вторую машину и погасили карту → обслуживание −X ₽/пер., платёж по карте −Y ₽/пер. Поток +Z ₽» |
| Движок | Нужны эффекты: **продать актив по kind** (`asset_sale`) и **досрочно погасить долг** (`liability_prepay` по kind). Сейчас есть только `asset_from_template` — это работа в `chains.py`, по образцу `used_car_action` |
| Риск баланса | Высвобождение потока ≈ 12k обслуживания + платёж карты; проверить балансовым прогоном |

### A2. «Подушка окупилась» (все с машиной, акцент Профи)

| | |
|---|---|
| Педагогика | Подушка и страховка — не «мёртвые деньги»: в аварию они выигрывают у кредитки |
| Шаг 1 (N) | Агент: КАСКО за 3% зп/пер. / только ОСАГО / отказ. Параллельно подсказка пополнить подушку |
| Шаг 2 (N+3…5) | ДТП (как `mq11_car_accident`): ветка по наличию полиса и размеру подушки — по полису / из подушки / в кредитку под 22% |
| Эпилог | «Три периода назад вы купили КАСКО → выплата 120 000, вы заплатили 9 000 премий» или «…отказались → ремонт в кредитку, переплата ~X ₽ за год» |
| Движок | Выбор ветки по состоянию (`safety_fund_balance ≥ X`, наличие полиса) — нужен `requires_state` или ветка из контекста шага 1 + `insurance_claim` (есть) |
| Отличие от текущего ДТП | Причинность: ДТП приходит как следствие шага 1, а не случайно |

### A3. «Рефинансирование» (Профи — автокредит, Руководитель — ипотека, Предприниматель — карта)

| | |
|---|---|
| Педагогика | Ставка ниже ≠ дешевле: комиссия, срок, полная переплата. Выигрывает тот, кто считает |
| Шаг 1 (N) | Банк: снизить ставку на 3 п.п. с комиссией 2% долга / снизить платёж за счёт срока +24 пер. / отказ |
| Шаг 2 (N+2) | «Высвободилось X ₽/пер.»: досрочно в долг / в подушку / в жизнь (`expense_line`, растёт уровень жизни) |
| Эпилог (N+6) | «Шесть периодов назад вы удлинили срок → платёж −8 000, но переплата +210 000» vs «…снизили ставку и гасили досрочно → долг закроется на 14 пер. раньше» |
| Движок | Эффект **изменить ставку / срок обязательства** (`liability_refinance`) — новый; пересчёт `monthly_payment` через `annuity.monthly_payment` |
| Связь | Заменяет разовый `mq11_refinance_bank` для этих персон (тот без последствий) |

Рекомендация по порядку: **A3 → A1 → A2**. A3 даёт самый понятный урок и требует одного нового эффекта;
A1 переиспользует продажу из DL1 (`asset_sale.py`); A2 зависит от ветвления по состоянию.

## B. Замена family_money (PO: текущий сюжет не нравится)

Проблема текущей цепочки: деньги без цели, последствия только у отказа, выбор «помочь/не помочь» — моральный,
а не финансовый. Варианты ниже меняют вопрос на финансовый.

### B1. «Поручительство» (Профи+)

Брат берёт кредит на машину и просит стать поручителем. Ничего не платите сейчас.
Через 3 периода: брат пропустил платежи → банк требует с вас 2 платежа / брат справился и благодарит.
Исход детерминирован выбором: поручиться с договорённостью о подушке брата (он копит) → справился;
поручиться «на слово» → просрочка. **Урок:** поручительство — ваш долг, даже если деньги не ваши.

### B2. «В долг или в подарок» (все)

Подруга просит 20% зп на переезд. Дать в долг с распиской / подарить половину / отказать.
Через 2 периода (только «в долг»): вернула половину и просит отсрочку — напомнить (+остаток, social −) /
простить (social +). **Урок:** давай в долг только то, что готов подарить.

### B3. «Семейный бюджет на отпуск» (Руководитель, Предприниматель) — ✅ принято PO, в YAML

Семья хочет отпуск: в кредитку сейчас / копить 3 периода (откладывать долю зп) / отложить на год.
Через 3 периода: копили → отпуск без долга и скидка за раннее бронирование; кредитка → отпуск был,
но платёж по карте ещё 6 периодов. **Урок:** одно и то же удовольствие дешевле, если копить.

**Решение PO 2026-10-21: B3** → [`chains/family_vacation.yaml`](../../../../data/events/mvp11/chains/family_vacation.yaml): отпуск 60% зп; копить → 55%, кредитка → 75% разом или 40% + 45%. family_money — `is_active: 0`.

Было: рекомендация **B1** (новый урок, ложится на долги, не дублирует события «одолжить» в каталоге) или **B3**
(социальная ось через семью, сравнение «копить vs кредит»). B2 близок к текущему сюжету.
