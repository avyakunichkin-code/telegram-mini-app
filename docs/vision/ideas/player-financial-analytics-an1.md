# AN1: финансовая аналитика игрока (вкладка «Аналитика»)

One-pager эпика **AN1**: дашборд личной финансовой аналитики в game shell — для **Game** и **Plan** (`save_kind`), без отдельного экрана. «Дашборд реальных данных» в брифах Plan — **лексика**, не второй продукт.

**Spec:** [`SPEC_ANALYTICS.md`](../../specs/SPEC_ANALYTICS.md) · **Backlog:** [`PRODUCT_BACKLOG.md`](../../backlog/PRODUCT_BACKLOG.md) § AN1.

---

## Problem Statement

**Как дать игроку (и пользователю Plan) понятную картину финансового состояния, рисков и траектории — по стандартам личных и банковских финансов, а не по «игровой сложности» — чтобы вкладка «Аналитика» была полезна в симуляции и с реальными цифрами?**

Legacy [`AnalyticsPremium.jsx`](../../../frontend-react/src/components/AnalyticsPremium.jsx) не обновлялся с первого подхода: смешивает произвольные цели, игровой «индекс стресса» и победу; не показывает полное месячное давление (ADR-009).

---

## Зафиксированные решения (2026-06-21)

| # | Тема | Решение |
|---|------|---------|
| 1 | Личное vs семья | **Не различаем** в продукте. Пользователь сам вводит «свои» цифры (личные или домохозяйство) — без переключателя и без отдельных режимов. |
| 2 | Пороги и зоны | **Не зависят** от шаблона Game / сложности. Единые **стандарты** личных финансов + где уместно **банковские** ориентиры (ПДН, ликвидность, подушка в месяцах). |
| 3 | Прогноз | **Оставляем** горизонт до 12 мес., не как «игровую фантазию»: переключатель **3 / 6 / 12 мес.** — «куда приду при текущих показателях» (детерминированная экстраполяция + явные допущения). |
| 4 | Победа | **Не в фокусе** аналитики. Victory — максимум **вскользь внизу** экрана; ядро — финансовые KPI и прогнозы. |
| 5 | Рекомендации | **Закладываем сейчас:** целевое решение — **автоматические расчёты** (rule engine на бэкенде); точечный ручной контент допустим, но не целевая архитектура. |
| 6 | E1 | **AN1 не блокируется E1** — можно выпускать на текущем `overview` / burn / timeseries; E1 углубляет breakdown позже. |

## Recommended Direction

### Роль вкладки

| Экран | Вопрос |
|-------|--------|
| Главная | Что делать в этом месяце? |
| Капитал | Чем владею, что купить/закрыть? |
| **Аналитика** | **Насколько устойчиво? Куда уходит месяц? Куда ведёт траектория?** |

### Информационная архитектура (сверху вниз)

1. **Снимок** — ликвидность, зона устойчивости, остаток после полного outflow (ADR-009).
2. **Поток месяца** — водопад: доход → обязательства → жизнь → остаток (доли от дохода).
3. **Устойчивость** — подушка в месяцах давления, ПДН/нагрузка по долгам, runway, просрочка, streak (как дисциплина, не «здоровье cash»).
4. **Динамика** — sparklines + таблица последних закрытий.
5. **Прогноз** — горизонт **3 | 6 | 12** мес., одна модель, переключатель.
6. **Рекомендации** — 1–3 карточки от **движка правил** (приоритет по severity).
7. **Победа** *(опционально, низ экрана)* — одна строка / ссылка на главную, без дублирования `MqxGoalDash`.

### Стандарты (единые для Game и Plan)

Ориентиры для зон UI и rule engine — **не привязаны к шаблону**:

| Метрика | Ориентир | Источник практики |
|---------|----------|-------------------|
| Подушка | **≥ 3–6** мес. essential pressure | Личные финансы, ЦБ/банки (резерв) |
| Платежи по долгам / доход | **≤ 35–40%** комфорт; **> 50%** критично | ПДН (банковский контекст; в игре — `liabilities_to_income_ratio`) |
| Lifestyle burn / доход | **≤ 50%** — зона внимания (настраиваемый порог в config) | Бюджет 50/30/20 (адаптация) |
| Просрочка | **> 0** — немедленный красный флаг | Универсально |
| Structural net < 0 | Обязательства давят до жизни | Cashflow анализ |

Точные числа порогов — в **config** (`analytics_thresholds` JSON или env), не в шаблоне Game.

### Прогноз 3 / 6 / 12 мес.

- **База:** последний снимок ликвидности + средний **фактический** Δ ликвидности за N закрытий (fallback: structural net − burn).
- **Не включает:** случайные события, новые сделки — **явный disclaimer**.
- **UI:** segmented control `3 мес | 6 мес | 12 мес`; график/число «ожидаемая ликвидность».
- **Не** линейная «фантазия без подписи» — под каждым горизонтом кратко: «если месяцы похожи на текущую модель».

### Рекомендации (архитектура)

**Цель:** `POST` не нужен; **`GET /api/finance/analytics/insights`** (или поле в overview) — список `{ id, severity, title, body, metric_refs, dedupe_key }`.

| Слой | Содержание |
|------|------------|
| **BE** | `analytics_insights.py` — чистые функции: вход = overview + timeseries tail + thresholds; выход = ranked insights |
| **FE** | `MqxInsightCard` — 1 главная + до 2 вторичных; без CTA советника (Pre-Alpha) |
| **Контент** | Шаблоны RU в YAML/JSON; параметры из расчёта — **автоматически** |
| **Ручное** | Исключения / A-B копирайт — ops, не блокер v1 |

Правила v1 (примеры): просрочка; ПДН выше порога; подушка < 1 мес.; burn > 50% дохода; отрицательный остаток после full outflow; ухудшение `avg_net_cashflow_6p` 3 периода подряд.

### Game vs Plan

| | Game | Plan |
|---|------|------|
| Данные | Симуляция шаблона + события | Ввод пользователя (как захочет — личное или «общее») |
| Стандарты | **Те же** | **Те же** |
| Копирайт | «ход», «партия» допустимы | «месяц», «ваши цифры» |
| Победа | Строка внизу опционально | Нет victory — только финансовые цели Plan (позже) |

## Key Assumptions to Validate

- [ ] Игрок понимает разницу **structural net** и **остаток после жизни** после одного прохода онбординга / подсказки Монетки.
- [ ] Прогноз 3/6/12 воспринимается как **ориентир**, а не обещание (playtest).
- [ ] Автоматические рекомендации не ощущаются как морализаторство (тон + 1 главная карточка).
