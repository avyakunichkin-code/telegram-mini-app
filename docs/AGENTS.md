# Документация монорепозитория

Сначала выбери продукт: [Game](game/README.md) или [Plan](plan/README.md).
Не загружай оба контекста для обычной продуктовой задачи.
Game: `game/` со своими foundation, handbook, specs, ux, vision, plans/backlog.
Plan: `plan/` со своими spec, планами, исследованиями и задачами.
Общие: decisions, ai, templates, DOCUMENTATION_SYSTEM, PROJECT_STRUCTURE;
shared-kernel план — `plans/PLAN_game-plan-split.md`.
Смешанные индексы только маршрутизируют к владельцу документа.

Код + тесты → spec продукта → foundation/утверждённая идея; аудит — снимок,
backlog — приоритет. Не дублировать канон ради новой структуры каталогов.
При переносе проверять входящие ссылки и сохранять содержимое/изменения пользователя.
Архив и исторический Claude-контур не обходить для обычной задачи.
