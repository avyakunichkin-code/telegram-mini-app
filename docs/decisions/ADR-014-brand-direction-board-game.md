# ADR-014: Направление бренда — «настольная игра про деньги»

## Status

**Accepted** (2026-10-14). Основание — разбор фирменного стиля и UI ([рекомендации](../design/tvoy-hod-style-recommendations.html)). Дополняет брендбук v2.0 ([`BRANDBOOK.md`](../reference/brandbook/BRANDBOOK.md), [`BRANDBOOK_MQX.md`](../reference/brandbook/BRANDBOOK_MQX.md)); отдельные визуальные решения по-прежнему проходят ★ в design-lab.

## Context

Логотип G1/G2 — объёмные «игрушечные» буквы в золоте и фиолете: айдентика казуальной игры. Интерфейс MQX сложился как fintech-стекло с фиолетовыми градиентами, иллюстрации разошлись на три стиля (3D логотипа, 2D Монетки, 3D-персонажи), Coin Gold в UI не используется, а главное действие называлось двумя именами. Система токенов строилась от темы Telegram, хотя основной канал по [ADR-012](ADR-012-primary-channels-pwa-web-over-tma.md) — PWA/web.

## Decision

1. **Метафора бренда — настольная игра про деньги.** Месяц — клетка-ход на поле, деньги — монеты, цель — финиш. Цветовые роли: **фиолет** — ход и действие (CTA, текущий ход), **золото (Coin Gold)** — деньги и награды, **изумруд** — рост и плюс, **красный** — только риск (просрочка, поражение); обычный расход нейтрален.
2. **Отдельный шрифт в PWA/web разрешён.** Выразительный display-шрифт с кириллицей для заголовков и крупных сумм + текстовый шрифт; самохостинг с подмножеством. Конкретная пара выбирается раундом design-lab (★). Снимает запрет «не подключать webfont без продуктового решения» в `BRANDBOOK_MQX.md` §5.
3. **Стиль иллюстраций — 3D, как у логотипа.** Монетка и персонажи приводятся к объёмному «игрушечному» стилю с мягким светом; плоский 2D для маскота и персонажей больше не вводится.
4. **Главное действие называется «Завершить ход»** во всех текстах UI, подсказок и документации; «Закрыть месяц» не используется.

## Consequences

- Срочно (сделано 2026-10-14): единое «Завершить ход» в UI, nudge и handbook; остатки XP и обращения на «вы» убраны.
- Дальше по порядку: раунд design-lab «настольная игра» (поле, фишки, монеты, пара шрифтов) → ★ → токены v2 с семантическим слоем и обеими темами PWA → миграция CSS по экранам (начиная с дашборда) → перерисовка Монетки и персонажей в 3D → Design System как живая справка.
- Фиолетовый градиент hero и стекло перестают быть каноном после ★ нового раунда; до этого действует текущий MQX.
- Брендбук обновляется по мере ★: реестр утверждений, §5 типографика, §7 Монетка.

## Alternatives considered

- **«Тёплый наставник»** (спокойный редакционный стиль) — хуже продолжает игровой логотип.
- **Вычищенный текущий MQX** без смены метафоры — дешевле, но оставляет шаблонный fintech-облик и не задействует Coin Gold.
- **Иллюстрации в 2D Монетки** — проще производство, но расходится с 3D-логотипом, главным носителем бренда.
