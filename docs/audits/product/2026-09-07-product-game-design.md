## Сводка

- **Жанр и платформа:** пошаговый симулятор личного бюджета / serious midcore (не F2P-кликер); **PWA + web primary**, TMA secondary; ЦА **30+**, «умная игра».
- **Продуктовая зрелость: 5 / 10.** Ядро TB1, два кошелька, Victory chain, YAML-события, 4 шаблона — поздний прототип с зрелой документацией. Как корабельный продукт: нет когорт, mid-game не оплачен контентом, экономика наказывает «правильное» поведение, бизнес-модель не выбрана.
- **Находки:** 🔴 **6** · 🟡 **14** · 🟢 **8**
- **Главный продуктовый риск:** игра учит копить подушку, но burn списывается только с `cash` — игрок, который делает «как надо», проигрывает. Поверх этого кампания **40–60 периодов** при **2 карточках/месяц** и **нулевых D1/D7**.
- **Топ-3:**
  1. Снять ловушку подушки + показать burn **до** «Закрыть месяц».
  2. Первая победа за **12–18 периодов**, не 40–60.
  3. Включить когорты (PLT) и закрыть волну **10–20** людей.

### Что работает — не ломать

| Система | Почему якорь |
|---------|----------------|
| TB1 «Закрыть месяц» | Пауза 30+; нет energy; 1–3 мин/период у опытного |
| Два кошелька + сгорание зарплаты | Редкий teachable moment vs Fortune City / YNAB-геймификация |
| Victory chain + `mechanics_unlock` | Учебная лестница без character XP (верно для ЦА) |
| Честный trade-off в событиях | Нет бесплатного needs+; YAML масштабирует контент |
| 4 стартовых шаблона | Replay без фарма уровня |
| Этика монетизации | Нет pay-to-win и CTA советника в Pre-Alpha |

## 1. Core loop и фундаментальный геймплей

Цикл: открытый месяц → зарплата / 2 события / капитал / подушка → **«Закрыть месяц»** → `process_period_end` → новый период. TB1 совпадает с обещанием «уважать интеллект и паузу 30+». Якорь, не менять на energy.

**Горизонты:** короткий («не уйти в минус в этом месяце») есть. Средний размыт: цели 1–3 chain — клики туториала, не мастерство. Длинный — пассив ≥10k ₽/мес на Студенте ≈ **857k** тела при ~14% → десятки месяцев при surplus ~25k. Между P8 и P25 мало power moments.

**Skill expression** узкий: зарплата бинарна; события — главный выбор, но α-FB-04 «листание»; treat-self раз в **15** периодов (ADR-006); капитал за unlock. Ближе к guided checklist, чем к FM-ходу.

**Плотность:** канон 1–3 мин опытный, 5–10 новичок, плейтест 30–45 мин / ≥5 периодов — здравый. Replay шаблонами заложен, контент событий общий → вторая партия = те же сюжеты (α-FB-03).

### Находки

🔴 **C2. Кампания 40–60 периодов × 2 карточки.** ~60 `definition_key` (часть persona-only и узлы цепочек) на 80 показов за 40p. Повторы неизбежны. Оценка: −10–20 п.п. D7 vs короткий акт 12–18 ходов (аналоги narrative-mgmt). **Решение:** первая победа 12–18p; info-слот; 20–25 уникальных историй на tier. **Effort:** 3–4 нед. RICE ~280.

🟡 **M1. События как paging.** Один жёсткий trade-off на карточку; Q11 + `event_chosen`. **Effort:** 2 нед. RICE ~150.

🟡 **M12. Нет informational/macro.** EVT1 P0, 1 info-слот, не вытесняет 2 choice. **Effort:** 2 нед. RICE ~145.

## 2. Meta-loop и прогрессия

Прогрессия **линейная chain** на Game-шаблонах. Parallel — legacy. `mechanics_unlock` — сильный tutorial-gate. После «открылись инвестиции» — плато.

Студент: 62.5k зарплата, 37.5k burn, 15k cash. Цепочка: salary → cushion → invest → подушка 2× → пассив ≥10k. Harder: 80k пассива, 10 млн cash / арендная квартира — другая игра в том же UI.

XP снят (ADR-003) — верно. M12 UI на паузе. Остались период, `clean_period_streak`, 4 шаблона, GE1. Мало для возврата через неделю.

**Hard gates:** 3× neg cash; needs=0 три периода. Treat-self CD 15 при decay ~14p до нуля → второй fail, на который почти нельзя ответить.

🟡 **M3. Победа не сходится с экономикой (V2-BAL).** Tutorial-бот: 16 close, 0 целей, defeat. **Решение:** акт 1 = safety 2× + депозит; 10k пассива — акт 2. **Effort:** 3–5 дней + `/balance-playtest`. RICE ~210.

🟡 **M5. Мета после XP.** Тосты unlock + бейджи в finale — P1. Экран M12 — P3.

🟡 **M8. Needs-GO vs treat-self 15.** Rescue при шкале <30; CD 8–10 на Студенте; «осталось N мес.». **Effort:** 1 нед. RICE ~140.

🟡 **M14. Шаблоны слабо различны для explorer.** Parallel на 2 шаблонах + 8–10 уникальных profile-событий. RICE ~95.

**Flow:** P1–P3 confusion; P8–P25 boredom; frustration — скрытый burn и подушка.

## 3. Экономика и баланс

**Faucets:** зарплата (claim), активы, купоны, редкий плюс событий.  
**Sinks:** скрытый lifestyle burn, обслуживание, долги, страховки, события, treat-self ~8% зарплаты / 15p.

Подушка **не** платит burn. `safety_first` в baseline умирает на **3-м** периоде — anti-strategy совпадает с учебным сообщением.

`net_monthly_cashflow` **без** lifestyle burn (ADR-009). Для аналитика ок, для игрока 30+ на дашборде — ложь (α-FB-15).

Просрочка без эскалации → ignore after tutorial. Страховка слабо связана с событиями.

🔴 **C1. Подушка убивает cash.** Превью close «на счёте останется X после burn Y»; chip «~1 месяц расходов на счёте»; не автотратить подушку молча. Опция: подтверждение «покрыть из подушки». **Effort:** 1–1.5 нед. RICE ~360. Цель: GO ≤P5 → ≤25%.

🔴 **C4. Скрытый burn.** GD-01 + GD-02 (подушка в месяцах burn) **без** полного E1. **Effort:** 1.5–2 нед. RICE ~320.

🟡 **M6. Страховка как комиссия.** 2–3 claim-события + строка «полис покроет». **Effort:** 1.5 нед.

🟡 **M7. Просрочка без давления.** Рост ставки / блок нового кредита после N. Не отдельный GO (ADR-009). **Effort:** 1 нед.

🟢 **m4.** Float/копейки — после видимого burn.  
🟢 **m7.** Отчёт периода: 3 строки в ritual, не ждать E1-115.

**Grind-to-reward:** surplus 25k к цели 857k = «ещё 40 месяцев close». Не fair grind — неверный win condition акта 1.

## 4. Монетизация

В prod нет IAP / ads / battle pass / energy. Для Pre-Alpha правильно. **Не** чинить F2P-хищничеством: ЦА 30+, столп «умная игра», запрет «платить за спасение от GO».

Гипотеза: игра бесплатна → лид → советник **45–75k ₽**. High-ticket B2B2C, не ARPDAU. Без CustDev и без доказанного «удара цифрами» — Excel.

🔴 **C6. Три продукта (Game / Plan / советник) до одного loop.** Freeze до D7 ≥8% на n≥50: только Game. **Effort:** 0 кода. RICE ~400.

🟡 **M9. Plan «Скоро».** Скрыть или «не в этой версии». **Effort:** 0.5 дня.

🟡 **M10. Советник без CustDev.** 8–12 интервью после стабильного цикла. CTA в приложении — не раньше Closed Alpha (уже канон). **Не ставить ARPDAU.**

🟢 **m5.** B2C позже: косметика персон / packs / B2B. Не подписка на «не проиграть».

## 5. Onboarding и FTUE

O2 strip в prod (2026-06-01), autostart Студент. Wave-0: цикл неясен. INT-2: онбординг прыгал — O1 снят, O2 ждёт людей. O3 spec не доказан на когорте. Вау-момент не поставлен; риск негативного вау: «перевёл в подушку и проиграл».

🟡 **M11.** Empty states Капитала. **Effort:** 3–4 дня.  
🟡 **M13.** Always-on хостинг. **Effort:** 2–5 дней ops.

🟢 **m1–m3.** Монетка, z-index модалки, RU `kind`.

## 6. Удержание и engagement

Handbook: Closed Alpha D7 **≥8%** среди закрывших ≥1 период — пол для друзей. Нишевый serious / PWA 2025–26: D1 **~25–32%**, D7 **~12–15%**, D30 **~5%**. F2P midcore (D1 35–45%) — нерелевантен.

Сессия **кампанийная** (1.2–1.8 **в неделю**), не 3/день. Нет daily/streak; TG player ⬜. Для 30+ честно; цена — удержание только на цели, которой доверяешь (сейчас цель далеко и экономика врёт).

🟡 **M4.** GE1 mid-toasts + 5 TG-шаблонов **без** FOMO-таймера. Не Duolingo-streak.

🟢 **m6.** Соц. фичи не expectation. Чат сообщества (PLT-4) важнее лидерборда.
