# UX/UI-аудит: ТВОЙ ХОД

**Kind:** `ux` · **Дата снимка:** 2026-09-07 · **Verdict:** DRAFT.

Канон адреса: [`../README.md`](../README.md). Kind: [`README.md`](README.md).

Смежные снимки: продукт [`../product/2026-09-07-product-game-design.md`](../product/2026-09-07-product-game-design.md), QA [`../qa/2026-09-07-mechanics.md`](../qa/2026-09-07-mechanics.md). Живой чеклист MQX: [`../../specs/UI_CONSISTENCY_AUDIT.md`](../../specs/UI_CONSISTENCY_AUDIT.md).

ЦА **30+**, каналы **PWA/web primary** (ADR-012), touch-first. Любая смена layout — **design-lab**, не hotfix в `*Premium.jsx`.

**Не выдумывать:** D1/D7, волна 10–20, скрин α-FB-19 от автора, live CLS онбординга.

---

## Сводка

- **UX-зрелость: 6 / 10.** MQX-язык, juice зарплаты, warn «зарплата сгорит», O3-strip без scrim — якоря. Главная **читает цикл задом наперёд**: самое опасное действие сверху, самое нужное — под скроллом.
- **Находки:** 🔴 **2** · 🟡 **12** · 🟢 **8**
- **Главный UX-риск:** новичок за 1–3 минуты жмёт «Завершить ход» в шапке, не видя «Зарплату» и не понимая, что расходы спишутся со **счёта**, а не с подушки.

### Топ-3 точки фрустрации игрока

1. **Главная: «что нажать?»** Hero отдаёт primary CTA закрытию хода; зарплата / подушка — четвёртый блок после потребностей, чипов и цели. Совпадает с α-FB-01. *Уход на 3-й минуте: «я ничего не сделал, а уже конец».*
2. **Закрытие хода без картины списания.** Chip «Расходы» выглядит как факт, не как отложенный удар; подушка с % не говорит «не платит жизнь». Продуктовая ловушка C1 как **дыра обратной связи**. *Уход после первого GO: «я копил правильно».*
3. **Стек оверлеев.** События `z-index: 520`, guidance до `560`, nav `100`, без scrim на strip. α-FB-17/19. *Тап мимо карточки, «ломается интерфейс».*

### Топ-3 быстрых улучшений (макс. эффект / мин. lab)

1. **Порядок на главной (lab 1 раунд):** сразу под hero — «Действия хода»; needs свернуть до одной строки риска; цель — compact chip. Не трогать экономику.
2. **Превью на кнопке закрытия:** подпись или chip «к списанию ~N ₽ со счёта» из уже существующего `estimate_period_close_preview`; при cash после close < 0 — danger-состояние кнопки.
3. **Один словарь:** везде «ход» как в `turnCopy.js` **или** везде «месяц» как в лексиконе продукта. Сейчас смесь ломает O3 («игра идёт ходами») vs toast «Не удалось закрыть месяц» vs аналитика «Поток месяца».

## Проблемы по экранам/состояниям

### Главная (Dashboard)

#### 🔴 U1 — Инверсия иерархии: close сверху, loop снизу

| | |
|--|--|
| Экран | `MqxDashboardHero` + стек `Needs → Finance chips → Goal → PeriodActions` |
| Retention / FTUE | Новичок 30+ сканирует сверху вниз: видит «Завершить ход» раньше зарплаты. α-FB-01. Риск ухода **до первого осмысленного хода**. |
| Клики | Зарплата: скролл + 1 тап (герой **не** sticky). Close: 1 тап с верха, 2 если уже проскроллили к действиям (назад вверх). |

**Факт:** UX-spec `dashboard.md` всё ещё пишет кнопку «Закрыть месяц» первым пунктом purpose; prod-кнопка — «Завершить ход»; действия loop — внизу.

**Решение (1–2):**

1. Lab-раунд dashboard: **Действия хода сразу под hero** (или salary-chip в hero рядом с close, visually secondary).
2. Пока salary не взята — close **outline/secondary**, не `hero-filled`; filled только когда loop шага выполнен или игрок явно skip через warn.

---

#### 🔴 U2 — Нет читаемого превью списания на close

| | |
|--|--|
| Экран | Hero CTA + chip расходов + chip подушки |
| Retention | Первый GO после «правильной» подушки (product C1). UI не показывает причинно-следственную связь **до** тапа. α-FB-15 ждут PA-T2. |

**Факт:** O3 beat `p1_close` учит текстом; после curriculum подсказки нет. `%` подушки = доля от нормы ×3 расходов, не «хватит ли на этот close».

**Решение:**

1. На кнопке / под ней: «Со счёта уйдёт ~N ₽» (preview API уже есть).
2. Chip подушки: вторая строка «не списывает жизнь» **или** danger, если cash < burn при полной подушке.

---

#### 🟡 U3 — Смесь «ход / месяц / период»

| | |
|--|--|
| Где | `turnCopy.js` = ход; `GameScreen` toast = «закрыть месяц»; `AnalyticsPremium` = «Поток месяца»; `AnalyticsCharts` = «Закрыть месяц»; `MqxGameOverModal` / needs streak = «месяцы»; curriculum = ходы |
| FTUE | Игрок не знает, одно ли это. O3 объясняет «ход», аналитика — «месяц». |

**Решение:** выбрать канон UI (рекомендация: **ход** = уже в кнопке и O3) и пройти grep по видимым строкам; «месяц» оставить только в художественном тексте карточек событий.

---

#### 🟡 U4 — Потребности занимают first screen раньше денег

| | |
|--|--|
| Экран | `MqxNeedsDash` первым в `mqx-dash-stack` |
| FTUE | α-FB-13: шкалы непонятны. Spec Z-NEEDS: скрыть до `brief_done` — в prod стек всегда показывает 4 шкалы. |

**Решение:** до конца P1-curriculum — compact (портрет + мин. ось) или скрыть; полный блок после beat `p3_needs`. Help уже есть — не дублировать простынёй.

---

#### 🟡 U5 — Цель сценария не отвечает «что сделать в этом ходу»

| | |
|--|--|
| Экран | `MqxGoalDash` между финансами и действиями |
| Retention | α-FB-07. Hint в `goalGuidanceCopy` есть, но конкурирует с 4 шкалами. Длинная chain 40–60p (продукт) выглядит как тупик. |

**Решение:** в свёрнутом виде одна строка «Сейчас: забери зарплату»; раскрытие — цепочка. Не тащить mid-game победу в UX-hotfix.

---

#### 🟢 U6 — Juice зарплаты есть, close/подушка беднее

Зарплата празднует; перевод в подушку — toast. Асимметрия: игрок не чувствует «ход прожит» до ритуала close.

**Решение:** короткий haptic/toast на contribute; не копировать burst зарплаты на close (ритуал уже есть).

### События (оверлей)

#### 🟡 U7 — Стек z-index: карточки vs guidance vs nav (α-FB-19)

| | |
|--|--|
| Где | `.events-overlay-root` **520**; `.mqx-guidance-strip` **508–510**, часть guidance **540–560**; `.bottom-nav` **100** |
| FTUE | Strip может лежать **поверх** карточки; nav может выглядывать из-за padding overlay. INT-2 без скрина — гипотеза по CSS, не live. |

**Решение:**

1. Один слой «модалка игры»: events **выше** strip, **ниже** только системных alert; при `open` — `pointer-events: none` на nav + strip hide или dock.
2. Lab: карточка на `100dvh` без дыр над tab bar.

---

#### 🟡 U8 — События как листание, не выбор (α-FB-04)

Карусель + свайп. Два слота ощущаются как «ещё одна карточка». Help-sheet есть.

**Решение:** на витрине «1 из 2» + зачем оба (slot). Не убирать свайп; добавить «осталось решить: 2».

---

#### 🟡 U9 — Pill «События» пропадает на ходах 1–2 без замены

`onOpenEvents` undefined, пока `areGameEventsUnlocked` (с хода 3). Пустое место в hero.

**Решение:** disabled pill «С хода №3» или строка в status-hint. Иначе игрок думает, что фича сломана.

---

#### 🟢 U10 — Тап «События» при `n === 0` ничего не делает

`EventCarouselOverlay`: `if (!open \|\| n === 0) return null`. `eventsOpen` остаётся true, UI пустой.

**Решение:** toast «Пока нет карточек» + `setEventsOpen(false)`; не глушить тап.

---

#### 🟢 U11 — Монетка на каждой карточке (α-FB-05)

Шум до волны Q5. Не трогать до плейтеста; если подтвердится — маскот только в help, не в chrome карточки.

### Онбординг (O3)

#### 🟡 U12 — Strip без якоря + lock tabs (α-FB-17)

Нет scrim/spotlight: «нажми Зарплату внизу», а зарплата за скроллом. Стрелка «вперёд» disabled (`nextDisabled` до beat) — ощущение залипания. `lockTabs` — серые Капитал/Аналитика без подписи «откроется позже».

**Решение:**

1. На `action_salary` — `scrollIntoView` якоря `data-onboarding-anchor="salary"`.
2. На disabled tab — title «Сначала закончим знакомство».
3. PA-T2: замерить CLS; не возвращать O1 spotlight без lab.

---

### Капитал

#### 🟡 U13 — IA «что делать дальше» (α-FB-06)

Потоки → Детали|Действия → сетка. С главной «Вложить» = смена таба без highlight. `MqxCapitalEmpty`: текст **visually-hidden**, видна только CTA — пустой блок выглядит сломанным.

**Решение:**

1. Показать `message` визуально (не только SR).
2. Deep-link «Вложить» открывает **Actions** + подсветка депозита. Lab, не prod-hotfix сетки.

---

#### 🟢 U14 — Гибрид форм инвестиций

`InvestProductForm` вне `mqx/` (`UI_CONSISTENCY_AUDIT`). Другой ритм полей vs sheets.

**Решение:** в спринт капитала, не отдельный P0.

### Итог хода / поражение

#### 🟡 U15 — Ритуал close бедный (α-FB-18)

`MqxPeriodCloseRitual` + highlights есть; полный breakdown по категориям — backlog E1-115. Игрок не сверяет «расходы chip» vs факт.

**Решение:** 3 строки обязательно: жизнь, обязательства, страховки; «счёт до/после». Tail оставить.

#### 🟢 U16 — Copy GO «три месяца» при UI «ход»

### Аналитика / Меню / Shell

#### 🟡 U17 — Аналитика на другом языке цикла

«Поток месяца», график просит «Закрыть месяц», пока нет ходов. Потерянный экран: новичок заходит до первого close, видит пустоту.

**Решение:** empty: «Закрой первый ход на главной — здесь появится график» + CTA на dashboard. Выровнять термины.

---

#### 🟢 U18 — План «Скоро» без одной фразы (α-FB-14)

By design. Одна строка: «Режим планирования бюджета — в следующей версии, сейчас играем сценарий».

---

#### 🟡 U19 — Ошибки: toast + смесь EN/RU

`choice_id is required`, «Не удалось закрыть месяц» при кнопке «Завершить ход». Нет `aria-live` как must (a11y Basic рекомендует).

**Решение:** FE `formatApiErrorDetail` + канон глагола кнопки; `aria-live="polite"` на тостах денег/ошибок.

---

### Доступность и ввод

#### 🟡 U20 — Документ a11y = TMA Basic, канал primary = PWA/web

`accessibility-requirements.md`: не в scope клавиатура. ADR-012: web primary. На десктопе Tab не ведёт цикл. Focus-visible на nav есть точечно.

**Решение:** P0 не SR; **P1 web:** Tab-порядок hero → actions → close; Enter на close. Lab не обязателен для focus-order hotfix, если layout не меняется.

---

#### 🟢 U21 — Нет haptic / reduced-motion политики в prod

Backlog D1/D2. ЦА 30+: крупные анимации juice без `prefers-reduced-motion`.

**Решение:** media-query на flyout; haptic только в TMA, опционально.

---

#### 🟢 U22 — Stale UX-spec vs prod

`docs/ux/screens/dashboard.md` (май): «Закрыть месяц», O1 coach. Prod: ход, O3 strip. Агенты читают spec → путают кнопку.

**Решение:** sync spec после утверждения иерархии (U1), не до lab.

## Рекомендации

### Быстрые победы (1–5 дней, часть — copy/CSS)

1. Унифицировать видимые строки **ход vs месяц** (`turnCopy` + grep).
2. Toast/empty на событиях `n === 0`.
3. Disabled «События» на ходах 1–2 с подписью.
4. Видимый текст empty капитала.
5. Подпись disabled-табов в онбординге.
6. `scrollIntoView` на якорь зарплаты в beat `p1_salary`.
7. Toast close: тот же глагол, что на кнопке.
8. Empty аналитики → CTA на главную.

Превью списания на кнопке close — **самый сильный** из быстрых, нужен аккуратный layout (лучше короткий lab или вписать в существующий hero без новой сетки).

### Дизайн-спринт (lab, 1–2 недели)

| Тема | Зачем |
|------|--------|
| Dashboard hierarchy (U1, U4, U5) | Loop читается сверху вниз |
| Close preview + cushion honesty (U2) | Снять ложную модель «подушка = жизнь» |
| Event overlay stack (U7) | Снять BLOCKER-класс overlap |
| Capital next-action (U13) | α-FB-06 |
| Period close ritual denser (U15) | Доверие к цифрам |

Не смешивать спринт с правкой burn-правил (это product/economy).

### Чек-лист для новых экранов

Перед lab→prod и перед билдом:

1. **Первый взгляд (5 с, 390×844):** видно ли **одно** следующее действие без скролла?
2. **Словарь:** только канон «ход» или только «месяц»; кнопка = toast = guidance.
3. **Обратная связь:** тап → 200 мс визуал (disabled/busy/juice); ошибка текстом на русском, не ключом API.
4. **Стек:** один modal layer; nav не кликается сквозь; guidance не перекрывает CTA карточки.
5. **Пустые состояния:** видимый текст + куда идти, не `return null`.
6. **Онбординг:** якорь скроллится; skip/Понятно есть; lock tabs объяснён.
7. **A11y Basic:** hit ≥44px; не только цвет; `aria-modal` на диалогах; web: Tab доходит до primary CTA.
8. **Контракт:** не обещать, что подушка оплатит close, пока правило такое в движке.
9. **Canon sync:** `APPROVED.md` + parity, если менялся layout.
10. **Не ломать якоря:** juice зарплаты, salary-warn, 4 таба.
