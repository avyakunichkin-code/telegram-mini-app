# Live Ops & Community-аудит: ТВОЙ ХОД

**Kind:** `liveops` · **Дата снимка:** 2026-09-07 · **Verdict:** DRAFT.

Канон: [`../README.md`](../README.md). Kind: [`README.md`](README.md).

Смежные снимки: продукт [`../product/2026-09-07-product-game-design.md`](../product/2026-09-07-product-game-design.md) (ловушка подушки, 40–60 периодов), UX [`../ux/2026-09-07-player-surface.md`](../ux/2026-09-07-player-surface.md). Платформа TG: [`PLAN_PLT.md`](../../plans/PLAN_PLT.md), [`TELEGRAM_BACKLOG.md`](../../backlog/TELEGRAM_BACKLOG.md).

Это **не** Genshin/Clash. Solo midcore 30+, TB1 без таймера, PWA/web primary. Daily streak / battle pass / energy в Pre-Alpha **запрещены** продуктовым аудитом — Live Ops не должен их протаскивать «для D7».

**Не выдумывать:** live D1/D7/D30, NPS, WAVE1 факты, статус публикации TG-канала, фактический `@TvoyHodBot` в prod.

---

## Сводка

- **Готовность к запуску событий Live Ops: 2 / 10.** Каталог YAML и 2 карточки/период — это **контент партии**, не сезонный календарь. Нет LTM, нет сезона, нет публичного патчноута, player-бот не включён в ops (PLT-201 ⬜), волна 10–20 не закрыта, Amplitude/D7 ⬜.
- **Готовность к Closed Alpha community-ops: 4 / 10.** Есть протокол плейтеста, ops-TG в коде, Watchtower funnel, 5 шаблонов игрока **спроектированы**, skill постов, invite-черновик. Не хватает заполненных URL чата/опроса и ритуала ответа.
- **Главный риск удержания:** игрок **правильно** копит подушку → GO (product C1) **и** за 40–60 ходов видит повторы карточек (α-FB-03) **без** причины вернуться через неделю. Live Ops нечем закрыть дыру: нет честного mid-act, нет мягкого return, daily-nudge в плане TG **ломает** TB1.
- **Топ-3 для «первого сезона» (Season 0 = Closed Alpha, не battle pass):**
  1. **Волна 10–20 + ритуал фидбека** (чат, опрос, патч «что починили по вашим словам») — репутация и NPS-прокси.
  2. **Player TG: победа / поражение / D+7 + `/quiet`.** Без шаблона «сегодня не закрыл период».
  3. **Контентный акт, не LTM-FOMO:** короткая цель 12–18 ходов *или* тематический пак YAML (8–10 ключей, «учёба/аренда») с датой в канале — после честного close-preview.

## По направлениям

### Events (карточки YAML vs Live Ops)

В коде «событие» = 2 `EventInstance` на период из `data/events/mvp11/` (~60 `definition_key`). Live-ops календаря **нет**.

#### 🔴 L1 — Нет сезонной обёртки, кампания = бесконечный пул

| | |
|--|--|
| Механика | 2 карточки/период × 40–60 периодов ≈ 80 показов при ~60 ключах (часть persona-only) |
| Retention / репутация | α-FB-03 «одни и те же интернет/жильё». D30 в нише ~5% и так низкий; без новизны mid-game D7/D30 не из чего расти. Репутация «контента на 3 вечера». |
| Решение | Не запускать «Сезон 1 с наградами». **Акт 1:** победа/финал 12–18p (product) + **дроп пака** раз в 2–4 недели (новые YAML, не множитель наград). |
| Эффект (гипотеза) | D7: +2–4 п.п. за счёт «есть куда вернуться к акту», не за FOMO. NPS: меньше «я это уже видел». Нет данных — мерить после CA n≥50. |

#### 🟡 L2 — Награды карточек ≠ Live Ops rewards

Trade-off в YAML (нет бесплатного plus). Достижения: сиды + тосты, **страницы «Все достижения» нет**. Нет сезонной валюты — и **не надо** в α.

**Решение:** видимость unlock в TG-шаблоне 3 + экран достижений (уже в spec). Не вешать XP/pass на карточки.  
**Эффект:** D7 слабый; NPS + за «меня заметили», без дисбаланса экономики.

#### 🟡 L3 — Частота 2/период не масштабируется в «ивент недели»

Пересечение с прогрессией: `event_tier` от `period_index`, события с хода 3. «Недельный ивент» с 4 карточками сломает TB1 и needs.

**Решение:** Live-дроп = **замена/расширение пула**, не 4-я карточка. Сложность — тот же balance contract.  
**Эффект:** D7 нейтрален; защита от выгорания vs «ещё кликов».

#### 🟢 L4 — Нет пересечения LTM с Victory chain

Победа — длинная chain. Сезонный reset прогресса **убил бы** 30+ trust.

**Решение:** сезоны если появятся — только **косметика / сюжетный пак / community-challenge вне save**. Прогресс партии не сбрасывать.

### Seasons

#### 🔴 L5 — Нет длительности, нет темпа, нет точки «сезон кончился»

Канон handbook: победы за сессию плейтеста **не ждать**; полная победа **40–60** периодов. Для Live Ops это **анти-сезон**: нет финиша, нет переноса, нет ожидания «через месяц новый акт».

**Решение Season 0 (4 недели CA):** не сезон игры, а **календарь коммуникации** (ниже). Игровой «сезон» = акт 1 до первого финала.  
**Эффект:** D30 не измеряем до CA; ожидание игрока «я в альфе, билды меняются» снижает удар по NPS vs молчаливая вечная α.

#### 🔴 L6 — План TG «не закрыл период сегодня» против TB1

| | |
|--|--|
| Канал | PLT-304, шаблон 4: локальный день, `period_open`, max 1×/сутки |
| Репутация | Игра обещает паузу 30+ («свернул — ок»). Daily nag = «это chore / Duolingo». Энергия без энергии. |
| Retention | Краткий bump D1, **просадка NPS и D30** у ЦА, которая как раз хочет паузу. |

**Решение:** шаблон 4 **не слать** в Season 0. Заменить на «открытый ход >14 дней» или только D+7 (шаблон 5). `/quiet` обязателен с первого сообщения.  
**Эффект:** D7 честнее (вернулись сами или по D+7); NPS не жжём daily. Гипотеза: daily close-nag **−5…10 NPS** на 30+.

#### 🟢 L7 — Не делать battle pass / streak / energy

Продуктовый аудит: freeze. Live Ops не компенсирует ими дыру mid-game.

### Social & UGC

#### 🟡 L8 — Нет социального слоя (и это ок), нет **видимости** прогресса

Solo. Нет рейтинга, гильдий, шаринга «итог хода», публичных достижений. UGC нет.

**Решение Season 0:**

- Не Discord (второй двор для 10–20 человек в RU 30+ = мёртвый канал). **Один** TG-чат тестеров.
- **Карточка шаринга** «Итог хода №N» (opt-in, без лидерборда) — lab, не P0.
- Достижения: экран в меню, не PvP.

**Эффект:** D7 от шаринга слабый (+1 п.п. если друзья); NPS от лидерборда на деньгах — риск токсичности и «кто засейвил». Не открывать PvP.

#### 🟢 L9 — Токсичность: низкий риск, пока solo

Дисбаланс наград между игроками не виден. Риск появится с рейтингом «кто быстрее победил» при разном стартовом шаблоне.

**Решение:** если когда-нибудь challenge — сегмент по `template_key`, не глобальный топ.

#### 🟢 L10 — UGC (моды карточек) слишком рано

Авторский YAML — pipeline команды (`create-event`). Игроки-авторы в α = support hell + баланс.

### Feedback

#### 🔴 L11 — Фидбек-цикл описан, не замкнут

| Есть | Нет |
|------|-----|
| Протокол: теги BLOCKER/UX, ежедневный разбор | WAVE1_RESULTS — пустой шаблон |
| α-FB реестр, n=1 wave-0 | URL чата/опроса в `PRE_ALPHA_WAVE1_OPS` = `________` |
| `player_run_feedback` на финале | Публичный «что изменили» |
| Watchtower / ops-TG для **команды** | Ответ игроку в том же треде <48 ч как SLA |

**Репутация:** альфа без видимой реакции = «написал в пустоту». NPS в CA меряют опросом — handbook Pre-Alpha **намеренно не** спрашивает NPS.

**Решение:**

1. Заполнить `FEEDBACK_CHANNEL` + опрос **до** инвайтов.
2. SLA: BLOCKER — день, UX — патчноут раз в неделю.
3. Пост/сообщение: «по вашему α-FB-15 сделали превью close» — даже если фича ещё lab.

**Эффект:** NPS-прокси Q7 «хотел ещё период» и Q6 «нужна была помощь». Не D7 напрямую; без этого D7 в CA **не интерпретируем** (ушли от злости vs от скуки).

#### 🟡 L12 — Нет прозрачности патчей для игроков

`CHANGELOG_TRACKER`: десятки черновиков, колонки Утв./Публ. пустые. Skill постов есть, канал не доказан.

**Решение:** 1 пост в **чат тестеров** (не обязательно публичный канал) после каждого билда: 3 буллета. Публичный канал — после PA-G2.

**Эффект:** sentiment ↑; D7 слабо.

#### 🟢 L13 — Внутриигровые голосования

Не нужны на n<50. Опрос после сессии закрывает.

#### 🟡 L14 — Telegram: три роли, одна не доведена до игрока

| Роль | Статус |
|------|--------|
| Ops-бот | Код есть; prod-настройка — чеклист этапа 0 |
| Player-бот | Webhook/start в коде ✅; **PLT-201 ops ⬜** |
| Канал | Маркетинг + invite; публикаций в трекере 0 |

**Решение:** Season 0 = ops smoke + **закрытый чат** + player `/start` без шаблона 4. Канал «для всех» — не gate α.

#### 🟢 L15 — Discord / голосования / форум

Не открывать. Watchtower — не комьюнити-тул.

## План запуска

**Предусловие (неделя −1):** preview списания на close и/или честный chip подушки (UX U2 / product C1). Иначе Live Ops усиливает негатив («вернулся — снова умер»). Заполнить invite URL. PA-G1 = 0 BLOCKER.

### Первые 4 недели (Season 0 — Closed Alpha community)

| Неделя | События Live Ops (не YAML) | Коммуникации |
|--------|----------------------------|--------------|
| **1** | Старт волны 10–20. **Нет** in-game LTM. Цель сессии 30–45 мин, ≥5 ходов. | Инвайт из шаблона + холодный старт API. Закреп: как слать BLOCKER. Ops-TG видит регистрации. |
| **2** | «Патч по фидбеку»: 3 изменения из α-FB (хотя бы copy/empty states). Опционально office hours 45 мин в чате. | Сообщение «что починили». Не просить NPS. |
| **3** | Если пак YAML готов — **тематический дроп** (анонс в чате, те же 2 карточки/ход, новый пул). Если нет — повторная сессия «докатите до хода 8». | 1 пост: новые истории, без множителей. Player TG: только win/loss если бот жив. |
| **4** | Retro + срез PA-A* / опрос. Решение: микро-волна vs Closed Alpha. | Патчноут недели 3–4. D+7 шаблон — **только** тем, кто `/start` и молчит 7 дней. |

Не в эти 4 недели: Discord, battle pass, daily, голосование в игре, советник, публичный маркетинговый сезон.

### Метрики

**Сейчас Pre-Alpha handbook: D1/D7 не gate.** Для Live Ops всё равно завести прокси, иначе календарь слепой.

| Метрика | Сейчас | Как мерить Season 0 | Зачем Live Ops |
|---------|--------|---------------------|----------------|
| **Retention D7** | нет данных; цель CA ≥8% среди закрывших ≥1 период | `last_seen_at` (PLT-107) или ручной «вернулся закрыть ещё ход» | Единственный north star return |
| **D30** | нет | не gate α | — |
| **Engagement** | PA-A1 ≥5 close / медиана close | Watchtower funnel, `period_closed`, `event_chosen` | Дроп контента vs тишина |
| **Sentiment** | n=1 качественно | Теги чата BLOCKER/UX/CONTENT; Q5–Q7; `player_run_feedback` | Репутация |
| **NPS** | не мерили (намеренно) | после CA, не неделя 1 | Не спрашивать до понятного loop |
| **TG** | ops; player ops ⬜ | `/start` count, `/quiet` rate, open rate шаблона 5 | Если quiet >30% — спам |
| **Content fatigue** | α-FB-03 | доля unique `definition_key` / 10 ходов | Нужен ли дроп |

Guardrail: **не** оптимизировать «закрытий в сутки» — это бьёт по TB1.

## Не делаем в этом снимке

- Править YAML и экономику (create-event / game-economy).
- Включать шаблон 4 «сегодня».
- Открывать Discord и лидерборд.
- Публиковать маркетинговый канал как замену фидбек-чату.
- Обещать числа D7/NPS как факт.

Утверждённое «делаем Season 0 так» → короткий spec или строка в `PRE_ALPHA_WAVE1_OPS`, не этот файл как канон.
