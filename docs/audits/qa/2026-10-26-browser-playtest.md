# Плейтест в браузере: ход 1–10 новым игроком

**Kind:** `qa` · **Дата:** 2026-10-26 · **Verdict:** DRAFT.

Маршрут: регистрация через форму → «Новая игра» → онбординг хода 1 (5 шагов) → ходы 2–10: зарплата, события, подушка, облигации, «Порадовать себя», вкладки «Капитал», «Аналитика», «Меню», офлайн. Консоль браузера и логи backend — без ошибок.

Параллельно шла переработка дашборда в соседней сессии (`MqxPeriodActions`, `MqxFinancePeriodBlock`) — раскладка главной в этом снимке промежуточная.
