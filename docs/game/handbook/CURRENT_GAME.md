# ТВОЙ ХОД · текущее состояние игры

Срез текущего локального кода на 07.11.2026. Это описание реализации, а не подтверждение внешнего релиза. Источники: App/GuestWelcomeScreen/AuthContext, DashboardScreen/MqxPocketBoard, backend guest_auth и guidance. Правила экономики — в соответствующих spec и коде; числа примеров не норматив баланса.

## Продукт и обещание

ТВОЙ ХОД — браузерная игра финансовой грамотности. «Финансы как игра» — подпись встроенного логотипа G1. PWA/web — основной канал, Telegram — дополнительный. ТВОЙ ПЛАН — отдельный прототип, не режим игры и не пункт стартового выбора.

Текст приглашения: «Твои решения. Твой финансовый опыт. Получай зарплату, планируй расходы и пробуй разные решения. Разбирайся в финансах через игру — без риска для настоящих денег». Не обещаем реальный заработок, гарантированное обучение, финансовый совет, банковские подключения или сроки прохождения.

## Вход и сохранение

Новый игрок нажимает «Начать играть». Сервер создаёт гостевую идентичность и настоящую партию Студента; обязательной формы почты/пароля/имени сохранения нет. Повтор начального запроса продолжает партию. Обычная «Новая игра» создаёт новую, в том числе после поражения.

После первого закрытого месяца можно добровольно создать аккаунт. Привязка почты сохраняет User.id, партию, решения, историю и деньги. Отказ не блокирует игру, ссылка остаётся в меню. Вход в существующий аккаунт открывает его сохранения, не объединяет их с гостевыми.

Гостевой доступ связан с браузером: HttpOnly-cookie, хеш capability на сервере, срок сессии 180 дней. Удаление данных браузера может лишить доступа; прогресс не переносится на другое устройство без аккаунта. Access JWT восстанавливается при живой сессии. Детали и ограничения: [SPEC_guest-first-start](../specs/features/SPEC_guest-first-start.md).

## Один ход

Получить зарплату → решить события → при желании изменить подушку/вложения → завершить ход → увидеть списания и результат. Зарплата ручная, пропущенная выплата не переносится. Один период — игровой месяц, без таймера и привязки к календарному месяцу.

Новые гостевые партии имеют onboarding_version=2: события с первого хода, подушка не обязательный учебный gate, краткая помощь по запросу. Старые партии сохраняют O3 и прежний порог событий (ход 3). В v2 колода открывается только вручную на любом ходу (локально, 08.11); счётчик событий остаётся на карточке «События».

## Интерфейс

«Игровой пульт»: логотип/ход/роль/маскот, счёт слева, кнопка завершения на всю ширину, прогноз списаний снизу. Монетка Б постоянно занимает место в верхнем блоке: think — зарплата, surprised — события, joy — готовность, worried — риск. По нажатию открывается контекстное окно. Автоматической разделяющей строки нет. На двух карточках действий только «События» и «Получить зарплату»/«Зарплата получена», высота постоянна.

Четыре потребности: Комфорт, Статус, Связи, Здоровье. Компактный блок, подробности по запросу. Цель — последовательный маршрут партии, текущий шаг и следующее действие. Навигация: Главная, Капитал, Аналитика, Меню. Мобильная панель внизу, десктопная сбоку.

## Готовность и открытые вопросы

Реализовано и проверено локально: гостевой старт/claim/resume, первый цикл, вариант Б без сдвигов; 719 backend-тестов, целевые guest/schema, FE unit/build, браузерные сценарии mobile/desktop. Точные результаты: [guest verification](../../../design-lab/screen-refresh/guest-first-round/VERIFICATION.md), [steady-help verification](../../../design-lab/screen-refresh/steady-help-round/VERIFICATION.md).

Баланс не принят: Student chain_runner seed42, 40p, v1/v2 обе победы P18, но денежный diff выше порогов. Общий manifest текущего дерева тоже расходится с прежними baseline. Не обновлять эталоны автоматически и не называть выпуск готовым.

[Плейтест первых трёх ходов](../audits/qa/2026-11-07-first-three-turns/README.md): деньги сходятся; следующие кандидаты — ручное открытие событий после P2, менее тревожный старт до зарплаты, ценность дорогих альтернатив. Эти кандидаты не стали утверждёнными изменениями экономики.
