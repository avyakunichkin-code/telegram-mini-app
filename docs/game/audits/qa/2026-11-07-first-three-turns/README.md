# Плейтест нового старта: первые три хода

07.11.2026. Skill game-studio:game-playtest. Живой Chrome через MCP Playwright, 390×844, localhost:5186, новый синтетический гость в отдельном browser context. Реальные UI-действия; без изменения API, баланса, seed, старых сохранений. Это один случайный прогон, не оценка распределения событий и не принятие нового baseline.

## Находки по приоритету

1. **Средняя, темп:** после «Дальше» в итогах второго месяца на третьем ходу автоматически открывается колода до получения зарплаты. Повторено после третьего итога на четвёртом. Игрок теряет инициативу, возвращается к модальным окнам после упрощённого первого опыта. Источник: frontend guidance/curriculum.js shouldDeferEventsAutoOpen только для v2 P1/P2; автооткрытие в GameScreen. Рекомендация: в новом сценарии события всегда открывать вручную, счётчик сохранить в доступном имени/индикаторе без новой строки.
2. **Средняя, финансовый выбор:** «Аптечка и витамины»: 3 120 ₽ даёт Комфорт +1/Здоровье +4; 1 250 ₽ даёт Здоровье +4. Доплата 1 870 ₽ за один комфорт при достаточных потребностях почти не имеет смысла. «Скидки»: доплата 2 500 ₽ меняет комфорт +3 на +4, здоровье одинаково +2. Это не ошибка формулы и не строго доминируемые варианты по всем осям, но новичку выгодно механически брать дешёвый положительный ответ. Требуется отдельный content/economy brief, не молчаливое изменение YAML.
3. **Низкая/средняя, первое впечатление:** на P1 до зарплаты прогноз −22 500 ₽ и обеспокоенная Монетка. Выплата доступна, её достаточно. Фактический прогноз верен, но тон чрезмерно тревожный. Подсказка «Не хватит на расходы — забери зарплату» правильна; лучше сначала спокойная задача получить выплату, риск оставить если даже после неё расходов не покрыть.
4. **Наблюдение:** новый необязательный маршрут оставляет цель «внести любую сумму в подушку» на шаге 2, но зарплата + дешёвые события позволяют свободно копить на счёте без понимания пользы подушки. Это не блокер, следующий обучающий момент стоит привязать к осмысленной цели, не обязательному клику.

Подушка/вложения не использовались намеренно: путь новичка без оптимизации. Потребности после трёх закрытий: Комфорт 67, Статус 50, Связи 50, Здоровье 73 (на экране следующего хода).

## Что работает

Первый запуск без регистрации; ручная зарплата; последствия выбора читаются до подтверждения; компактные кнопки и Монетка не меняют высоту; первый итог показывает расход и общий результат без повторов; предложение регистрации после первого итога отклоняется и не возвращается на следующих двух ходах. Деньги сходятся. После обновления данных на P4 зарплата снова доступна, счёт 82 280 ₽. Мгновенные данные за модальным итогом могут ещё быть предыдущими до refresh — отдельную регрессию этим не объявляем.

## Решение по балансу

Не снижать зарплату и не повышать расходы по этому одному прогону. Ранние события и раньше выполненный 40p diff меняют траекторию; baseline остаётся pending-balance. Сначала сделать ручное открытие событий последовательным для v2 и уточнить ценность альтернатив в 2–3 ранних событиях, затем повторить сравнение политик/seed. Человеческое согласование нового баланса этим отчётом не заменяется. Продуктовый код в плейтесте не менялся; тест-команды не запускались, так как изменения только в отчёте и PNG.
