# Следующий срез после нативного опроса

Основание: поручение владельца «Давай тогда следующие доработки».
Это сверка очереди и воспроизведение известной нестабильности, не утверждение
нового UI, экономики или выкладки. Пользователю предложен выбор направления.

## Проверенные факты

- Нативный опрос локально завершён: [отчёт](NATIVE_SURVEY_THREE_STEPS_2026-11-05.md).
- Нестабильность mobile Capital из readiness 04.11 сейчас не воспроизведена.
  Изолированный повтор `e2e/capital.spec.js`, mobile-chrome, repeat-each=5:
  **5 passed (1.2m), exit 0**. Это не доказательство устранения гонки.
- `CapitalDetailsPanel.jsx` уже содержит EmptyNote и переход во вкладку
  «Действия». PR-26 нельзя считать полностью отсутствующим по старому backlog.
- `MqxPeriodCloseRitual.jsx` уже показывает итог счёта, изменение за ход,
  списания/начисления и просрочку. PR-27 требует сверки конкретного остатка
  задачи, а не повторной реализации существующей разбивки.
- Разнообразие событий PR-22/24 требует измерения актуального каталога;
  наличие поля cooldown не доказывает достаточное разнообразие.

## Кандидаты

1. Понятнее первый вклад/покупка: проверить путь пустые «Детали» → действие →
   сумма → подтверждение → новая позиция. Изменённый UI сначала в lab.
2. Итоги хода: проверить сравнение предварительного списания с фактом,
   наличие понятного «до/после» и отсутствие повторения уже существующих строк.
3. События: read-only аудит повторов и тематического покрытия, затем отдельный
   конкретный brief для YAML, если дефицит подтвердится.

Два акта остаются после волны согласно решению владельца; пороги не выбраны.
Деплой, рассылка и реальная волна этим поручением не выполнялись.
