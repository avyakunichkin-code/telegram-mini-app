# Синхронизация документации и новый лендинг

Запрос владельца: актуализировать документацию игры и собрать три варианта лендинга. После просмотра предыдущий раунд отклонён, активный — [landing-author-round](../../../design-lab/landing-author-round/README.md). Никакого внешнего деплоя, принятия баланса или замены production-лендинга этим поручением не выполнялось.

Исторические аудиты, предыдущие APPROVED, ADR и действующие правила финансовых расчётов не переписывались. Старые O3-спецификации остаются применимыми к прежним партиям. Документы отдельного продукта ТВОЙ ПЛАН не обновлялись под Game. Это актуализация всего затронутого продуктового контура, не заявление, что каждый исторический Markdown описывает сегодняшний UI.

## Поведение, которое не меняли

События v2 доступны с P1; автопоказ подавлен только P1/P2. Предложение ручной колоды на всех ходах ещё не реализовано. Зарплата/расходы/цены событий не калибровались. Победа в два акта, слияние аккаунтов и автоматическая очистка гостей не объявлены готовыми.

Баланс остаётся pending-balance; полный legacy manifest и v1/v2 денежный diff exit1. Генерация маркетинговой страницы не равна утверждению нового баланса или запуску массового набора.

## Проверки

Итог браузерных проверок вариантов, ресурсов, CTA и ссылок — [VERIFY](../../../design-lab/landing-author-round/VERIFY.md). Правки не меняют runtime продукта; backend/экономические тесты повторно не запускались ради документации. Результаты предыдущей реализации не выдаются за новые проверки этого среза.

## Выбранный лендинг А

После явного утверждения владельца: стиль А, содержание прежнего landing/site, уменьшенные заголовки. Синхронизированы lab и локальный site, preview обновлён до pocket-page-round. Актуализированы brief, CURRENT_GAME и оба README. Сборка exit 0; браузерная проверка шести ширин и интерактивного выбора — PASS. Подробности: [VERIFY](../../../design-lab/landing-author-round/VERIFY.md). Без внешней публикации.
