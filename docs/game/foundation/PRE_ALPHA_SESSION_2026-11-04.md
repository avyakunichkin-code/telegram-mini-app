а не запись о проведённом плейтесте. Результаты человека пока не получены.

## Личная сессия

Локальный стенд подготовлен: [игра](http://127.0.0.1:5177/#/), API на
`127.0.0.1:8015`, новая SQLite `.codex-state/game-personal-20261104.db`.
Старт backend с `PYTHON_DOTENV_DISABLED=1`, тестовым ключом и выключенными
Telegram-уведомлениями. Это локальные процессы текущей сессии, а не постоянный
хостинг. Создать отдельный тестовый аккаунт; реальные данные не вводить.

Билд: текущая калибровка A, один акт в runtime. Главная —
[текущий утверждённый вид](../../../design-lab/dashboard/current-page-round/README.md).
Для сравнимого первого прохода — новая игра «Студент». Использовать только
игровые данные. Продолжительность 30–45 минут; ориентир 5 закрытых ходов,
для новичка минимум 3. Победа за сессию не обязательна.

1. Зафиксировать URL стенда, SHA/артефакт, устройство и браузер. Локальные
   незакоммиченные изменения означают, что одного HEAD недостаточно.
2. Начать игру без предварительного чтения гайда. Записать, понятно ли первое действие.
3. Получить зарплату; проверить, понятно ли, почему её нельзя получить второй раз.
4. Сделать перевод в подушку и обратно. Своими словами объяснить, откуда
   спишутся расходы при закрытии. Подушка не покрывает их автоматически.
5. До закрытия назвать ожидаемое списание и остаток; после закрытия сравнить
   с фактом. Зафиксировать расхождение, если есть, с номером хода.
6. Пройти события и несколько ходов; отметить повторы, непонятные варианты
   и место, где следующий шаг цели потерялся.
7. Свернуть/вернуть приложение и заблокировать/разблокировать телефон;
   проверить номер хода и балансы. Полный resume — по
   [PW1-чеклисту](PW1_RESUME_PLAYTEST_CHECKLIST.md).
8. Проверить «Капитал» и возвращение к игре. При остановке записать причину,
   даже если это усталость, а не ошибка.

| Наблюдение | Ответ человека |
|---|---|
| Стенд / версия / устройство | Не заполнено |
| Длительность / закрыто ходов | Не заполнено |
| Зарплата понятна без подсказки | Не заполнено |
| Разница счёта и подушки понятна | Не заполнено |
| Прогноз закрытия совпал с фактом | Не заполнено |
| Следующая цель понятна | Не заполнено |
| Где застрял / повторы / причина остановки | Не заполнено |
| Resume: номер хода и балансы сохранились | Не заполнено |
| Хочется продолжить ещё 1–2 хода | Не заполнено |

Ответы и реальные анкеты не добавлять в git. В репозитории хранить только
обезличенный итог и воспроизводимые баги. Автотесты не заполняют эту таблицу.
