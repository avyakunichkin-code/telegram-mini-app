## Что остаётся обсудить

- После личного плейтеста: когда приглашаем 10–20 участников и кто собирает обратную связь? Есть ли ещё не записанные результаты? Предложение — один канал фидбека и существующий [ops-лист](foundation/PRE_ALPHA_WAVE1_OPS.md), без нового процесса.

- Порог пассивного дохода и состав механик акта 2 — после проверки текущей A; см. концепцию выше.
- До 2026-12-01 выбрать способ закрытия C-3: (A) явная пометка игровых ставок как условных + короткий дисклеймер; (B) источники/даты для каждого финансового продукта + дисклеймер; (C) условные ставки сейчас, источники там, где прямо сравниваем с реальностью.
