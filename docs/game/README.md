Канонические документы игры находятся внутри `docs/game/` по слоям:
`foundation/`, `handbook/`, `specs/`, `ux/`, `vision/`, `plans/`, `backlog/`,
`events/`, `audits/`, `ops/`, `marketing/`, `reference/`, `balance/` и `tasks/`.
Новые документы Game создавай здесь; документы Plan — в `docs/plan/`.
Прежние адреса содержат только ссылки совместимости, исключённые из поиска.

Общие правила репозитория, ADR и библиотеки — через
[общий индекс](../README.md). Для обычной игровой задачи читать их по необходимости.
