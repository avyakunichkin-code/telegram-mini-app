## Что находится в папке

- `tasks.json` — единый редактируемый реестр.
- `items/GAME-OWNER-*.md` — отдельная карточка: что сделать, результат,
  зависимости и ссылки на расположение исходных материалов.
- `index.html` — работает напрямую из файла без сервера и подключения к API.
- `build.mjs` — пересобрать страницу и карточки: `node docs/game/tasks/build.mjs`.
- [AUDIT.md](AUDIT.md) — сверка актуальности и известные ограничения источников.
- [SOURCES.md](SOURCES.md) — карта исходных backlog/планов и их распределения.

Формат совместим с каталогом задач ПЛАНА. Генератор ХОДА самостоятельный:
пересборка не пишет в `docs/plan/`, Design Lab, продуктовые приложения или БД.
Spec и планы остаются на исходных местах, чтобы сохранить ссылки и один канон;
в этой папке собраны именно задачи и навигация по ним.

## Как пользоваться

1. Открыть страницу, выбрать статус, тип и приоритет. По умолчанию выполненное
   скрыто. Поиск работает по ID, названию, описанию и зависимостям.
2. Открыть карточку или исходный документ; решить, что взять следующим.
3. Поставить «В работе». Личная отметка не переписывает source status,
   не утверждает spec/макет, не разрешает выкладку и не закрывает зависимости.
4. Скачать очередь перед сменой браузера; восстановить через JSON-импорт.
   Если localStorage недоступен, отметки живут в текущей вкладке.

Статусы: **Можно начать** — можно готовить указанный результат;
**Есть зависимость** — сначала получить описанный вход;
**Позже** — осознанная очередь будущих решений;
**Уже решено** — история, не новое требование. «Мой статус» — личное состояние,
не автоматически вычисленный workflow. Завершение одной карточки не переводит
зависимые автоматически в ready.

Не записывать в очередь контакты участников или реальные финансовые анкеты.
Страница не делает внешних запросов и не читает ключи/токены приложений.
Экспортируются только известные ID и ваши статусы.
