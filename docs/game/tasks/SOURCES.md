Файлы audits/ops с датами используются как свидетельства выполненных работ,
а не новые источники обязательств. Полный исторический архив не превращён
в список персональных поручений. Темы без подтверждённого текущего gap
явно остаются задачами сверки/выбора; утверждения «всё проверено тестами» нет.
