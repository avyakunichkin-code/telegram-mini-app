# GAME-OWNER-28 · Проверить выбранный лендинг А перед публикацией

ТВОЙ ХОД · задача владельца · срез 07.11.2026.

Приоритет: P2. Исходный статус: Можно начать. Тип: Приёмка.

## Что сделать

Просмотреть локально внедрённый А: содержание, обещания, текущий preview и целевой адрес игры. Проверить, соответствует ли внешняя ссылка выбранному билду; не выбирать А/Б/В повторно.

## Результат

Зафиксирована приёмка конкретной версии и отдельное решение о публикации после readiness.

## Зависимости

Стиль А и уменьшенные заголовки уже утверждены; публикация ещё не подтверждена.
