# GAME-OWNER-05 · Принять решение по балансу и эталонам

ТВОЙ ХОД · задача владельца · срез 07.11.2026.

Приоритет: P1. Исходный статус: Есть зависимость. Тип: Утверждение.

## Что сделать

После разбора выбрать калибровку или явно принять объяснённый rebalance. Обновление baseline разрешать только для выбранного проверенного поведения.

## Результат

Записаны принятые параметры, причины, ограничения и разрешение на новый эталон, если требуется.

## Зависимости

Ждём от агента разбор текущего drift и конкретные варианты калибровки. Самому запускать симуляции и готовить технический разбор не требуется.
