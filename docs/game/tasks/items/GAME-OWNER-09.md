# GAME-OWNER-09 · Назначить волну 10–20 и канал обратной связи

ТВОЙ ХОД · задача владельца · срез 07.11.2026.

Приоритет: P1. Исходный статус: Можно начать. Тип: Организация.

## Что сделать

Определить ведущего, состав, даты и один канал обратной связи; заполнить ops-лист и порядок разбора блокеров. Использовать встроенный опрос v2 вместо обязательной внешней формы. При необходимости выбрать канал/чат, правила и закреп версии из PLT-401…405; согласовать, кто публикует приглашение.

## Результат

Есть календарь, ответственные, участники и заполненный ops-лист без выдуманных результатов.

## Зависимости

Планировать участников и время можно сейчас. Перед приглашениями дождаться подготовленного агентом readiness и устранения блокеров.
