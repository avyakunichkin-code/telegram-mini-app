# GAME-OWNER-19 · Уточнить продуктовую роль потребностей

ТВОЙ ХОД · задача владельца · срез 07.11.2026.

Приоритет: P2. Исходный статус: Есть зависимость. Тип: Продуктовое решение.

## Что сделать

После подготовленного агентом разбора выбрать, какое давление потребностей делает игру интересной, какие последствия приемлемы и нужен ли другой набор отдыха. Не требуется самому сверять формулы или редактировать spec.

## Результат

Уточнены актуальная spec и конкретный brief изменения, если оно нужно.

## Зависимости

Ждём от агента актуальную сверку set_point/CN1 и конкретные варианты решения. Инженерная диагностика не личная задача владельца.
