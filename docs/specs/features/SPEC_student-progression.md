# Spec: развитие роли «Студент»

**Решение PO 2026-11-09:** снять условие «только после волны» для этих пяти улучшений, делать spec и код. Цена: волна проверяет уже другую игру, и сравнение с принятыми baseline студента неполно.

## Проблема

Бот `chain_runner` выигрывает на 15-м ходу, после чего целей нет. Счёт растёт с 34 тыс. ₽ (P12) до 307 тыс. ₽ (P30) без осмысленных трат. Страховки, имущество и кредиты закрыты навсегда, своих сюжетов мало.

## Улучшения

### 1. Лестница открытий

`mechanics_unlock` получает необязательное поле `min_period`. Шаг открывается, когда выполнены его `after_goal` и `min_period`.

| Ход | Раздел | Флаг |
|---:|---|---|
| старт | Инвестиции | `capital_invest` |
| 6 | Страховки | `capital_insurance` |
| 12 | Потребительские кредиты | `capital_liabilities` |
| 20 | Авто и автокредит | `capital_car` |
| 26 | Жильё | `capital_property` |
| 32 | Ипотека | `capital_mortgage` |

Все шаги после старта требуют цель `tutorial_invest`. Это разовое действие, а номер хода только растёт, поэтому открытие не отзывается. Цели `safety_2x` и пассивный доход считаются по текущему состоянию и для привязки не подходят. Ни одна покупка не нужна для победы.

Новые флаги разделяют авто и жильё, кредит и ипотеку. Для остальных шаблонов всё открыто, как раньше. Проверка — на сервере (403 `mechanic_disabled`), UI использует существующее состояние «закрыто».

`overview.mechanics_next_unlock_period` — ход следующего открытия, если цель шага уже выполнена.

### 2. Открытие через историю

Пять карточек `mq11_student_unlock_*`. Условие `requires_mechanics_all`, приоритет слота, один раз за партию.

### 3. Мечта

Цепочка `student_dream` с 8-го хода: выбор поездки, курса или студии, через 6 ходов решение о покупке за 60–150 тыс. ₽.

### 4. Диплом

Цепочка `student_diploma` с 13-го хода: работа (+12 тыс. ₽), стартап (−15 тыс. ₽, через 8 ходов +25…45 тыс. ₽) или магистратура (60 тыс. ₽ и −5 тыс. ₽, через 6 ходов +22…35 тыс. ₽). Новый эффект события `monthly_salary_delta` действует со следующей выплаты, зарплата не ниже нуля.

### 5. Пакет историй

Файл `data/events/mvp11/student_progression.yaml`: цепочка «друг просит в долг» и 15 карточек.

## Старые сохранения

Флаги считаются на лету. Купленное не отбирается, начисления задним числом нет. Партии на поздних ходах получают уже наступившие открытия сразу. Данные не мигрируются.

## Границы

- Числа ходов и сумм — параметры для проверки плейтестом.
- Второй акт и его цели не входят ([SPEC_victory-acts](SPEC_victory-acts.md)).
- Новых экранов нет; lab не требуется. Новый визуальный индикатор открытия — отдельно через design-lab.

## Проверка

`backend/tests/test_student_progression.py`, `backend/tests/test_student_chains.py`, контракт каталога событий, `balance_playtest` студента.

## Симуляция (seed 42, 40 ходов, сравнение с принятыми baseline)

| Метрика | `chain_runner` до → после | `needs_keeper` до → после |
|---|---|---|
| Ход победы | 15 → 22 | нет → нет |
| Минимум потребностей, P30 | 9,4 → 17,7 | 9,4 → 25,7 |
| Счёт, P30, ₽ | 307 208 → 270 553 | 526 630 → 364 270 |
| Поражение | нет → нет | нет → нет |

**Решение PO 2026-11-09:** победа `chain_runner` на 22-м ходу принята для студента, хотя выходит за окно P12–P18 калибровки A. Baseline пока не обновлены. Боты не покупают новые разделы, поэтому лестницу проверит только живой плейтест.
