# Расширение нативного опроса · v2

Исторический отчёт пятишаговой реализации. Последующее уточнение владельца
возвращает три экрана; актуальный [срез](../../../ops/NATIVE_SURVEY_THREE_STEPS_2026-11-05.md).

Поручение владельца 05.11: добавить пару вопросов к деньгам/подушке,
оценку сложности «Легко / Нормально / Сложно» и полезный вопрос к завершению.
Реализовано девять обязательных ответов и необязательный свободный отзыв.

Новые вопросы:

- Понятно, как перевести деньги в подушку и обратно?
- Понятно, зачем на счёте нужен запас на расходы?
- Понятно, что изменилось после завершения хода?
- Как тебе сложность игры? — Легко / Нормально / Сложно.

Пять коротких шагов: 2 + 2 + 3 + 2 вопроса, затем отдельный свободный текст.
Отзыв вынесен отдельно, потому что два вопроса и поле вместе требовали
прокрутки на 360×640. Кнопки и шрифты не сжимались ради размещения.

## Совместимость

Текущий frontend явно запрашивает `first_turns_v2` в bootstrap/get и передаёт
его в submit/dismiss. Клиент без версии остаётся на `first_turns_v1`:
пять прежних ответов, прежние default API и независимый статус «Позже».
Строгая схема проверяет соответствие версии пяти или девяти ключам.
Чужой набор/сложность вне easy/normal/hard даёт 422. Старые строки не
переписываются; новое заполнение получает отдельный ID под новым ключом.
Watchtower показывает версии в отдельных таблицах с пятью/девятью колонками
ответов, а не дополняет v1 пропущенными или придуманными ответами.

Новой миграции не требуется: существующая 0051 уже содержит survey_key,
JSON и UNIQUE(user_id, survey_key). Для первой выкладки нативного опроса
0051 по-прежнему обязательна. Production не изменялся.
