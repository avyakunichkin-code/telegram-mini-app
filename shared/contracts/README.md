# Общие контракты

- fincore: dataclasses, Decimal и чистые функции; адаптеры принадлежат API продуктов.
- platform: инфраструктура без доменов; данные, секреты и JWT audience раздельны.
- ui-kit: нативное поведение; [контракт](../packages/ui-kit/CONTRACT.md).
- [Проверки UI](../tests/ui/README.md) проверяют реальные адаптеры обоих продуктов.

Продуктовые HTTP-контракты остаются в specs и коде соответствующего продукта.
