# Межпродуктовый UI-контракт

Этот контур владеет проверкой двух реальных адаптеров общего ButtonBase:
Plan Button и Game MqxButton. Он не входит в unit-набор любого приложения.
Продуктовые сценарии и темы проверяются внутри соответствующих приложений.

Из корня: `node --test shared/tests/ui/*.test.mjs`.
Установить зависимости этого каталога: `npm ci` из `shared/tests/ui`.
Контур имеет собственные package/lock и Vite/React; зависимости приложений не
используются как тестовый runtime. Загружаются реальные адаптеры обоих продуктов.
Backend и браузер для этого контракта не нужны.

Отдельный CI job `Shared UI contract` запускается при изменениях любого
frontend, общих пакетов, этого контура или CI. Ошибки контракта не скрываются
за пропуском продуктовых jobs. Это не проверка внешнего вида или human approval.
