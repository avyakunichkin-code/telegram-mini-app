# UI-сценарии (Playwright)

Сквозные сценарии игрока в настоящем браузере — системный Google Chrome (`channel: 'chrome'`), браузеры не скачиваются. Мобильный viewport (Pixel 7).

```bash
npm run test:e2e            # прогон, отчёт — playwright-report/
npx playwright test --headed --grep "События"   # один сценарий с окном браузера
npx playwright show-report  # открыть отчёт и trace упавших тестов
```

## Стенд

`playwright.config.js` сам поднимает изолированный стенд и гасит его после прогона:

- backend — `backend/.venv` + uvicorn на **:8011**, база — новый SQLite-файл во временной папке (локальный PostgreSQL не трогается, `DATABASE_URL` из окружения сильнее `backend/.env`);
- frontend — Vite на **:5181**, `/api` проксируется на :8011.

Порты 8011 и 5181 должны быть свободны (другие — `E2E_API_PORT` / `E2E_WEB_PORT`). Другой Python — `E2E_PYTHON=путь\python.exe`.

## Правила

- Каждый тест — **свой пользователь** через API (`player` в `fixtures.js`); тесты не зависят друг от друга.
- Любая ошибка в консоли браузера валит тест (`consoleErrors`). Ожидаемые — `test.use({ allowedConsoleErrors: [/…/] })`.
- Селекторы — по ролям и подписям, как видит игрок и скринридер (`getByRole`, `getByLabel`); классы — только для слоёв без роли (полоска Монетки, ритуал хода).
- Регресс найденного бага — комментарий `Регресс <дата>: что было`.
