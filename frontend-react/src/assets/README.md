> Источник дизайна: `design/system/` из корня репозитория. CSS — `runtime/`, графика — `assets/` и `illustrations/`. Файлы приложения экспортируются через `node scripts/design-assets.mjs`; редактировать оригинал, затем синхронизировать. Архивные маскоты пока используются приложением для совместимости.

# Экспорт дизайн-системы

Редактируемые оригиналы: [`design/system/`](../../../design/system/ASSET_STORAGE.md).

Пути оставлены для существующих импортов. Меняйте источник, затем из корня запускайте `node scripts/design-assets.mjs`. Сборка проверяет байтовое равенство экспортов и отклоняет незарегистрированные изображения/шрифты/анимации в этой папке. Новые ресурсы сначала добавляются в дизайн-систему и `asset-exports.json`.
