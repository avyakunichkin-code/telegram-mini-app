## Уточнение по скриншотам владельца · 06.11.2026

Пустая полоса после зарплаты признана ошибкой: скрытая подсказка теперь убирается из потока; высота самого зарплатного билета сохраняется. Объёмный recovery потребностей свёрнут под «как восстановить», критический streak не скрыт. Цель возвращена к утверждённой компактной подаче А: маршрут с флажком, название из сервера, текущее/целевое значение, прогресс, действие. Полные шаги/пояснения раскрываются отдельно. Источник MqxPocketGoal; новые пороги не введены.


По следующему уточнению владельца G1 встроен в карту хода на мобильном, над жетоном хода; ширина 60 px. Отдельная верхняя полоса убрана. Desktop сохраняет G1 в боковой навигации.
