## Порядок блоков (prod `DashboardPremium`)

1. **Карта хода** (`MqxDashboardHero`) — сверху, прокручивается с контентом: роль слева («Студент» по `template_key`), «Твой ход» (h1); номер хода справа без «из N».
2. Внутри карты: плашка **«N событий»** (колода, нажимается, если события открыты; 0 — «События решены») → **Монетка одной строкой** (самое срочное) → компактная **«Завершить ход»** → под ней строка **«Спишется N ₽ · останется M ₽»** (`period_close_preview`; минус — красным; третий минус подряд — красная плашка «игра закончится»), ★ PR-07 close-preview A.
3. **Потребности** (`MqxNeedsDash`) — 4 тонкие шкалы 2×2 с числом; в заголовке книга+? (help sheet) и сердце (treat-self); при нуле — строка риска.
4. **Деньги** (`MqxFinancePeriodBlock`) — портрет персонажа у суммы «На счёте»; ниже без рамок «Доходы за ход» (`total_monthly_income`, все источники), «Расходы за ход», «Подушка · N%» (★ BG-3) со второй строкой «не платит расходы» (красная, если счёт уйдёт в минус; ★ PR-07). Доход и расход ведут в потоки «Капитала» (стрелка `›` у подписи).
5. **Цель** (`MqxGoalDash`) — свёрнута: «Цель, шаг N из M» + дорожка точек без подписей + золотой финиш; раскрыта: шаги цепочки победы (`victory_config_json`), без Монетки.
6. **Действия хода** (`MqxPeriodActions`, ★ BG-3) — заголовок «Действия хода»; «Зарплата» — главная золотая кнопка на всю ширину с суммой и монетой как Монетка, после выплаты — пунктирная строка «Зарплата получена ✓»; ниже залитые фишки «В подушку» (+), «Из подушки» (−), «Вложить» (растущая стрелка).

## Монетка — что срочнее

Риск поражения по потребностям → просрочка → минус после хода («Не хватит на расходы — забери зарплату / сними из подушки», ★ PR-07) → зарплата → события → шаг цели → «все шаги готовы» / победа (`buildTurnTip`, `components/mqx/utils/boardDashDisplay.js`).

## Инварианты

- Токены v2 (`styles/tokens.css`): `--mq-coin*`, `--mq-board`, `--mq-cell*`, `--mq-turn*`, `--mq-gain*`, `--mq-risk*`; светлая и тёмная тема (`prefers-color-scheme`, `:root[data-theme='dark']`).
- Шрифт F3: Nunito 800/900 (заголовки, суммы) + Manrope 400/600/700 (текст), self-host `src/assets/fonts/` (cyrillic + latin, ₽ из latin-ext), системный fallback.
- BG-3 E + BG-4 K1: рамка у карты хода; информация на поле без контура, нижняя кромка только у действий. Роли цвета: фиолет — действие, золото — деньги/награды/финиш, изумруд — плюс, красный — только риск; расход нейтрален.
- Ходов не ограничено; путь = шаги цели. Движок сейчас отдаёт `min_period_index = 1` (ворота по ходу сняты), поэтому финиш пишется «Финиш — победа, игра продолжится»; «с N-го хода» — только при N > 1.
- Якоря онбординга сохранены: `hero`, `events`, `next_period`, `needs`, `finance-flows`, `goal`, `salary`, `cushion`.

## Итерация после игры (2026-10-15)

Утверждено в чате («Так лучше» + правки):

- **Плотность:** ~~главная целиком на 360×640 при свёрнутой цели (запас ~30px до таббара)~~ — снято 2026-10-26 вместе с ★ BG-3: на 360×640 главная прокручивается. Деньги — три плитки в ряд (подписи `--mq-fs-small` в одну строку, значения `--mq-fs-lead`), зазоры 10px, номер хода `--mq-fs-money`. Зоны нажатия ≥ 44px. Стили — блок «Плотность» в конце `styles/mqx/board.css`.
- **Потребности отделены от карты хода** (~14px).
- **Иконки потребностей:** «?» в круге — справка (вместо книги); сердце с «+» справа — «Улучшить потребности».
- **Финиш цели:** золотая клетка поля с монетой и пунктиром от последнего шага; больше не обрезается.
- **Кнопки подушки:** «В подушку» / «Из подушки» (иконка копилки со стрелкой внутрь / наружу); окно подушки с теми же заголовками; текст бита онбординга `p1_cushion` — «В подушку».

## Уточнение по скриншотам владельца · 06.11.2026

Пустая полоса после зарплаты признана ошибкой: скрытая подсказка теперь убирается из потока; высота самого зарплатного билета сохраняется. Объёмный recovery потребностей свёрнут под «как восстановить», критический streak не скрыт. Цель возвращена к утверждённой компактной подаче А: маршрут с флажком, название из сервера, текущее/целевое значение, прогресс, действие. Полные шаги/пояснения раскрываются отдельно. Источник MqxPocketGoal; новые пороги не введены.
