# Маскоты в стиле питомца · 03.11.2026

**Утверждён B · «Мягкий объём», 2026-11-03.** Решение владельца:
«Давай утвердим B Мягкий объём». Все четыре пары; [фиксация решения](../APPROVED.md).

Задача владельца: сохранить идеи персонажей и предметов-напарников,
перерисовать их с качеством и выразительностью созданного питомца Студента.

## Смотреть

Через [хаб Design Lab](../../index.html) → «Примитивы и бренд» →
«Маскоты в стиле питомца: четыре пары · B Мягкий объём ★».

В раунде — исходная пара, два новых исполнения на одинаковых данных,
вся семья, проверка в интерфейсе и маленьком размере, светлая/тёмная тема.
По умолчанию показан утверждённый B. Переключатели сохраняют персонажа и вариант в URL;
A остаётся доступен для сравнения.

| Вариант | Идея |
|---|---|
| A · Чёткий стикер | Ближе к питомцу: ясный контур, лаконичные тени, выразительные глаза |
| B · Мягкий объём | Те же персонажи с более округлыми формами, мягким светом и плавными бликами |

## Что сохраняем

| Персонаж | Напарник | Признаки |
|---|---|---|
| Студент | Студбилет | Каштановые волосы, фиолетовое худи, рюкзак; изумрудный билет с портретом и печатью |
| Профессионал | Зарплатная карта | Причёска с пробором, жёлтая куртка, белая футболка; фиолетовая карта с чипом |
| Руководитель | Портфель | Деловая стрижка, фиолетовый костюм, золотой галстук; коричневый портфель с застёжкой |
| Предприниматель | Смартфон | Каштановый пучок, серьги, фиолетовый жакет, золотой кулон; жёлтый смартфон |

Источник концептов — существующий [раунд напарников](../companions-round/README.md)
и его `characters.js`. В новом рисунке капюшон Студента опущен: открытая
причёска и лицо соответствуют понравившемуся питомцу. Два обычных плеча и руки
у Предпринимателя соответствуют этому lab-концепту; прежний шестирукий prod-портрет
не является источником данного раунда.

В выборе жизни показывается только человек. Пара — после выбора, на знакомстве.
Роли Монетки, сценарии, O3 и снятый барометр этим раундом не пересматриваются.
Тексты в контекстных фрагментах — демонстрационные, не новая спецификация онбординга.

## Артефакты

- `assets/reference/*-current.png` — существующие SVG, отрендеренные без перерисовки.
- `assets/*-before.webp` — те же исходники в общей сетке и масштабе для честного сравнения.
- `assets/reference/pet-style.png` — созданный питомец, стилевой ориентир.
- `assets/*-source.png` — новые оригиналы built-in imagegen, прозрачный фон.
- `assets/*.webp` — отдельные люди, напарники, аватары и пары для витрины.
- `art-processing.json` — реальные размеры и способ извлечения фигур.
- `ART_DIRECTION.md`, `generation-prompts.json` — направление и промпты.
- `qa/` — снимки desktop/mobile и результаты проверки витрины.

`process-art.py` только извлекает сгенерированные фигуры, обрезает прозрачные
поля, приводит к общему масштабу и кодирует WebP. Он не рисует детали персонажей.

## Обновление

```powershell
# Из корня; Python с Pillow
& .venv/Scripts/python.exe design-lab/mascots/pet-style-round/process-art.py
node design-lab/mascots/pet-style-round/render-references.mjs
```

Базовый CSS генерируется `sync-lab.sh`; вручную не редактировать.
Из `frontend-react/`: `npm.cmd run design-lab:sync-round -- design-lab/mascots/pet-style-round`,
затем `npm.cmd run design-lab:build-nav`.
В текущей Windows-сессии bash отсутствует в PATH; тот же прочитанный скрипт
успешно запущен через `C:/Program Files/Git/bin/bash.exe`.

Человеческое утверждение графики получено. Следующий срез — перенос серии B
в MQX/React по [DESIGN_WORKFLOW](../../../frontend-react/src/components/mqx/DESIGN_WORKFLOW.md).
По поручению «Переносим» серия B подключена в приложение 03.11.2026:
`PersonaPortrait`, `PersonaCompanion`, каталог `#/dev/mqx`. Редактируемые мастера
перенесены в `design/system/illustrations/soft-volume/`; этот раунд сохраняет
утверждённый снимок и сравнение A/B. [Область внедрения](../APPROVED.md).

Ограничения: это статические иллюстрации, не анимационный набор. В React
внедрены портреты и компонент напарника; поток знакомства/O3 сохраняется.
Уровень детализации мелких предметов и возрастная
выразительность лиц остаются предметом человеческого выбора. Существующие
параллельные изменения в приложениях и AI-конфигурации сохранены.
