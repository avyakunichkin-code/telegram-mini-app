# Нативный опрос · уточнение трёх шагов · 05.11.2026

Владелец уточнил: сохранить три экрана, увеличив число вопросов внутри
каждого. Предыдущая разбивка на пять шагов неверно трактовала поручение.
Трёхшаговый lab утверждён ответом владельца «Отлично» и перенесён в MQX.

1. Деньги и подушка — четыре вопроса: зарплата, счёт/подушка, переводы, запас.
2. Завершение хода — три вопроса: списания, итоги, затруднения.
3. Впечатления и отзыв — сложность, желание продолжить и необязательный текст.

Девять существующих вопросов сохранены. Новых API-полей нет. Ответы и текст
сохраняются при возврате и ошибке. Данные синтетические; API не вызывается.

Вопросы копируются из production в survey-questions.js через sync-lab.sh.
Группировка также берётся из production через three-step-layout.js.
lab-base.css генерируется; вручную не редактировать.

Компактнее только отступы; области нажатия не меньше 44 px. На узком экране
подписи сложности занимают три равные колонки. При клавиатуре/увеличении шрифта
прокрутка остаётся доступной.

`node verify.mjs`: exit 0, 30 проверок — три шага, sending/error на последнем,
360×640, 390×744 и desktop, light/dark; без внутренней прокрутки/переполнения.
Возврат с отзывом, сохранённые ответы, ошибка/повтор/успех проверены.
Скриншоты qa/hybrid-step-1.png … hybrid-step-3.png, JSON в qa/.
