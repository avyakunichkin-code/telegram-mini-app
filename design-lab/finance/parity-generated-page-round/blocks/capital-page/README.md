# screens-round — раунд 4: стиль ★ BG-1 на остальных экранах

Раунд 4 направления [ADR-014](../../../docs/decisions/ADR-014-brand-direction-board-game.md). Дашборд ★ BG-1 уже в prod ([`../APPROVED.md`](../APPROVED.md)); здесь — те же токены, шрифты (Nunito + Manrope) и правила на всех остальных экранах. Статус: **★ утверждено 2026-10-15** (в чате: «замечаний нет», перенос в prod по группам экранов); замечания после игры — следующими итерациями.

Одна партия на всех экранах: Студент, 12-й ход, на счёте 87 400 ₽, подушка 45 000 ₽, вклад 120 000 ₽ (+2 400 за ход), ОФЗ 50 000 ₽ (+500), потребкредит 180 000 ₽ (−9 000 за ход). Доходы 65 400, расходы 46 500, остаётся 18 900.

## Экраны

| Экран | Идея | Что изменилось относительно prod |
|-------|------|----------------------------------|
| Капитал · Детали | Имущество как карточки собственности: цветная полоса по типу (золото — вложения, изумруд — имущество, фиолетовый — страховки, красный — только долги). Итог хода под потоками | Канон «Детали \| Действия» v2 сохранён; убраны КАПС-лейблы «ДОХОДЫ/РАСХОДЫ», добавлен итог хода |
| Капитал · Действия | Фишки 3 в ряд по группам «Вложить / Купить / Занять». Закрытые механики — пунктир и «откроется по цели» (`mechanics_unlock`) | Эмодзи → значки в плитке цвета группы; закрытое видно, а не спрятано |
| Аналитика | Сначала вывод (состояние с полосой риска), потом: куда уходит доход, 3 показателя устойчивости, история + прогноз, совет Монетки одной строкой | Убраны «АНАЛИТИКА / ХОД #1», «Runway», «ПДН» → понятные подписи |
| Меню | Карта текущего сохранения с «Продолжить игру»; остальное — спокойные кнопки | Убраны служебные тексты («в том же каркасе, что вкладки игры») |
| Событие | Карта из колоды «2 события»: полоса домена, заголовок, пузырь Монетки, выборы с чипами последствий | Канон L3 сохранён; без XP; последствия — чипами (деньги, потребности) |
| Вход | Логотип + спокойная форма, одна главная кнопка | — |
| Выбор жизни | Карточки персонажей как выбор фишки; кнопка называет действие («Начать за Студента») | Шаг «Игра / План» убран (ADR-013) |
| Финал · Победа | Золотая клетка финиша с персонажем; «Играть дальше» главная кнопка | «Закрыть месяц» → «Завершить ход» |
| Финал · Поражение | Факт риска красным, два совета, отзыв; архив | То же |

Таббар — светлая поверхность через токены в обеих темах (в prod сейчас белый в тёмной теме), активная вкладка — фиолетовая фишка. Иконки вкладок в макете — заглушки, в prod остаются текущие.

## Запуск

```

```
