# Композиция карты хода · варианты

REVIEW. Владелец предложил улучшить компоновку после встраивания логотипа. Текущий production и предыдущие варианты сохранены.

А — собранная настолка; Б — баланс и действие; В — личный счёт. Одинаковые данные из скриншота: Студент, ход 6, счёт 63 413, списание 37 500, остаток 27 247 рублей. Логотип G1 без перерисовки. Полный вариант реализации будет использовать текущие DTO и обработчики.

Состояния: обычный, крупные суммы/длинная роль, минус, загрузка, ошибка прогноза, выполнение. Локальные ./ ресурсы, шрифты из источника системы. lab-base.css генерируется sync.mjs. До выбора человеком production не меняется.

Предпочтение автора: Б — проще иерархия, баланс получает собственную область, кнопка и прогноз не конкурируют в тесной нижней строке. А — меньше изменений и близость к текущему виду. В — меньше игровых акцентов.

Следующий раунд: добавлен **Г · По эскизу владельца** (логотип слева, жетон хода рядом, роль и небольшой персонаж справа, подпись и баланс ниже, кнопка на всю ширину, прогноз по нижнему краю). Предыдущие А/Б/В сохранены для сравнения. Production этим раундом не изменён.

Уточнение Г: сумма сдвинута ближе к подписи, маскот увеличен до 62×105 px (на 320px — 52×94). Его область перекрывает только свободное пространство справа от баланса, не кнопку. Проверяются длинная роль и крупная сумма.
