# ТВОЙ ПЛАН — лендинг, итерация 02

Статус: вариант **A** утверждён владельцем продукта 2026-10-30 и опубликован через GitHub Pages. Подтверждение — [APPROVED.md](./APPROVED.md), результаты — [DEPLOYMENT.md](./DEPLOYMENT.md). Зарегистрированный черновик Sites не публиковался.

- A (`dist/index.html?variant=a`): сначала обещание и бенто-обзор, затем вопросы и функции.
- B (`dist/index.html?variant=b`): сначала вопрос посетителя, затем голубой hero и обзор возможностей.

Данные и содержание одинаковые. Источники: `apps/plan-web/src/styles.css`, `apps/plan-web/src/screens/Start.jsx`, `docs/plan/specs/SPEC_plan-v1.md`. Используется собственная система Plan «Бенто», не игровая MQX. Суммы вымышленные. Регистрации, сбора данных и подключения API нет. Шрифты Onest/Unbounded загружаются из Google Fonts; при недоступности используются системные.

Просмотр из корня проекта (Windows): `& .venv/Scripts/python.exe -m http.server 4178 --directory design-lab/plan-landing/round-01/dist --bind 127.0.0.1`.

Итерация 02 дорабатывает оба варианта на месте. Добавлены пример структуры отчёта на вымышленных данных, четвёртый стресс-сценарий, общий вопрос, точность данных и история чекапов. Цвета сверены с предварительными правилами прототипа: кредиты 20 % — зелёный, подушка 4 месяца при целевых 6 — жёлтый. Декоративный график в hero заменён проверяемой разбивкой бюджета. Вариант B переставляет DOM-блок, сохраняя визуальный и клавиатурный порядок.

Оценка и источники: [REVIEW.md](./REVIEW.md). Варианты публикации: [GITHUB_PAGES.md](./GITHUB_PAGES.md).

Чистый выпуск находится в `sites/tvoy-plan-landing/` и отдельном GitHub-репозитории. Lab сохраняет оба варианта для истории; его dist не является источником автоматического деплоя. Обновлять опубликованный сайт следует через отдельный репозиторий выпуска.
