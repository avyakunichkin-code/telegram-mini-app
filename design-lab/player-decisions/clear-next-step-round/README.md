## Реальные данные и контракт

Все данные синтетические: Entrepreneur,ход8,зарплата200 000 ₽,
cash260 000 ₽,расходы180 000 ₽,подушка900 000 ₽,цель6×=1 080 000 ₽.
Не хватает180 000 ₽; после резерва расходов можно внести80 000 ₽,
после этого до цели100 000 ₽. Это максимум по текущим расходам, не гарантия
достаточности денег на будущие события; игрок вводит и подтверждает сумму в окне.

Events: реальные family_vacation_offer/B3,четыре выбора из YAML.
Кредит:0сейчас,N+3выписка75%salary или40%+45%(ещёN+3),не выдавать за бесплатный
отпуск. Ранняя бронь:0сейчас,через3хода поездка55%salary при согласии.
Короткий отдых12%salary сразу. ≈суммы при нынешней зарплате, не fixed-price promise.
API choices.impacts сохраняет текущие эффекты/term; additive future_payments v1
строит ограниченный read-only граф условных cash-последствий из каталога.
Контракт и границы — [SPEC_player-decisions](../../../docs/game/specs/features/SPEC_player-decisions.md).
Неизвестное динамическое продолжение явно помечается incomplete;
нет hardcode по definition_key на фронтенде и парсинга русского description.
Нельзя обещать точный заранее выбранный вариант будущей выписки.
Макет не изменяет YAML/стоимость/семантику existing saves.

Goal: victory.current_goal_key/detail/progress и outflow/cash доступны.
Контракт для целей других типов должен строить действие по goal.type и
mechanics permissions; unsupported goal получает текст без выдуманного CTA.
Сумма пересчитывается при открытии/отправке окна, а не доверяется старому макету.

Needs: needs_meta.periods_to_zero_if_idle — прогноз **без новых действий**,
не точный next-close. level/wear/level_sources и treat_self доступны.
Статус6,пример около1хода до нуля. Quiet eveningcost16 000 ₽,effective status≈+7 —
синтетический предпросмотр; фактическиеeffects брать из API,treat_self.options.
При cooldown кнопка недоступна, показан срок3хода; появление нужных событий
не гарантируется. Zero-streak/end conditions не выводить из произвольной needs6.
При отсутствии прогноза не вычислять результат закрытия на фронтенде на глаз.
