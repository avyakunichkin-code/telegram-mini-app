# Первое вложение · компактный A · утверждено и внедрено локально

Поручение: «Капитал: понятнее первый вклад и покупка». Владелец выбрал A,
попросил сохранить окно снизу, затем убрать подробные расчёты. Компактный
макет утверждён ответом «Отлично»: [запись выбора](APPROVED.md).
Этот README описывает финальный canon; подробное оформление отклонено.

## Текущий вариант

В пустых «Вложениях» две отдельные кнопки: «Открыть вклад» и «Купить облигации».
Каждая открывает соответствующий продукт в привычном окне снизу.
Название и ставка, ввод суммы, три пресета, счёт сейчас, одна строка остатка,
кнопка операции. Декоративная шапка, денежный маршрут, подробный чек и
прогноз начислений из формы убраны. Обычная форма ≤400 px.

Предупреждение появляется только при недостатке денег либо остатке ниже
расходов. Расходы не ограничивают максимально разрешённую сумму вложения:
это подсказка, не новое правило экономики. Подушка остаётся отдельно.
Ошибка POST сохраняет сумму. Отправка блокирует повтор и закрытие.

Bottom sheet: fixed снизу, scrim, прокрутка содержимого при необходимости,
видимая кнопка операции, Escape/крестик, focus trap/restore и reduced motion.
Изменение суммы не запускает анимацию заново. После успешной покупки —
«Детали» с позицией и фокусом на вкладке. Если подтверждённый POST выполнен,
а overview или positions не загрузились, существующий MqxStateError
«Покупка выполнена» предлагает обновить только GET. Старые данные и операции
скрыты до синхронизации, ложный пустой портфель не показывается.

## История раунда

A — два прямых действия; B — промежуточный экран сравнения. B архивирован.
Первое большое окно со ставкой-печатью и подробным чеком отклонено владельцем.
Его 84 проверки и скриншоты qa/a-* и qa/b-* — историческое свидетельство,
не финальная проверка компактного layout. verify.mjs сохраняется для сценариев
состояний/покупки; актуальная проверка размера и механики — verify-sheet.mjs.
