# board-game — направление «настольная игра про деньги»

Тема lab для [ADR-014](../../docs/decisions/ADR-014-brand-direction-board-game.md). Здесь проверяем, как метафора настольной игры ложится на реальные экраны, до любых правок в `mqx/` и prod.

## Что внутри

| Путь | Что это |
|------|---------|
| `styles.css` | Общие токены направления: поле, ход (фиолетовый), монета (Coin Gold), рост/риск; пары шрифтов `data-font`; материалы `.bg-coin`, `.bg-cell`, `.bg-action` |
| `direction-round/` | Раунд 1: три варианта верха дашборда + выбор пары шрифтов. **Superseded**: ходов не 12, нужно легче; выбран шрифт F3 |
| `logic-round/` | Раунд 2: дашборд на реальной логике (бесконечные ходы, путь = шаги цели), облегчённый, F3. **Superseded**: выбран гибрид A + шапка B |
| `hybrid-round/` | Раунд 3: компактность A, карта хода B, цель свёрнута; варианты — место Студента и Монетки |

## Роли цвета (ADR-014)

- **Фиолетовый** — только то, что игрок делает (ход, главная кнопка, фишка).
- **Coin Gold** — деньги и награды (монеты, цель). **Новый токен**: в prod появится только токенами v2 после ★.
- **Изумруд** — плюс/рост. **Красный** — только риск.

## Запуск

```bash
cd design-lab && npx serve .
```

Хаб → «Примитивы и бренд» → «Настольная игра ★ BG-1».

После правок `board-game/styles.css` пересобрать раунд:

```bash
cd design-lab/board-game/hybrid-round && ./sync-lab.sh
cd ../logic-round && ./sync-lab.sh
cd ../direction-round && ./sync-lab.sh
```

Статус: **★ утверждено 2026-10-14** — канон в [`APPROVED.md`](APPROVED.md), раунд `hybrid-round/`. В prod не перенесено. Решено: метафора — да, шрифт — F3 Nunito + Manrope, дизайн — лёгкий; раскладка — компактная A, шапка-карта B, «Завершить ход» сверху, «2 события» крупно, цель свёрнута.
