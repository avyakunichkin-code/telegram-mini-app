# Board game — утверждено ★ (концепция дашборда)

**Утверждено:** 2026-10-14, в чате («утверждаем»). **Направление:** [ADR-014](../../docs/decisions/ADR-014-brand-direction-board-game.md).
**Канон-раунд:** [`hybrid-round/`](hybrid-round/) — экран в двух состояниях (цель свёрнута / раскрыта). Раунды `direction-round/` и `logic-round/` — история, не канон.

Статус: **перенесено в prod 2026-10-14** (`DashboardPremium`, токены v2, шрифт F3 self-host). Канон prod-дашборда — [`../dashboard/APPROVED.md`](../dashboard/APPROVED.md), prod parity — [`../dashboard/bg1-page-round/`](../dashboard/bg1-page-round/). Расхождение: движок победы отдаёт `min_period_index = 1`, поэтому в prod финиш без «с 7-го хода».

## Порядок блоков

1. **Карта хода** (сверху): роль слева («Студент»), «Твой ход»; номер хода в правом верхнем углу (без «из N» — ходов не ограничено).
2. Внутри карты: **«2 события»** — крупная нажимаемая плашка с колодой → **Монетка одной строкой** (самое срочное) → **«Завершить ход»** (компактная кнопка).
3. **Потребности** — 4 тонкие шкалы 2×2.
4. **Деньги**: Студент рядом с суммой «На счёте»; ниже подушка, зарплата за ход, расходы за ход.
5. **Цель** — свёрнута: «Цель, шаг N из M» + дорожка точек без подписей + золотой финиш; раскрыта: список шагов цепочки победы, без Монетки.
6. **Действия хода** — 4 кнопки; «Зарплата» подсвечена золотом, пока не забрана.

## Инварианты

- Шрифт: **Nunito** (заголовки, 800–900) + **Manrope** (текст) — F3.
- Лёгкий стиль: края 1.5px, объём (нижняя тень) только у нажимаемого — кнопки, фишки, монеты; без сплошных заливок клеток.
- Роли цвета ADR-014: фиолетовый — действие, Coin Gold — деньги/награды/финиш, изумруд — плюс, красный — только риск.
- Путь на поле = шаги цели (`victory_config_json`), не счётчик ходов; финиш открывается с `min_period_index_for_victory`, после победы игра продолжается.
- **Токены (2026-10-26, аудит 2026-10-25 п. 6–8):** legacy `--mq-violet / -deep / --mq-emerald / --mq-danger / --mq-ink / --mq-line` — алиасы v2 (`--mq-turn`, `--mq-gain`, `--mq-risk`, `--mq-board-ink`, `--mq-cell-edge`) и следуют тёмной теме; `--mq-warning` #b45309 (контраст текста ≥ 4.5:1). Движение — `--mq-dur-press/fast/base/slow/scene` (80/150/250/350/500 мс) и `--mq-ease-standard/enter/exit/reward`; `prefers-reduced-motion` — глобально в `tokens.css`.
- **Стилевой долг в `styles/mqx` только убывает:** новые HEX/rgba (кроме запасного `var(--tg-theme-*, #…)`) и шрифты < 12 px запрещены (`check:style-discipline`), счётчики по файлам — `check:mqx-ratchet` (`frontend-react/scripts/mqx-style-ratchet.json`). Подъём шрифтов до 12 px и сокращение палитры — отдельным раундом lab.

## ★ BG-3 — дашборд: одна рамка на уровень (2026-10-25)

**Канон-раунд:** [`frames-round/`](frames-round/) — вариант **E · Итог** (`index.html#e`). Утверждено в чате 2026-10-25 («Утверждаю Е»). Уточняет BG-1 для главной; остальные варианты раунда («Было», A, D) — история, вариант B («одна панель») отклонён. **Перенесено в prod 2026-10-26** — главная (`DashboardPremium`), «Капитал · Действия», «Аналитика» (см. ниже).

Порядок блоков BG-1 не меняется. Меняется то, чем отделены уровни:

1. **Карта хода** — единственный блок с краем на экране (край и кромка `--turn`). Плашка «2 события» внутри — заливка `--turn-soft` без своей рамки.
2. **Потребности, деньги, цель** — без рамок, прямо на поле; группу держат заголовок секции и отступ.
3. **Деньги:** «На счёте» крупно → **«Доходы за ход»** (сумма всех источников дохода: зарплата + доход с вложений и имущества) и **«Расходы за ход»** рядом → «Подушка». Отдельной строки «Зарплата за ход» нет — сумма зарплаты показана на её кнопке.
4. **Действия хода — залитые фишки:**
   - «Зарплата», пока не забрана, — главная кнопка: золотая заливка `--coin` на всю ширину, монета слева, сумма справа, кромка `--coin-rim`. После выплаты — спокойная пунктирная строка «Зарплата получена ✓».
   - «В подушку» (+), «Из подушки» (−), «Вложить» (изогнутая растущая стрелка) — ряд из трёх: заливка `--turn-soft`, кромка `--turn`, иконка без плашки цвета `--turn`, подпись `--ink`.
5. **Монета с ₽** — как Монетка: золотое лицо, фиолетовое кольцо `--turn`, тонкий золотой обод, толщина ребра снизу.

Инварианты BG-3:

- Одна рамка на уровень: вложенный элемент не повторяет приём родителя (рамка / заливка / кромка / отступ).
- Иконки — без плашек; плашка только у иконки-объекта (монета, клетка).
- Объём (нижняя кромка) — только у нажимаемого.

Решено при переносе (2026-10-26): «Доходы за ход» — плановый доход хода `total_monthly_income` из `GET /api/finance/overview` (зарплата + доход с вложений), та же сумма, что «Доходы за ход» в «Капитале»; до выплаты зарплаты включает её.

### BG-3 в prod (2026-10-26)

- **Главная:** как вариант E. В prod сохранена плотность 2026-10-15: деньги — три колонки в ряд (Доходы → Расходы → Подушка). Ячейки дохода и расхода ведут в потоки «Капитала» — без рамки у подписи стрелка `›`.
- **Капитал · Действия:** фишки покупок — заливка клетки и нижняя кромка, без контура; иконка без плашки, цвет — тон раздела (золото, фиолетовый, изумруд, красный). Закрытые — пунктир. Потоки «Доходы / Расходы за ход» остались клетками с краем: они раскрываются по нажатию.
- **Аналитика (по инвариантам BG-3, отдельного lab-раунда не было):** «Счёт и подушка» — единственная клетка с краем; цветная полоса слева снята — риск показывают пилюля и красная сумма. «Куда уходит доход», три показателя и график — без рамок, на поле; отступ между секциями 16px. У фишки номера хода снята кромка (она не нажимается).

Решено в чате 2026-10-26 («Оставляем как есть»): требование плотности 2026-10-15 «главная целиком на 360×640» **снято**. На 360×640 главная с BG-3 прокручивается (≈110px — ряд «В подушку / Из подушки / Вложить» ниже таббара); на 390×844 помещается целиком.
