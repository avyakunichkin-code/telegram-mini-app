# direction-round — верх дашборда в метафоре настольной игры

Раунд 1 направления [ADR-014](../../../docs/decisions/ADR-014-brand-direction-board-game.md). Одинаковые данные во всех вариантах: Студент, ход 4 из 12, на счёте 87 400 ₽, зарплата +62 500 ₽, расходы на жизнь −37 500 ₽, подушка 45 000 из 112 500 ₽, 2 события.

## Варианты

| | Идея | Главный объект |
|---|------|----------------|
| **A. Трек** | Год — дорожка из 12 клеток, фишка на текущем ходе, финиш — золотая клетка цели | Поле: прогресс партии читается раньше денег |
| **B. Карта хода** | Ход — карта в руке: номер в углу, деньги стопкой монет, события — колода рядом | Одна крупная карта вместо hero |
| **C. Поле** | Участки, как карточки собственности: цветная полоса называет тип денег; цель — широкий золотой участок | Сетка участков; ход — тонкая полоса |

Во всех вариантах главная кнопка — «Завершить ход» (объёмная фишка, фиолетовая).

## Пары шрифтов (переключатель на странице)

| | Заголовки | Текст | Характер |
|---|-----------|-------|----------|
| F1 | Unbounded 800 | Golos Text | Широкий «игровой» гротеск + спокойный русский текстовый |
| F2 | Rubik 800 | Rubik | Одна семья, мягкие скругления, проще всего в prod |
| F3 | Nunito 900 | Manrope | Самый «игрушечный», круглый |

В lab шрифты грузятся с Google Fonts; для prod — self-host (решение ADR-014 о webfont в PWA).

## Что выбрать

1. Вариант (A / B / C или гибрид, например «трек из A + карта из B»).
2. Пару шрифтов.
3. Тёмная тема — проверить переключателем.
