# neobrutal-a-round — вариант A «Чернильный край» на экранах партии

Раунд 2 эксперимента с необрутализмом. В [`../neobrutal-round/`](../neobrutal-round/README.md) выбран **A** (2026-10-28, в чате: «Развить A»). Здесь A разложен на экраны из ★ BG-2 (`screens-round`) — состав и копирайт те же.

Одна партия на всех экранах: Студент, ход 12, на счёте 87 400 ₽, подушка 45 000 ₽, вклад 120 000 ₽ (+2 400 за ход), ОФЗ 50 000 ₽ (+500), потребкредит 180 000 ₽ (−9 000 за ход). Доходы 65 400, расходы 46 500, остаётся 18 900.

## Правило A

| Что | Как выглядит |
|-----|--------------|
| Нажимается (фишка, кнопка, выбор, «Закрыть / Продать / Погасить») | Чернильный край + жёсткая чернильная тень; при нажатии фишка вдавливается в поле |
| Главная карта экрана — одна на экран | Чернильный край + **цветная** тень: фиолетовая у карты хода и события, золотая у финиша |
| Всё остальное (плитки денег, лоты, итог хода, факт поражения) | Только чернильный край, без тени |
| Закрытое | Пунктир, без тени, «Откроется на шаге 4» |
| Внутри карточки (разделители строк) | Тонкая линия `--mq-cell-edge`, а не чернила — чтобы не было «матрёшки» рамок |
| Фишка внутри карты с рамкой | Без обводки: заливка + жёсткая тень. Рамка — одна на уровень (BG-3) |
| Сегмент | Две кнопки одним блоком: общая рамка и тень, прямой чернильный шов посередине, без подложки; активная половина — заливка `--mq-turn` |

## Карта хода — компактная (итерация 2026-10-28)

Отзыв: блок громоздкий, рамка в рамке в рамке (карта → фишки → бейдж номера и колода). Переключатель «Карта хода» в шапке:

| Вариант | Что | Высота на 375 px |
|---------|-----|------------------|
| Было | Как в раунде 1 | ≈300 px |
| **K1 · одна рамка** | Та же структура; рамка только у карты, «2 события» и «Завершить ход» — заливки с тенью без обводки, номер хода — текст «ход 12» без бейджа, заголовок 20 px, плотнее отступы | ≈220 px |
| **K2 · в две строки** | Как K1, плюс: подсказка Монетки — подзаголовком, «2 события» и «Завершить ход» — рядом в одной строке; «Студент» и «ждут решения» убраны (персонаж — в блоке денег) | ≈146 px |

**Выбран K1** (2026-10-28, в чате: «K1») — по умолчанию на странице; «Было» и K2 остаются в переключателе для сравнения.

Сегмент «Детали \| Действия» переделан по отзыву: без подложки, две кнопки единым блоком с прямым вертикальным соединением.

Чипы события («Техника», «Непредвиденное») — по отзыву без обводки, выделены фоном `--mq-turn-soft` с текстом `--mq-turn-ink`; полоса над заголовком — цвет карты, иначе фиолетовый чип теряется на фиолетовой подложке. Реплика Монетки в событии — тоже без обводки, только фон `--mq-coin-soft`: внутри карты события больше нет вложенных рамок.

## Экраны

| Экран | Что нового относительно раунда 1 |
|-------|----------------------------------|
| Главная, Событие | Те же, что A в раунде 1, на данных хода 12 |
| Капитал · Детали | Потоки — плитки, итог хода — плашка роста. Сегмент «Детали \| Действия»: активный — фиолетовая фишка. Лоты — карточки собственности с цветной полосой сверху (золото — вложения, красный — долги, изумруд — имущество); действия в строке — маленькие фишки |
| Капитал · Действия | Фишки 3 в ряд, значок без плашки в цвете группы; закрытые — пунктир |
| Финал · Победа | Золотая клетка финиша с цветной тенью, появляется с overshoot (`--mq-ease-reward`, без анимации при `prefers-reduced-motion`); итоги — плитки; «Играть дальше» — главная |
| Финал · Поражение | Клетка нейтральная, без тени; факт риска на `--mq-risk-soft` с чернильным краем; советы — список с золотыми маркерами |

Интерактив: зарплата (счёт растёт, кнопка уходит в «Получена»), выбор в событии, переключение сегмента, светлая и тёмная тема.

## Что понадобится при утверждении

Токены v4: толщина чернильного края, цвет края и тени (в тёмной теме — `--mq-board-ink-faint`), смещение тени для фишки (3px) и маленькой фишки (2px). Правило «цветная тень — одна главная карта на экран» — в брендбук рядом с «одним доминирующим фиолетовым блоком». Перенос в prod — только после ★ в чате, через `mqx/`.

cd design-lab/board-game/neobrutal-a-round && ./sync-lab.sh
