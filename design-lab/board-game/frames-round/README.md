# frames-round — одна рамка на уровень

Раунд по проблеме «матрёшки рамок»: блок с краем → внутри фишки с краем → внутри плашки иконок. Один и тот же канон ★ BG-1 (главная) и ★ BG-2 («Капитал · Действия») в вариантах «Было», A, D и итоговом E; содержимое одинаковое, меняется только то, чем отделены уровни.

| Вариант | Блок | Кнопка | Иконка |
|---------|------|--------|--------|
| Было | край | край + кромка | плашка |
| A · Фишки на поле | ничего (отступ + заголовок) | заливка + кромка | голая; зарплата — монета |
| D · Рамка = нажимается | ничего; карта хода — заливка | фиолетовый контур + кромка | голая, цвет действия |
| **E · Итог** | карта хода из A (единственная с краем), остальное на поле | залитые фишки: зарплата — золотая главная на всю ширину с суммой, «В подушку» / «Из подушки» / «Вложить» — фиолетовая заливка `--turn-soft` + кромка `--turn` | голая, `--turn`; «Вложить» — растущая изогнутая стрелка |

Заголовки секций («Потребности», «Действия хода») добавлены во все варианты, включая «Было», — без рамок группу держит заголовок.

Отзыв 2026-10-25: верхний блок — из A (он главный и может быть уникальным); вариант B «одна панель» отклонён и убран из раунда; ключевые — действия хода, им нужна заливка, зарплата — как основная кнопка. Подписи действий: «В подушку», «Из подушки», «Вложить» (снимает открытый вопрос BG-1 про «Пополнить / Снять»).

В E есть переключатель состояния зарплаты: «не забрана» — золотая главная кнопка; «забрана» — спокойная пунктирная строка «Зарплата получена ✓».

Статус: **★ BG-3 утверждено 2026-10-25 — вариант E** (канон: [`../APPROVED.md`](../APPROVED.md)). В prod не перенесено. После утверждения: в деньгах «Зарплата за ход» заменена на «Доходы за ход» (все источники) рядом с «Расходы за ход»; монета с ₽ на кнопке зарплаты — как Монетка (фиолетовое кольцо). Ссылка сразу на вариант: `index.html#e`, `#a`, `#d`, `#base`.

```bash
cd design-lab && npx serve .
```

```bash
cd design-lab/board-game/frames-round && ./sync-lab.sh
```
