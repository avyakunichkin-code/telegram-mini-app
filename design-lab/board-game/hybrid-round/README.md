# hybrid-round — раунд 3: гибрид A + B

Раунд 3 направления [ADR-014](../../../docs/decisions/ADR-014-brand-direction-board-game.md). Собран по отзыву на раунд 2 (`../logic-round/`):

- компактность — из A;
- шапка — карта хода из B; «Завершить ход» сверху и чуть меньше;
- «2 события» — второе по важности: крупно, сразу под шапкой, нажимается;
- цели — формулировки из B, но свёрнуты до дорожки без подписей («шаг 3 из 5»); по нажатию раскрываются в тропинку со всеми шагами;
- шкалы потребностей — как в раунде 2;
- Студент и Монетка остаются; их место ещё ищем — это и есть разница между вариантами.

Логика игры та же, что в раунде 2: ходов сколько угодно, путь = шаги цели, финиш с 7-го хода, после победы игра продолжается. Шрифт F3 Nunito + Manrope. Данные те же.

## Итог раунда — ★ утверждено 2026-10-14 (канон: [`../APPROVED.md`](../APPROVED.md))

Отзыв на три варианта расстановки персонажей сведён в один экран (показан дважды: цель свёрнута / раскрыта):

1. Слева сверху — роль игрока («Студент»), под ней «Твой ход».
2. Номер хода — в правом верхнем углу карты.
3. Монетка одной строкой разделяет «2 события» и «Завершить ход».
4. Студент — рядом с суммой на счёте (из варианта 3).
5. Подписи «Пополнить» и «Снять» непонятны — **отдельная задача после утверждения концепции**.
6. Цель: свёрнута — дорожка без подписей; раскрыта — список шагов без Монетки.
