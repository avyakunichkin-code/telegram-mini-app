## Воспроизведение

1. Собрать frontend и запустить Vite на 5176.
2. Из корня: `node design-lab/board-game/ink-refinement-round/render-reference.mjs`.
3. Открыть раунд на сервере design-lab. `node verify.mjs` из раунда — browser QA.

`runtime.css`, `reference.js`, `reference-provenance.json`, `assets/runtime/` — снимок,
полученный генератором из frontend, без ручной перерисовки. Генератор использует
только синтетические API-заглушки. `styles.css` оформляет lab и точечные отличия A/B/C.
`lab-base.css` по-прежнему обновляется только sync-lab.sh, ручных правок нет.

Техническая правка 04.11.2026: архивный index.html подключает существующий
`./lab-base.css`, как требует общий checker self-contained раундов. Перенаправление
на действующий канон и решение оставить текущий вид сохранены. Полный
`npm run check:guardrails` из frontend-react после правки — exit 0, 43 раунда.

Проверка 04.11.2026: 24 сочетания ширины/темы/состояния × 4 экрана, четыре потребности,
нативная ink-рамка, уникальные ID, disabled и обратная связь, без JS/HTTP ошибок и
горизонтального overflow. Скриншоты и verification.json — в qa/.

Уточнение 04.11.2026: потребности — тонкие шкалы 6 px без обводки и чернильного
ребра заполнения. Исправлено в source runtime и повторно выгружено в этот lab.
Регрессия проверяется по computed styles в React и во всех четырёх макетах.
