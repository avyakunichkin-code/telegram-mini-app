# logic-round — раунд 2: дашборд на реальной логике игры

Раунд 2 направления [ADR-014](../../../docs/decisions/ADR-014-brand-direction-board-game.md). Отзыв на раунд 1 (`../direction-round/`): стиль нравится, но ходов в игре не 12, а сколько угодно, и дизайн нужен легче. Шрифт выбран — **F3 Nunito + Manrope**.

## Что взято из логики игры

| Факт | Источник | Как показано |
|------|----------|--------------|
| Ходы не ограничены, после победы игра продолжается | `SPEC_victory-v2` (F1), `game/period.py` | Номер хода — счётчик на фишке, без «из N» |
| Финиш — цепочка шагов цели, победа не раньше 7-го хода | `victory/seeds.py` (`_BASIC_TUTORIAL_CHAIN`), `min_period_index_for_victory` | Путь на поле = 5 шагов цели + золотой финиш |
| Зарплата только по кнопке | CLAUDE.md, core loop | Действие «Зарплата» подсвечено золотом, пока не забрана |
| 2 события за ход | ADR-008 | Плашка/колода «2 события» |
| Поражение: 3 хода с минусом на счёте или с потребностью на нуле | `_apply_cash_streak`, `_apply_needs_decay` | Потребности на дашборде; красный остаётся только для риска (здесь риска нет) |
| Порядок блоков L3 | `dashboard/APPROVED.md` | ход → потребности → финансы 2×2 → цель → действия |

Данные во всех вариантах: Студент, ход 4, на счёте 87 400 ₽, подушка 45 000 ₽, зарплата +62 500 ₽ (ещё не забрана), расходы −37 500 ₽, потребности 70/45/60/80, цель — шаг 3 из 5.

## Варианты

| | Идея |
|---|------|
| **A. Путь к цели** | Горизонтальная дорожка из шагов цели, фишка на текущем шаге, под ней — что сделать сейчас. Ход — фишка-счётчик в шапке. |
| **B. Карта хода** | Ход — карта с номером в углу, колодой событий и кнопкой «Завершить ход». Цель — вертикальная тропинка со всеми шагами. |
| **C. Монеты и шаги** | Самый лёгкий: крупно деньги, потребности метками, цель — полоса из 5 сегментов. Из «настольного» — только монета и фишка хода. |

Облегчение относительно раунда 1: края 1.5px, объёмная тень только у кнопок и фишек, без сплошных фиолетовых заливок клеток.

Расхождение с prod: «Завершить ход» в A и C стоит внизу (под большой палец), а не в hero.
