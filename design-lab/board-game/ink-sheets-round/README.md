# ink-sheets-round — окна Капитала в «Чернильном крае»

Запрос 2026-10-29 (в чате, со скриншотами prod): окна «Продать?», «Страховки», «Жильё», «Кредиты» привести к стилю приложения, сначала сравнить варианты.

**Общее для всех вариантов** (решено 2026-10-29 на окне «Депозит», уже в `frontend-react/src/styles/mqx/ink.css`): у окна только чернильная линия сверху, без боковой обводки; крестик — заливка и тень, без обводки.

Данные — с тех же скриншотов (Профессионал, доходы 100 000 ₽, расходы 94 886 ₽); списки жилья сокращены до 7 позиций в трёх группах.

## Варианты (меняют содержимое окна)

| Вариант | Позиция в списке | Действие | «Продать?» |
|---------|------------------|----------|------------|
| **A · список** | Строка прямо на поле окна, тонкая линия `--mq-cell-edge` между строками; цвета группы нет — группу называет заголовок окна | Фишка со словом («Купить», «Снять», «Взять», «Оформить»): заливка + тень, без обводки | Две фишки в ряд: «Отмена» — заливка, «Продать» — красная с чернильным краем |
| **B · лоты** | Карточка собственности, как лоты на странице Капитала: чернильный край, цветная полоса сверху (изумруд — имущество, красный — долг, фиолетовый — защита) | Внутри рамки — фишка со словом без обводки (одна рамка на уровень) | «Продать» во всю ширину сверху, «Отмена» — текстом под ней |
| **C · плитки** | Плитка заливкой без края, цвет группы — полоса 4 px слева (ближе всего к нынешнему виду) | Фиолетовая «+» с чернильной тенью, без обводки | Как A, «Отмена» — в рамке ввода без тени |

Во всех вариантах исправлено то, что сломано в prod:

- заголовки групп («Потребительские», «Объект страхования») белым по светлому не видны — здесь `--mq-board-ink-soft`;
- в «Продать?» кнопка называлась «Удалить» — здесь «Продать»;
- суммы в строке подписаны словами («−15 000 ₽ за ход», «14% годовых», «12 ходов») вместо значков.

Виды страховки: в A и C — заливка без обводки, выбранный — фиолетовый; в B — фишки с краем и тенью, выбранная вдавлена.

## Запуск

```bash
cd design-lab && npx serve .
```

Хаб → «Примитивы и бренд» → «Настольная игра — окна Капитала в «Чернильном крае»». Переключатели вверху: вариант A / B / C, светлая / тёмная тема.

`lab-base.css` = `@font-face` из `frontend-react/src/styles/fonts.css` + `../neobrutal-round/tokens-v3.css` + `../neobrutal-round/styles.css`. После правок базы:

```bash
cd design-lab/board-game/ink-sheets-round && ./sync-lab.sh
```

Статус: **выбран A · список** (2026-10-29, в чате: «A · список»). В prod — слой `ink.css` (не ★, как весь «Чернильный край»):

- строки в окнах (`mqx-capital-template-row--*-h` внутри `mqx-sheet`) — без цветной полосы, тонкая линия между строками;
- `MqxRowAction` получил `verb` («Купить» / «Снять» / «Взять» / «Оформить»), подпись видна только в ink, в классическом стиле — прежний «+»;
- заголовки групп и «Объект страхования» — `--mq-board-ink-soft`, поле выбора — рамка ввода, виды страховки — заливка, выбранный — фиолетовый;
- «Продать?» (`MqxConfirmDialog`): лист с линией сверху, «Отмена» и опасное действие рядом; в тёмной теме текст на красном — цвет поля (контраст 6.7:1). Подписи кнопок по действию: «Продать», «Закрыть», «Погасить», «Отменить полис» вместо «Удалить» — для обоих стилей.

Не перенесено: подписи сумм словами («за ход», «годовых») — в prod остались значки метрик.
