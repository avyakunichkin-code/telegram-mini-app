# neobrutal-round — необрутализм в цветах игры

Эксперимент со стилем на основе дизайн-системы MQX v3 ([`docs/design/claude-design-system/`](../../../docs/design/claude-design-system/README.md)). Цвета, шрифты (Nunito + Manrope) и отступы — только из канона v3; новых hex нет. Меняется подача: чернильный край и жёсткая смещённая тень.

**Идея:** тень — это «lift» фишки из системы, доведённый до предела. Край и тень — чернилами поля `--mq-board-ink`, а не чистым чёрным. Нажатие вдавливает фишку в поле (`translate` на высоту тени за `--mq-dur-press`).

Одни и те же данные во всех вариантах — партия из ★ BG-3 (`frames-round`, вариант E): Студент, ход 4, на счёте 87 400 ₽, подушка 45 000 ₽, событие «Сломался ноутбук».

## Варианты

| Вариант | Идея | Чем расходится с каноном v3 |
|---------|------|-----------------------------|
| **A · Чернильный край** | Блоки без рамок (как BG-3); чернильный край 2px у всего видимого, жёсткая тень — только у нажимаемого. Карта хода — единственная с фиолетовой тенью | Край 2px чернилами вместо 1.5px `--mq-cell-edge`; тень диагональная вместо вертикального lift. Радиусы и «тень только у нажимаемого» сохранены |
| **B · Всё поле** | Каждая секция — клетка с тенью, радиус 8, фон экрана — сетка игрового поля. Карта хода — сплошной фиолетовый блок, «Завершить ход» — светлая фишка | Ломает «клетки без тени» и BG-3 «одна рамка на уровень»; один радиус на всё |
| **C · Плакат** | Прямые углы, номер хода 64px монетным цветом, баланс 44px, карта хода — чернильная плита, заголовки секций — чернильные ярлыки, деньги разделены линейкой | Радиус 0 вне шкалы радиусов; кегли 44/64 вне шкалы шрифтов |

Во всех вариантах работает: «Зарплата» — счёт растёт от старого значения (count-up + pop монеты, без анимации при `prefers-reduced-motion`), кнопка уходит в пунктир «Зарплата получена»; в событии выбор варианта гасит остальные до 0.5 и включает кнопку.

Тёмная тема: край и тень — `--mq-board-ink-faint` (светлые чернила на тёмном поле слепят), плита C — `--mq-cell-raised`.

## Что понадобится при утверждении

Новые токены v3 → v4: толщина чернильного края (`--mq-ink-w`), цвет края и тени (`--mq-ink-line`, `--mq-ink-drop`), смещение тени (`--mq-ink-off`). Для C — ещё правка шкал радиусов и шрифтов. Перенос в prod — только после ★ в чате, через `mqx/`.

## Запуск

```bash
cd design-lab && npx serve .
```

Хаб → «Примитивы и бренд» → «Настольная игра — необрутализм». Сразу на вариант: `index.html#a`, `#b`, `#c`.

`lab-base.css` = `@font-face` из `frontend-react/src/styles/fonts.css` (шрифты копируются в `assets/fonts/`) + `tokens-v3.css`. После правок:

```bash
cd design-lab/board-game/neobrutal-round && ./sync-lab.sh
```
