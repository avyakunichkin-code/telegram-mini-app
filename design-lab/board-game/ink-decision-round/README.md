# ink-decision-round — материал для решения PO по «Чернильному краю»

Снимок пробного периода (2026-11-02): сравнение prod в двух стилях — **ink** (тогда слой `styles/mqx/ink.css`) и **classic** (`?style=classic`). После ★ слой влит в CSS блоков, classic и переключатель сняты (PR #20) — пересъёмка этим способом больше невозможна. Экраны: Главная (ход 1, ход 3 с онбордингом и без), Капитал, Аналитика, Меню, карусель события, итог хода. Размеры 412×915 и 1440×900. Рядом на странице — что меняется, риски, что не тронуто ink-слоем, статусы раундов маскотов и вопрос PO.

**Статус:** ★ решение PO 2026-11-02 — «Чернильный край утверждаем» (после двух доработок по замечаниям; последняя правка — подпись «Нажми «Понятно»…» под кнопкой в подсказке онбординга). Канон — [`../APPROVED.md`](../APPROVED.md).

## Как сняты скриншоты

e2e-стенд (`frontend-react/playwright.config.js`: backend на SQLite :8011 + Vite :5181), временный Playwright-сценарий (в репозиторий не закоммичен). Шаги сценария:

1. Новый игрок, `/?style=<ink|classic>#/` → «Новая игра» (Студент).
2. Ход 1 по онбордингу → итог хода.
3. Ход 2 → ход 3 с событиями → карусель.
4. Онбординг снят (`PATCH /api/game/guidance {action: skip_all}`) → Главная, Капитал, Аналитика, Меню.

Кадры — JPEG, затем WebP q78 (`assets/shots/<vp>-<style>-<экран>.webp`). Процент на странице — доля пикселей (порог яркости > 24), отличающихся между стилями на одном кадре. Тема только светлая.

Чтобы переснять после правок ink, повторите сценарий (шаги выше), сохраните кадры с теми же именами и пересоберите страницу.

## Запуск

Хаб: `cd design-lab && npx serve .` → «Настольная игра — Чернильный край: материал для решения PO».

```bash
cd design-lab/board-game/ink-decision-round && ./sync-lab.sh && npx serve .
```

`lab-base.css` — токены из `board-game/styles.css`; `styles.css` — вёрстка страницы.
