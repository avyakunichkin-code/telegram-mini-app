**Утверждено:** 2026-10-15, в чате («замечаний нет»; правки после игры — итерациями). **Направление:** [ADR-014](../../docs/decisions/ADR-014-brand-direction-board-game.md).
**Канон-раунд (prod parity):** [`../board-game/screens-round/`](../board-game/screens-round/) — экраны «Меню», «Вход», «Выбор жизни» и таббар. Общие инварианты BG-2 — [`../board-game/APPROVED.md`](../board-game/APPROVED.md).

Статус: **перенесено в prod 2026-10-15.** Прежние раунды этой папки (Монетка-пузырь P1–P6), [`../start-menu/`](../start-menu/), [`../auth-flow/`](../auth-flow/), [`../game-templates/`](../game-templates/) (экран шаблонов) и [`../new-game-mode/`](../new-game-mode/) — история, не канон.

## Поток

Вход → Меню (старт) → «Новая игра» → **Выбор жизни** → партия. Шага «Игра / План» нет ([ADR-013](../../docs/decisions/ADR-013-game-only-drop-plan-mode.md), GO-01). Пустой список сохранений — «Новая игра» сразу запускает партию за Студента.

## Меню (вкладка игры и стартовый экран)

1. Шапка вкладки: h1 «Меню», «Игра на паузе» (на старте вместо шапки — логотип, h1 скрыт).
2. **Карта сохранения** (`MqxSaveCard`): фиолетовая рамка с нижней тенью; портрет персонажа в круге, роль, «Ход N · на счёте X ₽», третья строка — «Цель: шаг N из M» (в партии) или название сохранения (на старте; в списке профилей нет цели). Одна главная кнопка «Продолжить игру».
3. Спокойные кнопки (`MqxBoardButton`): «Новая игра · другая жизнь», «Все сохранения · N партий».
4. Текстовая «Выйти из аккаунта».
5. «Как играть» — **нет**, пока нет экрана правил.
6. Пусто (старт, 0 сохранений): карта «Сохранений пока нет» с главной «Новая игра».
7. «Все сохранения» — шторка: строка = партия (портрет, роль, «название · ход N · итог»), «Сейчас» / «Открыть». Без бейджа режима.

## Вход / регистрация

Логотип → карточка формы (подписи «Почта», «Пароль», поля на поверхности доски, фокус — золотая обводка) → одна главная кнопка («Войти» / «Создать аккаунт») → спокойная кнопка перехода («Создать аккаунт · займёт минуту» / «Уже есть аккаунт · войти»). Без Монетки и пузыря.

## Выбор жизни

Шапка «Выбери жизнь» / «У каждой свой старт и своя цель» → радиогруппа карточек (`MqxStarterScenarioPicker`): портрет `*-pick`, роль, доход за ход (изумрудом, из строки зарплаты шаблона), стартовые условия; выбранная — фиолетовая рамка и отмеченный кружок; стрелки переключают выбор. Тап по карточке **только выбирает**. Главная кнопка называет действие: «Начать за Студента / Профессионала / Руководителя / Предпринимателя». Ниже текстовая «Назад». Название сохранения — авто («Моя игра N»), поля имени и «Быстрого старта» нет. Состояния: загрузка, ошибка сети, пусто.

## Таббар

Поверхность `--mq-cell` и край `--mq-hair` в обеих темах (не белый в тёмной), без разделителей; активная вкладка — фиолетовая фишка (`--mq-turn-soft`, текст и иконка `--mq-turn`, нижняя тень `--mq-turn`). Иконки — текущие.
