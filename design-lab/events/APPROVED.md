## Порядок блоков (сверху вниз)

1. **Затемнение** экрана игры — тёмное в обеих темах (`rgba(29, 21, 48, .62)` + лёгкий blur).
2. **Строка колоды** над картой: мини-колода (2 фиолетовые карты, как плашка «2 события» на дашборде) + «Событие N из M». Белый текст на затемнении.
3. **Карта** — вытянутая из колоды: фон `--mq-cell`, рамка 2px `--mq-turn`, радиус 20px, нижняя тень `0 4px 0 --mq-turn-deep`.
   1. **Полоса домена** (`--mq-turn-soft`): пилюли — домен (`event_domain` → русская подпись), «Страховой случай» (изумруд, пульс), «Рекомендуемое · потребность»; справа справка «?» и «×».
   2. **Заголовок** — Nunito 800, 22px, не больше 2 строк.
   3. **Пузырь Монетки** — Монетка 44px + реплика (`description`), пузырь скроллится внутри (E5-B).
   4. **Выборы** — плоские кнопки (`--mq-board`, hair-рамка, нижняя тень 2px — нажимаемое): название, описание (до 2 строк), **чипы последствий**.
4. **Стрелки** ‹ › под картой — только если событий больше одного; свайп работает как раньше.

На узком экране (< 600px) карта прижата к низу, на широком — по центру.

Зоны нажатия: «×», «?» и стрелки — не меньше 44px (визуально полоса домена остаётся тонкой). Цвет текста задаётся на панели, а не на корне оверлея: лист справки «Как читать событие» не наследует цвет тёмной темы.

## Чипы последствий

| Источник | Текст | Цвет |
|----------|-------|------|
| `impacts.cash` | `−12 000 ₽` / `+3 000 ₽` | минус — `--mq-risk`, плюс — `--mq-gain` |
| `impacts.burn` | `Расходы +1 500 ₽/ход` | рост — risk, снижение — gain |
| `impacts.safety` | `Подушка +5 000 ₽` | по знаку |
| `impacts.insurance_payout` | `Выплата +20 000 ₽` | gain |
| `impacts.coin` | `Актив 450 000 ₽` | Coin Gold (`--mq-coin-soft` / `--mq-coin-ink`) |
| `impacts.term` | подсказка сервера («Продолжение сюжета через 2 пер.») | нейтральный |
| `needs_delta` | `Комфорт −8`, `Статус +5` | падение — нейтральный, рост — изумрудный |

Логика — `components/mqx/events/eventImpactChips.js` (тест `__tests__/eventImpactChips.contract.test.js`).

## Запреты

- **Никакого XP** — ни чипов, ни подписей (механика опыта снята).
- Красный — только риск (минус денег, рост расходов). Падение потребности — не красное.
- Цвет домена не перекрашивает карту: домен — подписью в пилюле; карта всегда фиолетовая (действие).
- Нет hex в JSX; тёмная тема — только через токены `--mq-*`.
- Логика выбора и карусели (`useEventCarousel`, `onResolved`) не меняется дизайном.
