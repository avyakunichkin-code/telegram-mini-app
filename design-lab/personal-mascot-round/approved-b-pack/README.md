# Личный маскот · выбранный образ Б

08.11.2026. Самостоятельный персонаж в стиле ТВОЙ ХОД: без кепки, щетины и рюкзака. Аккуратная светло-каштановая причёска, голубые глаза, сливовый пиджак, светлая футболка, серые брюки полной длины и белые кеды.

## Файлы и применение

| Файл | Для чего |
| --- | --- |
| avatar-telegram.png | Новая аватарка Telegram и других профилей; квадрат с запасом под круглый кроп |
| pose-confident.png | Основной образ, представление автора, подпись, страница о себе |
| pose-welcome.png | Приветствие, знакомство, начало презентации |
| pose-explain.png | Объяснение, инструкция, текст или схема слева от персонажа |
| pose-think.png | Вопросы, анализ, выбор, разбор решений |
| pose-work.png | Разработка, рабочие заметки, закулисье проекта |
| pose-success.png | Запуск, достижение, благодарность, хорошая новость |
| cover-wide.png | Обложка поста, титульный слайд, баннер; заголовок добавлять слева |

Шесть поз — отдельные PNG с прозрачным фоном. Аватарка и обложка содержат фон. Размеры оригиналов указаны в manifest.json. Откройте index.html для просмотра всех файлов. Это исходная графика, не установленная аватарка и не опубликованный Telegram-стикерпак.

Не растягивать по одной оси. Для слайдов и постов вставлять PNG непосредственно поверх фона. Сохранять свободное пространство вокруг рук и головы; для аватарки использовать отдельный квадратный файл. У обложки оставлять текст в левой половине, вдали от персонажа. При продолжении серии использовать pose-confident.png как основной референс, не возвращать кепку, щетину или укороченные брюки.

Создано через imagegen с одним выбранным референсом. Все изображения просмотрены при генерации. Возможны небольшие различия формы лица и оттенков между сгенерированными позами.
