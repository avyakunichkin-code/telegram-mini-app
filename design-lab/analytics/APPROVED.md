## Порядок блоков

1. **Шапка:** «Аналитика» (h1) + «Как ты стоишь на N-м ходу»; номер хода — фишкой справа, как на дашборде. Без КАПС-лейблов и pill «Ход #N».
2. **Вывод — «Счёт и подушка»:** сумма (счёт + подушка) и одна строка про подушку в ходах расходов с ориентиром 3 хода. Полоса слева: красная + пилюля с причиной (`Подушка тонкая`, `Подушки нет`, `Долги давят`, `Траты больше дохода`, `Много долгов`, `Счёт на исходе`) — **только** когда на экране есть красное: красный показатель (п. 4) или минус за ход; иначе изумрудная полоса без пилюли. Одна база расчёта — траты за ход (`total_monthly_outflow`); без трат за ход риска нет.
3. **«Куда уходит доход»** (+ «N ₽ за ход»): полоса долей и легенда — расходы на жизнь (нейтральный), платежи по долгам (красный), содержание имущества (второй нейтральный, если > 0), «Остаётся тебе» (изумруд). Если траты больше дохода — полоса = траты, в легенде «Не хватает» красным контуром.
4. **Три показателя устойчивости** простыми словами: «подушка, ходов расходов», «хода продержится счёт» (счёт / траты за ход), «дохода на долги». Красное число — только при риске (подушка < 3, счёт < 1 хода, долги ≥ 40 %); для скринридера — «есть риск».
5. **«Счёт + подушка» — история и прогноз на 3 хода:** факт сплошной фиолетовой (до 12 закрытых ходов), прогноз пунктиром золотом, отметка «сейчас» (пунктир + точка), «≈сумма» в конце прогноза. Легенда «было / если ничего не менять». Прогноз = среднее Δ по закрытым ходам, иначе «остаётся за ход».
6. **Монетка одной строкой** (класс ★ BG-1 `mqx-bg-tip`): риск → шаг цели → ориентир подушки → «Всё устойчиво — так держать».

## Состояния

- **Нет закрытых ходов:** график — только «сейчас» и прогноз + строка «История появится, когда завершишь первый ход».
- **Нет доходов и трат:** вместо полосы — «Доходов и трат за ход пока нет — забери зарплату на «Главной»».
- **История грузится / ошибка:** «Загружаем историю…» / текст ошибки + «Повторить» (44px).

## Инварианты

- Пилюля, красные показатели и красный совет Монетки считаются из одних правил (`analyticsBoardDisplay.js`) и горят вместе.
- Сначала вывод, потом из чего он. Без служебных фраз («Снимок, потоки…», «Без событий и сделок», «Цели партии — на Главной») и терминов (Runway, ПДН, ликвидность).
- Роли цвета ADR-014: фиолетовый — факт/действие, золото — прогноз денег, изумруд — плюс, красный — только риск.
- Лёгкий стиль: ячейки `--mq-cell` + `--mq-hair`, объём только у фишки хода.
- Данные — `GET /api/finance/overview` + `GET /api/finance/analytics/timeseries`; без хардкода.
- Без переключателя горизонта 3/6/12 и графика «доходы/расходы» (сняты в BG-2).
