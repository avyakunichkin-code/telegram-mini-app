# Выбор A/B

**Текущее решение: гибрид 2 (B) «Журнал с полями» утверждён владельцем.**
Зафиксировано 2026-11-06 при внедрении; канон — ../APPROVED.md. Остальное ниже —
история поиска направления, не разрешение внедрять A/C или книжный B3.

Текущая доработка B — **B3: журнал-разворот**, а не карточная колонка B v2.
Владелец поручил переделать по концепции страниц «тогда / сейчас»; воплощение
в lab показано для финального выбора. Подробности — README. Статус review.

**A: архив карточек.** Сначала три самостоятельных карточки с вопросом, датой,
риском четырёх областей и открытием отчёта; затем сравнение. Больше места каждому
снимку, больше прокрутки.

**B: журнал.** Те же карточки в компактной колонке, сравнение рядом. Приоритет
текущей паре отчётов, при узком окне — последовательный поток без широкой таблицы.
Рекомендация: B, он продолжает компактность утверждённого билета действий.

Оба варианта используют одинаковые данные и состояния. Владелец выбрал B с
доработкой удобства и выразительности. В B v2 появились быстрые пары, заметка
о главном изменении, выделение выбранных записей и мобильное раскрытие журнала.
Для переноса обновлённого UI требуется финальное утверждение; статус review.
