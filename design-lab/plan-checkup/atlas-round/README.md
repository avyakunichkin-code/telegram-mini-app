# Финансовый атлас · адаптивный раунд 01

2026-11-07. **A1 · Карта сначала — утверждён владельцем.** После показа адаптивного раунда владелец выбрал «Вариант А1». Область утверждения и следующий срез — в [APPROVED.md](APPROVED.md). Ранее утверждённые экраны Plan остаются каноном приложения до переноса нового дизайна.

Два варианта композиции на одинаковых данных:

- **A1 · Карта сначала** — крупный редакционный заголовок, бюджет, горизонтальный маршрут к резерву, затем действия. Рекомендация для первого знакомства с разбором. На телефоне маршрут вертикальный.
- **A2 · Первый шаг сначала** — те же данные, но шаги перед картой; на десктопе карта справа, на телефоне после действий. Для пользователя, который уже знаком с разбором. DOM-порядок меняется вместе с визуальным.

Открытие: Design Lab → «ТВОЙ ПЛАН · Финансовый атлас». Локальный сервер из корня: `.venv/Scripts/python.exe -m http.server 4173 --bind 127.0.0.1 --directory design-lab`; хаб `http://127.0.0.1:4173/`.

## Состав и взаимодействия

Русские экраны с локальными шрифтами: обзор, цель резерва, три шага, подробности бюджета. Навигация ведёт к разделам одного отчёта; это не новые маршруты приложения. Форма выбора варианта/состояния в верхней серой полосе относится только к лаборатории.

Состояния: готовый отчёт, загрузка без вымышленных промежуточных сумм, недостаток данных с входом в демо, ошибка загрузки с повтором, офлайн с датой копии и заблокированными действиями, сохранение с disabled, ошибка сохранения с повтором. Чекбоксы, прогресс, раскрытие шагов, «не подходит» и возврат работают в памяти страницы. При ошибке отметка не подтверждается. Повтор применяет отложенную отметку один раз. Обновление страницы сбрасывает демо; запросов к API и хранения пользовательских данных нет.

## Данные и смысл

180 000 ₽ дохода − 135 000 ₽ расходов и платежей = 45 000 ₽ остатка в месяц (25%). Резерв 270 000 ₽ покрывает 2 месяца расходов. Цель примера 405 000 ₽ покрывает 3 месяца; разница 135 000 ₽. При пополнении по 45 000 ₽ — 3 месяца без процентов, инфляции и изменения бюджета. Это демонстрационная цель, не новый порог расчётного движка. Долги и защита не оценены без достаточных данных.

Маршрут — смысловая схема, не временной график и не прогноз доходности. Лайм — бренд и акцент, не зелёный вердикт. Нехватка резерва обозначена текстом и коричнево-янтарным статусом. Декоративные изолинии скрыты от скринридеров; основная информация остаётся текстом. Фокус, reduced-motion, forced-colors, нативные чекбоксы/details и touch targets включены в раунд.
