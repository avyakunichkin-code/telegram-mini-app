# Утверждение A · P3-11

Дата: 2026-11-07.

Решение владельца после просмотра A/B: **«Да, делаем А»**. Утверждён A «Рядом с полем»: оценка денежных данных в каждом разделе мастера, мягкое предупреждение при широком диапазоне, подсказка раздела с наибольшим вкладом неточных сумм, состояния ввода/сохранения/ошибки.

Оценка не означает достоверность прогноза; сервер остаётся источником сохранённой точности отчёта. Приоритет уточнения использует текущие веса шкалы, не новый финансовый порог. B сохранён как сравнительный вариант.

Разрешён перенос в существующий мастер Plan с сохранением порядка разделов, API и данных. В полном мастере учитываются все разделы, хотя lab демонстрирует четыре основных. Вход, семейный экран и быстрый старт не получают нового layout автоматически. Внешняя публикация и реальные данные не входят в поручение.
