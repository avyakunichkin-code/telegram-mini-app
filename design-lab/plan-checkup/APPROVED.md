# ТВОЙ ПЛАН — утверждённый канон (plan-checkup)

Дизайн-система — «Бенто» (токены — `apps/plan-web/src/styles.css`, копия для lab — `styles.css` этой папки). Не MQX игры.

## ★ Отчёт: первый экран — C2 (утверждено PO 2026-11-02)

Раунд: [`bento-round`](bento-round/README.md), вариант **C2 · C + график прогноза**. Prod: `apps/plan-web/src/screens/Report.jsx`.

Порядок блоков сверху вниз:

1. Строка-шапка: «Черновой / Итоговый разбор на {месяц}» + пилюля точности.
2. **Светофор 2×2** — четыре цветные плитки областей (Бюджет, Долги, Подушка и цели, Инвестиции и защита): одна главная цифра и подпись. На десктопе — 4 в ряд.
3. **«Деньги на счетах»** — график на 12 месяцев, две линии: «как сейчас» (сплошная) и «если хуже» (пунктир, нижние доходы и верхние расходы); ноль подписан, зона ниже нуля подсвечена; легенда с конечными суммами.
4. **Ответ на вопрос со входа** — графитовая плитка: вопрос, вердикт, главная цифра, текст; внутри — «С чего начать» (3 шага, следующий выделен жёлтым, отметки «Сделано / Не подходит»).
5. «Остаётся в месяц» и точность ввода.
6. Подробно по областям, стресс-тест, кредиты, цели, дисклеймер — как в прототипе.

Инварианты: красный — только для фактов (минус, просрочка), не для оценки людей; суммы без переноса внутри числа; на 375 px без горизонтальной прокрутки (e2e CS-11).

Отступление от spec: в `SPEC_plan-v1` (UI/UX) ответ стоял выше светофора — spec поправлен под C2 тем же решением PO.

## ★ Лозунг и вход — U1 в раскладке S4 (утверждено PO 2026-11-02)

**«ТВОЙ ПЛАН. Деньги отвечают.»** Раунд: [`bento-round`](bento-round/README.md), итерация 4, вариант U1; раскладка S4 выбрана в итерации 2. Prod: `apps/plan-web/src/screens/Auth.jsx`, подпись бренда в шапке — `App.jsx`.

Экран входа: графитовая плитка — лозунг «Деньги отвечают», подзаголовок «Вместо таблицы на сто строк — три плитки и следующий шаг.», контраст «таблица → три цветные плитки»; рядом (на телефоне — ниже) карточка входа по e-mail.

Почему U1: лозунг описывает механику продукта — человек задаёт вопрос со входа («Потянем ипотеку?»), деньги отвечают. Отклонены: «Финансы как есть» (рабочий), L2–L4, S1–S3, T1–T8, U2–U8.

## ★ Повторный чекап — R2 + G2 (утверждено PO 2026-11-02)

Раунд: [`recheck-round`](recheck-round/README.md). Prod: `apps/plan-web/src/screens/Report.jsx`, логика — `src/logic.js` (`previousCells`, `stepStatus`, `goalBar`). Данные — `report.previous` и `goals[].progress` из plan-api.

- **R2 «С прошлого раза»** — отдельная плитка сразу под «Деньги на счетах», только если есть прошлый итоговый разбор: «{месяц прошлого} → {месяц текущего}», три ячейки было → стало (подушка в мес., платежи в % дохода, остаётся в тыс. ₽/мес) и прошлые шаги со статусами «сделано / в работе / не подошло». Плитка ответа C2 не меняется.
- **G2 карточка цели** — вместо таблицы целей: название и срок, «накоплено из суммы», полоска (зелёное — сейчас, серое с риской — где были в прошлый раз), «с {месяца} +X ₽», «темп … · нужно … ₽/мес», вердикт «Успеваете / Реальный срок — …». На телефоне — во всю ширину, на десктопе — по две в ряд.

Порядок блоков отчёта (дополняет C2): … прогноз → **С прошлого раза** → ответ с шагами → остаток и точность → области → стресс-тест → кредиты → **цели (карточки)**.
