# Общие пакеты

Общий код имеет двух потребителей, но не содержит продуктовые экраны или правила.
`fincore`: stdlib/Decimal/DTO, без IO/ORM/HTTP и игровых needs/events/victory/ходов.
`platform`: инфраструктура без доменов. `api-client`: транспорт.
`ui-kit`: поведение примитивов, оформление принадлежит приложениям.

При изменении контракта проверяй обоих реальных потребителей; для UI —
[shared UI](../tests/shared-ui/README.md). Обычная задача приложения не требует
чтения документации второго продукта. Не обобщать код под будущего потребителя.
