# event-audit

Пример: «проверь весь каталог перед EVT». Не primary: «напиши новое событие».
Используй docs/templates/EVENT_CATALOG_ANALYSIS.md, .claude/skills/create-event/event-balance-rules.md §1–4/10/11, data/events/mvp11 и фактический loader/spawn. Определи scope all/persona/key; проверь free lunch/Pareto, repeat/cooldown, тематические axes, chain payout/blocks_period_end, coverage. Отчёт: ключ → факт → риск → источник → предлагаемое действие; отдели автопроверку от содержательного суждения. Ничего не исправляй в audit-режиме; handoff $event-authoring. Не объявляй старые результаты skill-test текущим доказательством.

Общие границы и готовность: [AGENTS.md](../../../AGENTS.md). Читай только источники затронутой области.
