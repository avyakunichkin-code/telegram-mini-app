# delivery

Примеры: «исправь опечатку README», «уточни идею», «сделай plan по approved spec». Не primary: новый event, экономика, новый UI.
Выбери стадию по [процессам](../../../docs/ai/CODEX-PROCESSES.md). Idea даёт one-pager/DRAFT, утверждённая идея → spec с контрактом и CS; утверждённая spec → plan со срезами; implementation выполняет согласованный срез и проверку. Исправление известного бага не требует нового эпика: воспроизведение → минимальная правка → регрессия. Handbook пересказывает код/spec для людей; старый встроенный Plan не возвращать. Для guidance/admin/release/TMA/deprecation/marketing открывай только соответствующий процесс. Не коммить, не публикуй и не меняй baseline автоматически.

Общие границы и готовность: [AGENTS.md](../../../AGENTS.md). Читай только источники затронутой области.
