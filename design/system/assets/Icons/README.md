# Icons

`FinanceMetricIcons` — обводочные иконки 24×24, концы скруглены. В коде это спрайт `frontend-react/src/assets/icons/finance-metrics-sprite.svg` с `currentColor`; здесь каждая иконка — отдельный файл с чернилами `#1d1530` (`mq-board-ink` светлой темы), потому что `<img>` не наследует цвет. В интерфейсе используй спрайт/компонент и задавай цвет через `color`.

| Файл | Значение |
|------|----------|
| `coins` | сумма, стоимость позиции |
| `trend-down` | платёж, обслуживание, списание |
| `trend-up` | доход, начисление |
| `percent` | ставка (платим — `mq-risk`, получаем — `mq-gain`) |
| `term` | срок |
| `shield` | страховка |
| `warn` | предупреждение |
| `overdue` | просрочка |
| `trash` | удалить |
| `wallet` | счёт, кошелёк |
| `goal` | цель |
| `expense` | расход |
| `flow` | поток денег |

Размеры: 16 (чип, метрика) · 20 (строка, кнопка) · 24 (таббар). Порядок в строке метрик: сумма → платёж → доход → % → срок / страховка.
