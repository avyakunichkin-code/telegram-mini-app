# Где хранится дизайн

Единственное хранилище — `design/`. Текущий набор находится в `system/`, прежняя система и растровые маскоты — в `archive/classic-v3/`.

- `illustrations/soft-volume/` — утверждённые B-мастера четырёх персонажей и напарников;
  [происхождение и генерация](illustrations/soft-volume/README.md). Растровые экспорты
  в `assets/Personas/` и `assets/Companions/*-soft-volume.*`.
- `illustrations/characters.js` — предыдущая SVG-серия для прежних lab/landing-потребителей.
- `illustrations/monetka.js`, `assets/Monetka/*.svg` — новая Монетка и Квитя. Прежних PNG в активной галерее нет.
- `assets/Logos/` — G1 с подписью, G2 и размеры. `assets/Icons/`, `fonts/`, `tokens.json`, `components/` — библиотека системы. InkEdge — текущая подача.
- `runtime-ink.css` — экспорт реального CSS приложения, не второй редактируемый источник.

SVG чиби, напарников и полной Монетки генерируются из JS. Копии JS в двух lab-раундах теперь тоже экспорты. Синхронизация из корня: `node scripts/design-assets.mjs`. Проверка без записи: та же команда с `--check`.

Реестр `design/asset-exports.json` отделяет активные источники от архивных экспортов для совместимости приложения. `frontend-react/src/assets/`, старый лендинг, брендбук и новый lab-лендинг — потребители. Обе сборки проверяют совпадение.

Приложение получает портреты B через прежние совместимые пути `character-portraits/`;
карта экспортов теперь указывает на активную систему. Напарники экспортируются в
`frontend-react/src/assets/companions/`. Генератор старых портретов пишет в архив
и не перезаписывает новую серию. Кубковые портреты финала сохраняют прежний источник.

Исторические lab-раунды и baseline сохранены как снимки. Хаб и lab-base.css не правятся вручную. [Связь текущего CSS с lab и InkEdge](CURRENT_STYLE.md).
