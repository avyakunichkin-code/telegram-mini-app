**«Чернильный край» — пробный стиль подачи, не ★.** Необрутализм в цветах игры: чернильный край и жёсткая смещённая тень вместо мягкой нижней кромки. Не новый бренд: цвета, шрифты, радиусы и отступы — те же токены v3, меняется только то, как нарисованы края и объём.

**Статус (2026-11-02):** ★, единственный стиль prod. Правила влиты в CSS блоков приложения, переключатель `?style=classic` снят. Покрыты все экраны партии: Главная, таббар, подсказка онбординга, Капитал (шапка, потоки, сегмент, лоты, фишки, листы и окна), событие, итог хода, Аналитика, Меню, финал. Экраны до партии — ★ BG-2. Инварианты — `design-lab/board-game/APPROVED.md`.

**Правило трёх видов:**

| Что | Как |
|-----|-----|
| Нажимается (фишка, кнопка, выбор, «Продать / Погасить») | Чернильный край + жёсткая чернильная тень `mq-ink-off`; при нажатии фишка вдавливается в поле на ту же величину |
| Главная карта экрана — **одна на экран** | Чернильный край + **цветная** тень: фиолетовая у карты хода и события, золотая у финиша |
| Всё остальное (плитки денег, лоты, итог хода, факт поражения) | Только чернильный край, без тени |
| Закрытое | Пунктир `mq-control-edge`, без тени, «Откроется на шаге N» |

**Внутри карты с рамкой** — без обводок (★ BG-3 «одна рамка на уровень»): фишка — заливка + тень `th-ink-fill`; разделители строк — тонкая `mq-cell-edge`, не чернила. Сегмент — две кнопки одним блоком: общая рамка и тень, прямой чернильный шов посередине, активная половина — заливка `mq-turn`. Лист — только линия сверху, без боковой обводки и без `mq-elev-3`. Чипы и реплика Монетки в событии — без обводки, фоном `mq-turn-soft` / `mq-coin-soft`.

**Тёмная тема:** светлые чернила на тёмном поле слепят — край и тень на тон тише текста (`mq-ink-line` = `mq-board-ink-faint`).

**Токены (пробные):** `mq-ink-w` 2px, `mq-ink-off` 3px, `mq-ink-off-s` 2px (маленькая фишка), `mq-ink-line`, `mq-ink-drop`. Префикс пересекается с legacy-алиасом `mq-ink` (= `mq-board-ink`): при ★ стоит переименовать в `mq-stroke-*` или удалить алиас.

**Нельзя:** цветная тень у двух карт на одном экране; чернильная тень у того, что не нажимается; рамка внутри рамки.

**Prod:** правила — в CSS блоков (`design/system/runtime/styles/mqx/*.css` → экспорт `frontend-react/src/styles/mqx/`), токены `--mq-ink-*` — в `tokens.css`.
