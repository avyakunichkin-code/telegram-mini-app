Три обязательных состояния любого экрана с данными: загрузка (скелетон), ошибка (что случилось + «Повторить»), пусто (что здесь будет + первое действие).

**Когда:** каждый экран и лист, который ждёт API. Скелетон повторяет форму будущего контента; спиннер — только в кнопке.

**Потребитель передаёт:** `MqxStateError {title, message, retryLabel, onRetry}`; пустое — текст и действие. Офлайн: «Нет сети — ход сохранён на сервере», денежные кнопки disabled с этой причиной.

**Правила:** ошибка — последствие и выход, без кодов; shimmer останавливается при `prefers-reduced-motion`.

**Prod:** `MqxStateSkeleton`, `MqxStateError`, `MqxCapitalEmpty`, `MqxCapitalDetailEmpty`; каталог — `MqxStatesCatalogDemo`.
