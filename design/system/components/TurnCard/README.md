Карта хода — главный блок дашборда: кто играет, номер хода, колода событий, одна строка Монетки и «Завершить ход».

**Когда:** только сверху главной вкладки. Единственный фиолетовый акцент экрана.

**Порядок внутри (★ BG-1):** роль + «Твой ход» слева, номер хода справа → плашка «N события» (нажимается, открывает колоду) → Монетка одной строкой (самое срочное) → «Завершить ход».

**Потребитель передаёт:** роль и портрет, номер хода, число непрочитанных событий, самую срочную подсказку, `onEvents`, `onEndTurn`, флаг блокировки (если событие обязательно — кнопка disabled, причина в подсказке).

**Prod:** `MqxDashboardHero` (`components/mqx/layout/MqxDashboardHero.jsx`).
