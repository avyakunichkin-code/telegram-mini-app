Монета — материал денег и награды: заливка `mq-coin`, ребро `mq-coin-rim`, блик `mq-coin-face`, объём `mq-lift-coin`.

**Когда:** рядом с главной суммой («На счёте»), финиш дорожки цели, иконка зарплаты, награда в ритуале. Монета = «это деньги» — не используй её как декор или маркер списка.

**Потребитель передаёт:** размер (`th-coin--s` 20 · `--m` 28 · по умолчанию 40 · `--l` 56) и, если нужно, один символ на лице (`₽`, `+`) — цвет `mq-coin-on`.

**Нельзя:** текст цветом `mq-coin` (1.9:1); больше 5 монет в анимации начисления; монета на красном.

**Prod:** класс `bg-coin` (BG-1), в `MqxDashboardHero` и финале. Анимация начисления — `MqxJuiceGainFeedback` (`mq-dur-scene`, `mq-ease-reward`).
