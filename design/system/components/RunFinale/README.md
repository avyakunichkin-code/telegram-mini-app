Финал партии: победа — золотая клетка финиша с персонажем и кубком, итоги, «Играть дальше»; поражение — факт риска красным, 2–3 совета, «Переиграть».

**Когда:** после `win_reached` или поражения (`needs_depletion`, долг). После победы игра продолжается.

**Потребитель передаёт:** исход, персонаж, итоги (ходов, капитал, цели), для поражения — причина и ход, с которого шкала падала, советы.

**Правила:** заголовок — `display`; победа — монеты + `mq-ease-reward`, haptic `success`; поражение — без анимации тревоги, haptic `error`.

**Prod:** `MqxRunFinale`, `MqxGameOverModal`; ассеты — группа Finale.
