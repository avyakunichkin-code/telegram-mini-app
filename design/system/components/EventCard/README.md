Карта события из колоды: полоса домена, заголовок, ситуация, 2–3 варианта с последствиями.

**Когда:** 2 события за ход, оверлей поверх дашборда (`mq-scrim`), карусель свайпом и стрелками.

**Потребитель передаёт:** домен (pill), заголовок `title`, текст ситуации `body` (≤3 строки, дальше — прокрутка), варианты `{label, impacts, needsDelta}`, `onChoose`, `onClose`, флаг обязательности (`mandatory_gate`).

**Правила:** вариант — глагол + объект; последствия ДО выбора чипами (деньги → потребности); выбранный — край `mq-turn` + `mq-turn-soft`, остальные opacity .5 за `mq-dur-fast`. Риск-событие — одна встряска 240 мс. `role="dialog"`, закрытие явной кнопкой. Узловое (`th-event--key`) — край `mq-coin-rim`, когда в YAML появится поле `beat`.

**Prod:** `EventCard`, `EventChoiceButton`, `EventCarouselOverlay`, `useEventCarousel`, справка `MqxEventHelpSheet`.
