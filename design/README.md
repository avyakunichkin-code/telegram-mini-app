# Дизайн ТВОЙ ХОД · единое хранилище

- **[Актуальная система](system/index.html)** — необрутализм «Чернильный край», логотип G1 с подписью, чиби-персонажи, напарники, новая Монетка, шрифты, иконки и примеры.
- **[Правила хранения](system/ASSET_STORAGE.md)** — где менять оригиналы, как экспортировать и проверять.
- **[Карта экспортов](asset-exports.json)** — файлы для приложения, лаба, лендинга и брендбука. Это производные, не самостоятельные оригиналы.
- **[Архив классической v3](archive/classic-v3/README.md)** — прежняя система и растровые персонажи. Сохранены для истории и совместимости уже существующих импортов приложения.

Утверждённые персонажи и напарники **B «Мягкий объём»** — мастера в
`system/illustrations/soft-volume/`, [решение владельца](../design-lab/mascots/APPROVED.md).
Экспорты — `system/assets/Personas/` и `Companions/*-soft-volume.*`.
`system/illustrations/characters.js` сохраняет прежнюю SVG-серию для существующих
lab/landing-потребителей; новая Монетка — `system/illustrations/monetka.js`.

Команды из корня: `node scripts/design-assets.mjs` и `node scripts/design-assets.mjs --check`. Проверка отклоняет изменённые экспорты и незарегистрированные файлы в `frontend-react/src/assets`.

Приложение использует ink-стили и новые портреты B через `PersonaPortrait`.
`PersonaCompanion` предоставляет все четыре предмета в MQX; онбординг сохраняет
прежний поток и голос. Кубковые позы победного финала — отдельная прежняя серия.
Лендинг и каталог системы также показывают B. Лендинг сохраняет композицию A,
но рассказчики используют отдельные WebP-экспорты высотой 400 px из тех же мастеров.

Исторические lab-раунды остаются по прежним адресам как снимки процесса, а не новые источники. Сгенерированные `lab-base.css` и lab-хаб принадлежат прежним генераторам.

CSS приложения редактируется в `system/runtime/`: `runtime/index.css` → `frontend-react/src/index.css`, `runtime/styles/` → `frontend-react/src/styles/`. Это байтовые экспорты, поэтому существующие CSS-импорты приложения работают без изменения внешнего вида. Старые шрифтовые подмножества и PNG, ещё нужные приложению, экспортируются из архива.
