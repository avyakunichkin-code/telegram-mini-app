# Personas

Портреты четырёх жизней (★ persona-portraits-round), размер `md` (72px по высоте): Студент, Профессионал, Менеджер, Предприниматель. Все размеры (`pick` 56, `md` 72, `dash` 108) хранятся здесь. `frontend-react/src/assets/character-portraits/` — генерируемый экспорт.

Карта: `mq_game_*` → slug в `personaPortraits.js`. Prod: `PersonaPortrait size="pick|md|dash"`. На светлой подложке `mq-turn-soft` в кружке (`th-avatar`). `alt` — имя роли, если несёт смысл, иначе пустой.
