# Monetka

Маскот и напарница, не название продукта. WebP с альфой, без пустых полей.

- `monetka-mascot.webp` — поза по умолчанию: подсказки, пустые состояния, онбординг.
- `monetka-wink.webp` — похвала, шаг цели, срочный совет с подмигиванием.
- `monetka-sit-edge.webp` — пауза, меню, «прогресс сохранён».

В UI 22–64px. Пузырь — CSS (`th-tip`), не в картинке. Нельзя: ₽ на лице, заглушка вместо ассета. Стиль — псевдо-3D, перерисовка отложена до публичного запуска (ADR-014 п. 3). Prod: `MonetkaAvatar`, позы `frontend-react/src/assets/monetka-poses/`.
