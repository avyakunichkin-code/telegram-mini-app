Переключатель из двух фишек: «Детали | Действия», «Добавить | Мои (N)».

**Когда:** внутри карточки раздела или вкладки «Капитал» — два взаимоисключающих режима одного содержания. Больше двух — это вкладки, не сегмент.

**Потребитель передаёт:** `mode`, `onModeChange`, подписи и счётчик (`mineCount`).

**Prod:** `MqxSectionSeg`, `MqxCapitalPageModeSeg`, `MqxSubtab`.
