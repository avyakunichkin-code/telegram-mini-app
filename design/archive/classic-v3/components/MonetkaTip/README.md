Реплика Монетки: портрет + пузырь из CSS. Одна мысль, на «ты», без паники.

**Когда:** самая срочная подсказка хода (одна строка в карте хода — вариант `inline`), шаг онбординга (strip O2), пояснение в пустом состоянии. Не комментировать каждое событие.

**Потребитель передаёт:** текст (≤2 предложения), позу (`mascot`, `wink` для похвалы, `sit-edge` для пауз), тон `warn` для срочного.

**Правила:** пузырь — CSS, не в PNG; подсказка пульсирует 2 раза при появлении и замирает; `alt=""` у Монетки, если смысл в тексте.
