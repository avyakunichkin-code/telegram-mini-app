Лист снизу — каталог покупок Капитала, детали, формы сумм — и подтверждение опасного действия.

**Когда:** всё, что открывается поверх экрана и закрывается без ухода с него. Подтверждение — только для потери денег или прогресса: продать, погасить досрочно, закрыть вклад, отменить полис.

**Потребитель передаёт:** заголовок (`title`), содержимое, `onClose`; для подтверждения — текст последствия и глагол действия.

**Правила:**

- Поверхность `mq-cell-raised`, `mq-r-card` сверху, `mq-elev-3` над `mq-scrim`; вход — `mq-dur-slow` + `mq-ease-enter`, выход ×0.75.
- `role="dialog"`, `aria-modal`, видимый заголовок (Radix `DialogTitle`), крестик — кнопка ≥ `mq-tap` с `aria-label="Закрыть"`.
- Списки в листе — строки на поле листа, разделитель `mq-hair-w` `mq-cell-edge`; группу называет заголовок листа, цветная полоса в строке не нужна. Действие строки — кнопка со словом («Купить», «Снять», «Взять», «Оформить»), не голый «+».
- Подписи групп и полей — `mq-board-ink-soft`, никогда белым по светлому.
- Подтверждение: текст называет последствие («Получишь 520 000 ₽, расходы уйдут со следующего хода»); «Отмена» и опасное действие рядом, опасное — справа. **Кнопка названа действием:** «Продать», «Закрыть», «Погасить», «Отменить полис» — не «Удалить», не «ОК». Текст на красной заливке — цвет поля `mq-board` (6.7:1 в тёмной теме).

**Нельзя:** лист в листе; подтверждение для безопасного действия; «Вы уверены?» без последствия.

**Prod:** `mqx-sheet` (листы Капитала), `MqxConfirmDialog` + `useMqxConfirm` (подтверждение), `MqxRowAction` с `verb` (действие строки; подпись видна в стиле «Чернильный край», в классическом — «+»).
