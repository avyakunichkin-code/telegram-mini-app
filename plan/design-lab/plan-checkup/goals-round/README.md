## Контракт следующего среза

Сейчас `GoalRow` не имеет ID, а `target_month` обязателен. Повторный чекап
копирует данные целиком. Для реализации требуется стабильный ID цели при создании
и копировании, его сохранение при правках и явная поддержка отсутствующего срока.
Не сопоставлять старые цели по названию или позиции. Legacy без ID — нет сравнения.

Сравнение: только собственный завершённый родитель, сохранённый старый отчёт;
контекст нового завершённого отчёта замораживается, как P3-03. Прошлые цели,
суммы и сроки не пересчитываются. Новые/удалённые цели не смешиваются с существующими.
Переименование не меняет идентичность. Изменение целевой суммы показывается явно.

Темп = Δ накоплений / число месяцев между чекапами. В том же месяце — нет оценки
темпа. При неизвестном, нулевом или отрицательном темпе нет конечной даты по темпу.
При достижении суммы — «цель достигнута». Без срока нет нужного взноса, есть подсказка.
Свободный остаток семьи не считается фактическим взносом и не раздаётся нескольким
целям одновременно. Сценарная оценка не учитывает доходность или причины изменения.
