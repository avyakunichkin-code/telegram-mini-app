# Синяя палитра ТВОЙ ПЛАН · 10.11.2026

Статус: утверждено владельцем и перенесено локально в Plan. [APPROVED.md](APPROVED.md), [CANON.md](CANON.md). Владелец выбрал палитру лендинга для приложения и синие яркие акценты: «Согласен, давай внутри также использовать новую палитру с лендинга. Яркие акценты у нас должны быть синим, как на лендинге, при этом нужен дополнительный цвет чуть более темный и средний по яркости».

Основной `#073BFA` — из утверждённого лендинга. Предложение дополнительного оттенка — `#31549B`: темнее и менее насыщенный; используется в выбранной навигации, secondary-акцентах и второй линии прогноза. Глубокий `#172B52` — контрастная панель. `#EEF2FB` — светлая подложка. Положительные/предупреждающие/опасные состояния сохраняют отдельные семантические цвета, неизвестное — нейтральное.

`tokens.json` — утверждённый светлый образец для сравнения. Runtime-источник цветов — `plan/web/src/palette.css`; приложение перенесено локально, лендинг этим срезом не меняется. Это узкий цветовой раунд: структура атласа и финансовые правила не пересматриваются. Образцы содержат вымышленные данные и простую отдельную иллюстрацию прогноза, не API расчётного движка. Цель резерва 3 месяца — условие примера.

Три контрольных поверхности: ввод суммы/диапазона, ответ с двумя метриками, прогноз с двумя подписанными линиями и таблицей. Яркий синий обозначает основное действие, более спокойный — текущий раздел и вторичный акцент; цвет не служит единственным признаком состояния.

Просмотр из корня: `.venv/Scripts/python.exe -m http.server 4192 --bind 127.0.0.1 --directory design-lab`. Адрес: `http://127.0.0.1:4192/plan-checkup/palette-20261110-round/`.
