# Выбор подачи прошлого шага

1. **Короткая строка:** минимальное вмешательство в отчёт, меньше визуального акцента.
2. **Заметка на полях:** рекомендованный баланс компактности и характера журнала.
3. **Мост между шагами:** явное «прошлое / сейчас», больше пространства и контекста.

Один набор данных и один сценарий на все три варианта. Владелец явно выбрал 3 / C
«Мост между шагами», 2026-11-06. A/B — сравнение, не канон. Оценка финансового
результата не выводится из галочки.
