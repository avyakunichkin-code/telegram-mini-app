# Утверждение · B2 / C1 «Акцент»

Дата: 2026-11-07.

Решение владельца: **«Отлично, утверждаем»** после добавления пометки завершённых шагов в показанном макете.

Утверждён текущий срез:

- Компактная страница B2, отвечающая на один вопрос; подробности открываются в одной рабочей области.
- Боковая навигация на десктопе и нижняя панель на телефоне.
- Текущая показанная подача C1 «Акцент»: выделенный главный вывод, спокойные показатели, явное действие «Открыть шаг»; C2/C3 остаются сравнительными вариантами.
- Короткий текст, минимум цифр в первом слое, подробности по раскрытию.
- «✓ Выполнено» в заголовке завершённого шага, включая свёрнутое состояние. Снятие отметки с действия возвращает шаг в работу. Статус появляется после подтверждения сохранения.
- Представленные главы прогноза, устойчивости, долгов и истории, а также показанные состояния lab.

Срез ограничен существующим демонстрационным отчётом. Это утверждение дизайна, не новая финансовая политика и не одобрение деплоя. Вход, анкета и прочие ещё не показанные вопросы не утверждаются автоматически. Расчётные контракты и правила Plan сохраняются.

Перенос в `apps/plan-web` — следующий рабочий срез. В этой фиксации приложение, API и данные не менялись. Результаты самопроверки перечислены в QA.md; они не заменяют настоящее решение владельца, приведённое выше.
