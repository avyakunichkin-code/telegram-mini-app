Один шаг.
Несколько понятных действий.

Утверждён компактный B. A оставлен для сравнения на тех же вымышленных данных. Отметки — только в этой демонстрации, перевод денег не выполняется.

Отметка означает, что вы сами выполнили действие. Суммы — иллюстрация, финансовые правила не меняются. A показывает весь список; B оставляет компактный билет и раскрывает действия по запросу.

Повторное открытие восстанавливает подтверждённые отметки из памяти страницы. Перезагрузка браузера сбрасывает пример. В приложении прогресс должен сохраняться через API.
