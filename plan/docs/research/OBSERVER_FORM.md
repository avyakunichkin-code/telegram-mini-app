# Бланк наблюдения · одна сессия

Пустой шаблон. Заполненную копию хранить вне git. Не писать имя, контакты,
личные суммы, идентификаторы аккаунта или токены. Порядковый номер сессии —
только в рабочей копии, без сопоставления с человеком.

Build / метка проверенного checkout: ______. Вариант: **А**.
Экран: mobile / desktop; фактическая ширина: ____.
Сессия началась / завершилась: ____ / ____. Остановлена досрочно: да / нет.
Время — длительность с паузами; активное время отдельно не оценивать на глаз.

| Задание | До помощи: что удалось / ошибка категории | Помощь ведущего | Итоговый статус |
|---|---|---|---|
| resume · восстановление | ______ | нет / навигация / объяснение | ______ |
| conclusion · вывод и влияние диапазона | ______ | нет / навигация / объяснение | ______ |
| transfer · перевод и неизменность общих денег | ______ | нет / навигация / объяснение | ______ |
| next_step · шаг и проверка результата | ______ | нет / навигация / объяснение | ______ |
| feedback · добровольный отзыв | дан / отказ / не успели | нет / подсказка вопроса | ______ |

Допустимые итоговые статусы: independent / assisted / error / unobserved.
На задание один статус. Для conclusion оцениваются и вывод, и границы;
для transfer — различие счёта/резерва и 12 месяцев. Если часть не наблюдалась,
отметить это здесь; не объявлять всё задание independent без обеих частей.
В feedback independent означает добровольный ответ, а не положительный отзыв.
При отказе/пропуске — unobserved. Сначала фиксируется попытка, затем помощь.

Категории затруднений (можно несколько): input / resume / conclusion / range /
transfer / step / navigation / technical. Одну категорию считать не более
одного раза за сессию. Помощь не стирает исходное затруднение.

Наблюдаемый факт без личных сведений: ____________________.
Гипотеза причины, отдельно от факта: ____________________.
Сначала проверить техническую воспроизводимость на вымышленном кейсе.

## Запись для агрегатора

После сессии добавить в sessions внешнего JSON только объект ниже; заменить
все статусы фактическими. **Не добавлять шаблон заранее:** он не означает
проведённую сессию. При отсутствии наблюдения сохранить unobserved.

```json
{
  "viewport": "mobile",
  "tasks": {
    "resume": "unobserved",
    "conclusion": "unobserved",
    "transfer": "unobserved",
    "next_step": "unobserved",
    "feedback": "unobserved"
  },
  "difficulties": []
}
```

Свободный текст, время, номер и заметки в JSON не включать. Агрегатор намеренно
отклоняет дополнительные поля. Сессию не дублировать при переносе результатов.
