# P3-12 · последний отчёт офлайн · 2026-11-05

Поручение владельца: продолжить следующую задачу, пока три гибрида истории
P3-08 остаются в lab для выбора. Внедрение истории этим срезом не разрешалось.

## Реализовано

- Production-сборка создаёт service worker с allowlist HTML/JS/CSS. Оболочка
  открывается при полной перезагрузке без сети; API и внешние запросы не кэшируются.
- Локальный снимок только итогового отчёта, привязанный к пользователю и SHA-256
  текущего JWT. Исходная анкета, семья, e-mail и дополнительный токен не копируются.
  Начальная сумма для графика сохраняется отдельно, без повторного расчёта отчёта.
- Последний по completed_at отчёт сохраняет приоритет перед старым открытым;
  отметки действий того же отчёта обновляют копию. Повреждённая/старая схема,
  истёкшая или другая сессия исключают показ копии. Отказ storage не ломает онлайн.
- Существующий экран отчёта показывает месяц данных, «Офлайн · только чтение»
  и дату сохранения копии в имеющейся строке даты. Layout не менялся.
  Запись и новый чекап отключены; без копии показана явная ошибка.
- Выход, смена сессии, наблюдаемый 401 и успешное удаление аккаунта очищают
  приватный снимок. Отложенная запись не воскрешает его после выхода. Соседняя
  вкладка сбрасывает видимый отчёт. Отмена удаления сохраняет копию.
- После возврата сети проверяются сессия и серверные данные. Нет новых событий
  аналитики, API-маршрутов, зависимостей или изменений финансовых правил.

## Ограничения

Нужен хотя бы один подключённый запуск с загрузкой итогового отчёта и установкой
service worker; для SW требуется HTTPS или localhost. Наличие копии не означает
проверку удалённого аккаунта без сети: отзыв проверяется при подключении,
автономное чтение ограничено сроком токена. Статическая оболочка после выхода
остаётся, финансовый снимок удаляется. Это локальный прототип без деплоя и
реальных данных. P3-08 остаётся на стадии выбора дизайна; P2 целиком не закрыт.
