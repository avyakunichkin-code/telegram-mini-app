# P3-03 · Мост между шагами · 2026-11-06

Пользователь явно выбрал вариант 3 «Мост между шагами». Основание и canon:
[APPROVED](../../design-lab/plan-checkup/APPROVED.md).

Внедрён отдельный компонент Plan: прошлый шаг с отметками и сравнением метрики
рядом с текущим первым шагом. Доступны дополнительные прошлые шаги, открытие
старого отчёта и возврат к новому. На телефоне страницы идут последовательно.
Заголовки текущих рекомендаций берутся из API, демонстрационные суммы не переносятся.

`previous_steps` добавляется к новому отчёту; при завершении сохраняется вместе
с ним. Читается сохранённый отчёт собственного завершённого родителя, без пересчёта.
Изменение отметок родителя не переписывает завершённый дочерний отчёт.
Старые финальные отчёты не дополняются задним числом. Недоступный родитель,
неизвестная метрика и отсутствие старого списка действий представлены явно;
чужой родитель не раскрывается. Разница версий показана предупреждением.
Отметка выполнения не объявляется причиной изменения финансовой метрики.

Офлайн-копия сохраняет готовый мост; открытие другого отчёта без сети отключено.
Запоздалый ответ загрузки родителя отбрасывается после смены экрана, отчёта,
сессии или режима чтения. Это исправляет гонку, воспроизведённую независимым
reviewer; добавлена браузерная проверка ухода в профиль и перехода офлайн.
