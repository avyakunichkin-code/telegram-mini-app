# ТВОЙ ПЛАН: проверка полного пути, 2026-11-03

Локальная проверка `apps/plan-api`, `apps/plan-web` и общих зависимостей на синтетических данных. Аудит — снимок результатов, не новая спецификация. Существующие изменения других задач сохранены. Игровые приложения и общее финансовое ядро этим срезом не изменялись.

## Найдено и исправлено

- Повторяющиеся ID членов семьи принимались API; теперь ответ 422.
- Повторяющиеся ID долгов принимались API и приводили к потере одного долга в словаре стратегии погашения; теперь ответ 422.
- Удаление человека проверяло только доходы и долги, оставляя без владельца накопления, вложения, пенсию и страховку; теперь проверяются все связанные разделы черновика.
- Взрослого с доходами или долгами можно было превратить в ребёнка в обход проверки разделов; теперь изменение блокируется (409).
- Повторный чекап копировал финансовые записи последнего отчёта, но мог брать другой состав семьи; теперь копируется связанный снимок членов семьи.
- Расчёт погашения игнорировал долг с нулевым основным остатком и ненулевой просрочкой; теперь учитывает такой долг.
- Переключение разделов анкеты теряло несохранённый ввод; теперь изменённый раздел сохраняется перед переходом. Ошибка сохранения оставляет пользователя в текущем разделе.
- Создание чекапа не обновляло историю и оставляло предыдущий отчёт в состоянии; теперь история обновляется, отчёт сбрасывается.
- После 401 старый отчёт оставался в памяти и вновь открывался нажатием на логотип; данные очищаются при 401 и выходе.

Регрессии воспроизведены тестами до исправления для связей/ID, повторного чекапа, просрочки, переключения разделов и истёкшей сессии. Первые попытки E2E также выявили ошибки новых локаторов теста; локаторы исправлены без ослабления проверок.

## Проверенные пути и ограничения

Браузер: вход по тестовому коду, состав семьи, быстрый и подробный ввод, переключение разделов с сохранением и reload, демо-семья, все десять разделов, черновой и итоговый отчёты, четыре стресс-сценария, отметка шага, повторный чекап с данными, история, удаление аккаунта, истёкшая сессия. Проверены отсутствие горизонтального переполнения и разрывов длинных сумм в отчётах; happy path не пишет ошибок консоли.

API: валидация, изоляция домохозяйств, отклонение игровых токенов, согласие, TTL/попытки/лимит кода, одноразовый код, сохранность после перезапуска, неизменность итогового чекапа, идемпотентное завершение, отзыв токена и purge удаления. Анализ: диапазоны, стресс-потеря дохода, кредитное решение, приоритеты шагов, стратегии долгов и отсутствие торговых советов.

Реальные анкеты, отправка почты, production/PostgreSQL, деплой, реальные устройства и браузеры кроме Chrome не проверялись. UI layout не менялся. Это проверка текущего локального каркаса, не подтверждение готовности к работе с реальными пользователями и не гарантия отсутствия всех возможных ошибок. Полный игровой backend pytest и игровые balance-сценарии не запускались: игровая логика и общие расчёты не менялись.
