# SPL-403 — браузерный контракт Game и границы ui-kit, 2026-11-04

Следующий срез после переноса отчёта: закрыть пробел browser evidence для второго
потребителя ButtonBase и зафиксировать фактический состав пакета. Изменения
пользователя сохранены; производственные компоненты и стили этим срезом не менялись.

## Выполнено

- Добавлены `game/web/e2e/ui-kit.html`, `ui-kit.jsx` и `ui-kit.spec.js`:
  настоящий MqxButton и production CSS barrel, без подмены адаптера. Проверяются
  ref, Enter/Space, явный submit, default type=button, блокировка busy при
  disabled=false, aria-busy, восстановление доступности и точный Tab-порядок с
  пропуском disabled-кнопки. Все семь вариантов остаются доступны в обеих темах;
  disabled имеет отличающуюся непрозрачность.
- `npm run test:ui-kit` запускает отдельный Vite/Chrome стенд без game/api/auth.
  Тесты также обнаруживаются обычным игровым `test:e2e`, уже используемым в CI.
  Отдельный кэш Vite и strictPort отделяют стенд от других задач.
- `shared/packages/ui-kit/CONTRACT.md`: инвентаризация потребителей и границ, карта
  surface/text/focus/disabled и источников Game/Plan. Это документированный
  семантический контракт, не новый общий CSS namespace или перенесённая палитра.
  Единственный реализованный общий примитив сейчас — ButtonBase.

Первый базовый browser прогон прошёл 4/4. После усиления Tab-проверки новый прогон
упал 2/4: тест неверно предполагал, что нажатие кнопки «Фокус» оставляет фокус на

тест: он явно проходит submit → loading → focus → следующий доступный вариант.
Это не регрессия продукта. Повтор сначала не был исполнен: автоматическая
проверка разрешения завершилась ошибкой лимита использования. После поручения
«Продолжай» тот же запрос прошёл проверку и выполнился; финальный результат — 4/4.

## Что остаётся за границами

Это browser conformance общего примитива, не полный core-loop E2E игры и не
полный аудит контраста/скринридера. Game/Plan темы и визуальные варианты не менялись,
поэтому повторный lab approval не требовался. Field/Error/Progress не извлекались
без общего сценария, доменные компоненты остались в приложениях.

Полные guardrails этим срезом не повторялись: последний прогон во время переноса
отчёта завершился exit 1 на незатронутом `board-game/ink-refinement-round/index.html`
без подключения `./lab-base.css`. Этот исходный пробел не закрыт данным срезом.
P2 не объявляется закрытым, код P3 не начат; game/api/экономика, реальные данные,
письма и публикация не затрагивались.
