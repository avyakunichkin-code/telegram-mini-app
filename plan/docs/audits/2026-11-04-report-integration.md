# ТВОЙ ПЛАН — перенос утверждённого отчёта, 2026-11-04

Основание: владелец после просмотра исправленного lab подтвердил «Так да, всё,
утверждено», затем поручил перенос: «Да, отлично, делаем». Утверждённые исходники
и порядок — [канон](../../design-lab/plan-checkup/APPROVED.md).
Существующие изменения рабочего дерева сохранены, публикация не выполнялась.

## Что изменилось

- `Report.jsx`: четыре области → F2 → A2/S1 → остаток/точность → подробности с M1
  → остальные шаги → стресс-тесты → долги и цели. Три остальных типа вопроса,
  ипотека и обзор сохраняют свой ответ API; пояснение раскрывается через details.
- `ReportBlocks.jsx`: две конечные суммы прогноза из API; начальный запас из
  введённых счетов/подушки, без долгосрочных депозитов; M1 использует расходы и
  target_months отчёта. Нулевые расходы не создают NaN/фиктивную цель; сосуд
  ограничен 100%, фактическая сумма показана полностью.
- Первый шаг использует title/why/numbers API. Для first_cushion показывается
  результат пополнения на need, для cushion_target — результат месячного взноса,
  для других правил денежный результат не выдумывается. Отметки done/dismissed/
  suggested сохранены, повторные запросы блокируются на время сохранения.
  Rank 1 остаётся первым билетом после отметки, следующий suggested виден ниже.
- `report-blocks.css`: утверждённые формы, адаптивность и темы. Main-график заменён
  дорожками F2; стресс-графики и подробные результаты остались. API и расчётные
  правила не менялись. Lab-суммы и цель 3 месяца не перенесены в правила.
- Canon/README, spec и roadmap синхронизированы с выполненным переносом.

Успешный полный E2E: E2E_API_PORT=8042, E2E_WEB_PORT=5212, E2E_PYTHON — абсолютный
путь корневой .venv. Запуск вне sandbox разрешён для локальных сокетов Windows.
Первый полный прогон потерял серверы после шести успешных тестов и остановлен;
его connection-refused ошибки не выданы за ошибки расчётов. Адресный повтор —
2 passed. После исправления CSS выполнен полный успешный прогон выше.

Новый E2E сверяет UI с настоящим ответом API, проверяет 375/701/792/1050/1440 px,
светлую/тёмную темы, отсутствие горизонтального переполнения и обрезки ключевого
содержимого, неразрывность сумм, пояснение ответа и контраст текста предпосылок
прогноза >= 4.5. Другие тесты проверяют финализацию/отметку шага, повторный чекап,
все разделы, удаление, истёкшую сессию и финансовые границы.

На визуальном просмотре и независимом review обнаружен конфликт порядка CSS:
общая `.card` перекрывала фон F2/A2/S1. Исправлена специфичность селекторов,
добавлена проверка контраста. Свежие мобильный и планшетный скриншоты просмотрены.
Скриншоты — `plan/web/test-results/checkup-утверждённые-блоки-2f48e-ные-API-адаптивность-и-темы-{mobile-375,desktop}/report-{width}-{light,dark}.png`.
Они перезаписываются новым E2E. Полные результаты команд — в выводе этой сессии.
Unit выдаёт предупреждение WebSocket-порта Vite при параллельных SSR harness;
все восемь проверок завершились успешно, на приложение оно не указывает.

## Границы

Независимый `mqx-ui-reviewer` дал PASS по переносу после проверки исходников,
approval/canon и свежих скриншотов. Найденный им конфликт CSS устранён и повторно
проверен. Полные игровые guardrails остаются с указанной выше исходной проблемой
другого раунда; он не изменялся. Review не подменяет человеческое утверждение.

Игровой frontend, backend, fincore, API и финансовые правила этим переносом не
менялись; игровой backend pytest и balance не запускались. Это проверка
синтетических сценариев и адаптации UI, не исследование понятности с людьми
и не полный аудит доступности. P2 целиком не объявляется закрытым.
Реальные данные, почта и внешний деплой остаются за условиями ADR-017.
