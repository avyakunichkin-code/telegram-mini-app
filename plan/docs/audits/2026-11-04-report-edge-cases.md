# ТВОЙ ПЛАН — сложные случаи в браузере, 2026-11-04

Продолжение согласованного дневного среза: проверка согласованности расчёта,
объяснения и действия на синтетических данных. Предыдущие изменения сохранены.
Новый дизайн отчёта остаётся в lab; этот срез проверяет действующее приложение.

## Сценарии и результат

Добавлены четыре сценария в `plan/web/e2e/checkup.spec.js`, каждый проходит
через вход и быстрый ввод, настоящий API и отображение отчёта на 375 px и desktop.
Ответы API не подменяются. Проверяются также консоль, горизонтальное переполнение
и неразрывность денежных сумм.

| Синтетические данные | Проверяемый результат |
|---|---|
| Доход 60 тыс., расходы 80 тыс., резерв 0 | Остаток −20 тыс., бюджет красный, первый шаг stop_deficit и его текст виден в UI |
| Доход 40–140 тыс., расходы 80 тыс., резерв 100 тыс. | Базовый остаток +10 тыс., пессимистичный минус в месяце 3, предупреждение в UI, точность не refined |
| Доход 100 тыс., расходы 50 тыс., платежи 60 тыс. | Остаток −10 тыс., долговая нагрузка 60%, долги красные, первый шаг stop_deficit |
| Все четыре суммы 0 | Остаток 0, базовый прогноз нулевой, нет рекомендации direct_surplus |

Платежи быстрого ввода остаются оценочным агрегированным кредитом; эта проверка
не утверждает его параметры и не заменяет подробный разбор реальных долгов.

## Найдено и исправлено

Переключатель диапазона вложен в label. До исправления Chrome присваивал кнопке
имя всего поля вместе с текущей суммой вместо названия действия. Добавлен явный
aria-label: «примерно от–до: {поле}» / «знаю точно: {поле}». Видимый текст остаётся
частью доступного имени. Layout и финансовые правила не менялись.

Первый прогон новых сценариев выявил несовпадение локатора с реальным accessible
name. Отдельная проверка ожидаемого имени до правки — exit 1; после правки
диапазонный сценарий проходит. Финальная редакция сохраняет в aria-label видимую
формулировку; повторный прогон этого сценария на mobile и desktop — exit 0,
2 passed. Сборка после последней редакции также прошла с exit 0.

## Проверки и ограничения

Windows PowerShell, Python 3.13 из корневой .venv, Node/Vite, системный Chrome.
Из `apps/plan-web`:

- `npm.cmd run test:unit` — exit 0, 4 passed.
- `npm.cmd run build` — exit 0, bundle собран.
- `node node_modules/@playwright/test/cli.js test --reporter=list` — exit 0,
  20 passed, mobile-375 и desktop. E2E_API_PORT=8038, E2E_WEB_PORT=5208,
  E2E_PYTHON — абсолютный путь корневой .venv, отдельная временная SQLite.
- `node node_modules/@playwright/test/cli.js test --grep 'широкий диапазон дохода' --reporter=list`
  после финальной редакции aria-label — exit 0, 2 passed; порты 8039/5209.

E2E запускается с разрешённым выходом из sandbox из-за известного ограничения
локальных сокетов Windows. Первые незавершённые прогоны не считаются зелёными.
Логи и артефакты — вывод команд сессии и `plan/web/test-results/` (перезаписываются
следующим прогоном). `git diff --check` по путям среза — exit 0.

Backend не менялся: полный pytest и игровой баланс повторно не запускались.
Исследование понятности с людьми, независимый review и полный аудит доступности
не выполнялись. Реальные данные, почта, юридическое согласование и публикация
не входят в этот срез. P2 целиком не закрыт.
