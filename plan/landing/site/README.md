# ТВОЙ ПЛАН — лендинг

Информационный сайт прототипа семейного финансового чекапа.
Текущий дизайн: D «Опора и свобода», утверждён 10.11.2026; полная страница просмотрена и разрешена к публикации: «Отлично, публикуй». Статические HTML/CSS/JS без сборки.

Сайт: https://avyakunichkin-code.github.io/tvoy-plan-landing/

Размещение: GitHub Pages, ветка `main`, папка `/`.
Локальный просмотр: любой статический HTTP-сервер из корня репозитория.

Все суммы вымышленные. Персональные финансовые данные не собираются;
аккаунты, backend, платежи и банковские интеграции не подключены.
Шрифты Onest и Unbounded загружаются через Google Fonts с системным fallback.

Текущие стили — `fintech.css`, иллюстрация — `assets/foundation.webp` (121 952 байта). Синий акцент, светлый фон, финансовая конструкция с резервом и защитой. Тексты и подписи — HTML. Исторические `styles.css`, `bento-blocks.css`, `roadmap.css` сохранены, но текущей страницей не подключаются.

Источник утверждения и контрольный срез: `design-lab/plan-landing/fintech-hero-20261110/` основного проекта. Сценарии `site.js`, вымышленные данные отчёта и общий `cookie-consent.js` сохранены. Полный Chrome smoke на 320/375/390/768/1024/1440 px: без переполнения, битых ресурсов и JS-ошибок; четыре сценария, четыре вопроса, объяснение суммы, отметка/сброс шага и cookie persistence — PASS (exit 0). Полного WCAG-аудита и полевых Core Web Vitals нет.

Исходная историческая дизайн-система — ТВОЙ ПЛАН «Бенто».
