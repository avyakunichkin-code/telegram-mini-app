# Лендинг ТВОЙ ПЛАН

Единственный редактируемый источник после переноса — `site/` в этом каталоге.
Сборка: `npm.cmd run build`, результат — `dist/`. Зависимости не требуются.
Локальное превью: статический HTTP-сервер из dist. Деплой не выполнялся.

Импортирован чистый HEAD `a27f40cdeb7f2ea7eb066fdb2eb58edaa69186ec` отдельного
репозитория tvoy-plan-landing. История всех refs сохранена переносимым Git bundle:
[история](../docs/archive/source-history/README.md).
Старый checkout в sites остаётся локальным архивом и не является источником новых правок.
Сохранение исходного URL и перенос публикации — отдельное действие владельца.
