Рамки: одна на уровень

Зарплата

Канон BG-1/BG-2: клетка с краем у каждого блока, внутри — фишки с краем, внутри фишек — плашки иконок. Три уровня одного приёма.

Рамок у блоков нет — группирует отступ и заголовок. Фишка — заливка клетки и нижняя кромка, без контура. Иконки без плашек; зарплата — сама монета.

Карта хода и поле — из A. Действия хода залиты: зарплата, пока не забрана, — главная золотая кнопка на всю ширину с суммой; «В подушку», «Из подушки», «Вложить» — фиолетовая заливка. После выплаты зарплата уходит в спокойную строку «Получена».

Рамка значит «нажимается». Деньги, потребности, потоки — без рамок, прямо на поле. Контур фиолетовый у действий, золотой у зарплаты, пунктир у закрытого. Карта хода — заливка без края, внутри обведены только её кнопки.
