## Поток

Вход → Меню (старт) → «Новая игра» → **Выбор жизни** → **Знакомство с напарником** (★ 2026-11-02, [`../mascots/companions-round/`](../mascots/companions-round) B) → партия. Шага «Игра / План» нет ([ADR-013](../../docs/decisions/ADR-013-game-only-drop-plan-mode.md), GO-01). Пустой список сохранений — «Новая игра» сразу запускает партию за Студента (и тоже показывает знакомство).

## Меню (вкладка игры и стартовый экран)

1. Шапка вкладки: h1 «Меню», «Игра на паузе» (на старте вместо шапки — логотип, h1 скрыт).
2. **Карта сохранения** (`MqxSaveCard`): фиолетовая рамка с нижней тенью; портрет персонажа в круге, роль, «Ход N · на счёте X ₽», третья строка — «Цель: шаг N из M» (в партии) или название сохранения (на старте; в списке профилей нет цели). Одна главная кнопка «Продолжить игру».
3. Спокойные кнопки (`MqxBoardButton`): «Новая игра · другая жизнь», «Все сохранения · N партий».
4. Текстовая «Выйти из аккаунта».
5. «Как играть» — **нет**, пока нет экрана правил.
6. Пусто (старт, 0 сохранений): карта «Сохранений пока нет» с главной «Новая игра».
7. «Все сохранения» — шторка: строка = партия (портрет, роль, «название · ход N · итог»), «Сейчас» / «Открыть». Без бейджа режима.

## Вход / регистрация

Логотип → Монетка «в шапке» (см. ниже) → карточка формы (подписи «Почта», «Пароль», поля на поверхности доски, фокус — золотая обводка) → одна главная кнопка («Войти» / «Создать аккаунт») → спокойная кнопка перехода («Создать аккаунт · займёт минуту» / «Уже есть аккаунт · войти»). Пузыря нет.

## Выбор жизни

Шапка — Монетка с репликой «Выбери жизнь» / «У каждой свой старт и своя цель…» → радиогруппа карточек (`MqxStarterScenarioPicker`): портрет `*-pick`, роль, доход за ход (изумрудом, из строки зарплаты шаблона), стартовые условия; выбранная — фиолетовая рамка и отмеченный кружок; стрелки переключают выбор. Тап по карточке **только выбирает**. Главная кнопка называет действие: «Начать за Студента / Профессионала / Руководителя / Предпринимателя». Ниже текстовая «Назад». Название сохранения — авто («Моя игра N»), поля имени и «Быстрого старта» нет. Состояния: загрузка, ошибка сети, пусто.

## Монетка в шапке ★ 2026-11-02

Решение PO 2026-11-02 — [`../mascots/pregame-monetka-round/`](../mascots/pregame-monetka-round), **вариант B «Монетка в шапке»** (в чате: «утверждаем B, Монетка в шапке»). Меняет прежний канон «Без Монетки и пузыря»: Монетка ведёт экраны до выбора роли, напарник — первые шаги после.

- Вход, регистрация, меню на старте (есть сохранение / пусто), выбор жизни, экран загрузки: Монетка ink 56 px **без надписи на ободе**, рядом реплика — она же h1 экрана — и пояснение. Логотип остаётся (на выборе жизни логотипа нет, как и раньше).
- Лица: вход — улыбка, регистрация — радость, меню с сохранением — подмигивает, меню пусто и выбор жизни — улыбка. Жестов пальцами нет.
- Меню-вкладка внутри партии — без Монетки (это уже после выбора роли).
- Тексты — `PREGAME_VOICE` в `mqx/utils/pregameDisplay.js`; компонент — `mqx/pregame/MqxMonetkaVoice`.

## Знакомство с напарником ★ 2026-11-02

Карточка персонажа (вариант B): имя роли, строка стартовых условий, пара персонаж + напарник на мягком фиолетовом, «**<Напарник>** проведёт тебя через первые шаги.» → главная кнопка «Начать первый ход». Без логотипа и Монетки: эстафета передана напарнику. Перезагрузка на этом экране ведёт в партию (она уже создана). Prod: `screens/pre-game/CompanionIntroScreen.jsx`, `mqx/brand/MqxCompanionCard`, `mqx/brand/personaCompanions.js`.

## Таббар
