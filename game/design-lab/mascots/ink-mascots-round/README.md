# ink-mascots-round — Монетка и Квитя в «Чернильном крае»

Перерисовка маскота из псевдо-3D в необрутализм — тот пункт ADR-014 п. 3 («перерисовка перед публичным запуском»). Направление выбрано на холсте Design 2026-10-29 (в чате: Монетка — основной маскот, счётчик-«номинал» без цифр; Квитя — в виде квитанции, без рулона). Статус: ★ **APPROVED** 2026-11-02 — в чате: «Утверждаем, главное без пальцев вверх…», «Квитя — великолепен». Правки при утверждении:

- «Напоминание» — вместо большого пальца вверх (читался как средний палец) жест `hey`: поднятая открытая ладонь со штрихами «эй!», вторая рука на поясе. Жестов пальцами у Монетки нет.
- «Объясняет» и «Предупреждение» (`chin`) — рука у подбородка рисуется поверх надписи на ободе, буквы и «★» её не перекрывают.

Шаблон — `game/design/system/illustrations/monetka.js` (канон, экспорт в `pregame-monetka-round/monetka.js`); inline-копия в `index.html` этого раунда синхронизирована вручную.

**В prod** (2026-11-02): псевдо-3D Монетка заменена везде. `game/web/src/components/mqx/brand/Monetka.jsx` — шаблон целиком (`face`, `arms`, `caption`; все 7 лиц, включая `surprised` / `worried` / `victory`, которых нет в `monetka.js`); `MonetkaAvatar.jsx` — `monetka-ink-avatar.svg` для мест до 120 px: подсказка онбординга (54), событие (44, страховка 56), «Зарплата сгорит» (56), строка-подсказка на главной и в Аналитике (26). Витрина — `#/dev/mqx` → «Маскоты». PNG `monetka-mascot.*` и `monetka-poses/*` из приложения удалены.

**Квитя в prod** (2026-11-02, место подтвердил PO — «чек-Квитя по раунду»): итоги хода `MqxPeriodCloseRitual` — поле доски, заголовок «Ход №N завершён», чек `KvityaReceipt` (строчки хода из `period_highlights`, просрочка, «Итого за ход» маркером, «На счёте»), ниже Монетка с репликой (`periodCloseMonetkaLine`: просрочка → подушка выросла → ход в плюс / минус / ноль), главная кнопка «Следующий ход». Прежний ритуал ★ juice C заменён. Лицо Квити — одно (по умолчанию); `kvitya-joy` / `kvitya-think` пока не используются.

## Ситуации Монетки

| Надпись сверху | Лицо | Руки | Когда |
|----------------|------|------|-------|
| ДЕНЬ ЗАРПЛАТЫ | smile | wave | Приветствие, старт |
| НОВЫЙ ХОД | smile | wave | Начало периода |
| ЖМИ ЗАРПЛАТУ | wink | hey | Зарплата не взята |
| СОБЫТИЕ! | surprised | up | Пришла карта события |
| ИНТЕРЕСНО… | think | chin | Объяснение механики |
| ПОДУШКА РАСТЁТ | joy | up | Похвала |
| ДОЛГ РАСТЁТ | worried | chin | Предупреждение |
| ПОБЕДА | victory | up | Финал партии |

Монетка рисуется одним шаблоном в `index.html` (`monetka(face, arms, top)`) — inline SVG, чтобы надпись на ободе шла шрифтом игры (Nunito); в `<img>` SVG шрифт страницы не получает. Так же стоит устроить React-компонент: `face`, `arms`, `caption`.

Цвета персонажей зашиты в SVG и от темы не зависят; экран итогов — на токенах v3 и следует теме.
