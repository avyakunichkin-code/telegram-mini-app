# Компонентная база MQX — утверждён вариант А

Оба варианта используют одинаковые данные, формы и состояния. Меняется смысл золотой кнопки. **А (утверждён)** сохраняет акцент утверждённой Главной. **Б** переносит золотой акцент на основное действие каждого экрана. Цвет ошибки в обоих вариантах зарезервирован для опасного действия или сообщения об ошибке.

Витрина — макет на условных данных. Палитра опирается на [«Финансы как игра»](../finance-game-round/elements.html) и [дизайн-систему](../../design/system/CURRENT_STYLE.md). Имена под примерами указывают на существующие компоненты, которые нужно переиспользовать при внедрении.

| Слой | Общая точка | Экраны для выравнивания |
|---|---|---|
| Действия | MqxButton; пресет хода поверх общего примитива | Главная, Капитал, Аналитика, Меню и окна |
| Карточки и метрики | MqxCard, MqxCardHeader, MqxFinListRow, MqxProgress | Главная, Капитал, Аналитика |
| Навигация | MqxSectionSeg для выбора внутри экрана, BottomGameNav для перехода между экранами | Капитал, Аналитика и оболочка |
| Формы и окна | AuthFormField как ориентир поля; MqxCapitalSheet и MqxConfirmDialog по назначению | Капитал, вход, Меню, окна Главной |
| Состояния | MqxStateSkeleton, MqxCapitalEmpty, MqxStateError | Все экраны, которые загружают данные |

Решение и фактический статус внедрения зафиксированы в [APPROVED.md](./APPROVED.md).
