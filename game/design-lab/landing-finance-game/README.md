# Лендинг · «Финансы как игра»

[Превью всей страницы](index.html) · [1280 px](preview-1280.png) · [390 px](preview-390.png).

Композиция повторяет порядок первого концепта. Стартовая сцена со Студентом и настольной дорожкой воссоздана по концепту. В горизонтальном роадмапе сохранены этапы разработки с текущего лендинга.

Изображения витрины сняты с текущих игровых компонентов MqxDashboardHero, MqxFinancePeriodBlock и EventCard при ширине 390 px с демонстрационными данными. Интерактивный выбор использует сценарий лендинга с условными суммами.

Кандидаты для библиотеки после утверждения — стартовая иллюстрация, дорожка с вехами и блок выбора с последствиями.

## Реализация

Пользователь выбрал приложенный полноформатный макет для реализации. Источник рабочего лендинга — [landing/site/index.html](../../landing/site/index.html). В трёх панелях показаны карта хода, финансы и событие из текущих компонентов игры. Полоса показателей ниже использует демонстрационные данные. Расстановка ролей соответствует согласованному превью.
