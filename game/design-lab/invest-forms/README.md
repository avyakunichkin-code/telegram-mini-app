# Invest forms — design lab

Витрина форм **депозита** и **облигаций**: подчёркнутый ввод, ползунок 0…баланс, фиксированная ставка.

## Открыть

```bash
cd design-lab/invest-forms
npx serve .
```

## Варианты

| ID | Название | Идея |
|----|----------|------|
| **A** | Минимал | Подчёркивание + ползунок, ставка строкой справа |
| **B** | Полоса + форма | Accent + chip ставки |
| **D ★** | Компактная строка | Сумма + chip (15% / 16% годовых) — **в prod** |
| **C** | Hero-сумма | Крупные цифры, ползунок ниже, ставка под заголовком |
| **D** | Компактная строка | Сумма и ставка в одной линии, узкий ползунок |
| **E** | Плотный TMA | Минимум вертикали: сумма + ползунок + chip ставки внизу |

**Prod:** `InvestProductForm` + `InvestAmountControl` в `game/web/src/components/`.

Ставки MVP: депозит **15%**, облигации **16%** (`constants/investProducts.js`). Депозит капитализирует проценты каждый ход, облигации выплачивают купон на счёт. При неизменных ставках и без реинвестирования купонов депозит обгоняет облигации по накопленному доходу на 12-м ходу. Решение экономики — `game/docs/canon/GAME_DESIGN.md`, раздел «Инвестиции».
