# Продолжение карты хода Г

- А — События и зарплата сразу под картой. Потребности ниже, в два ряда.
- Б — Потребности сразу под картой. На широкой Главной четыре шкалы в строку, затем События и зарплата.

В обоих вариантах движение денег сведено в три колонки, цель раскрывается по нажатию. Карта Г и ассеты взяты из эталона лендинга. Данные условные, игровые действия показывают демонстрационные диалоги. Откройте index.html для сравнения.
