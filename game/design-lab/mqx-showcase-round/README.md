# Навигация по витрине MQX

[Сравнить варианты](index.html). А — справочник по типам компонентов, Б — группировка по экранам и сценариям. Оба используют одинаковые демо, в том числе семантику варианта А из компонентной базы: золото отмечает завершение хода. Выбор структуры витрины не меняет игровые экраны.

Вариант А утверждён в чате и внедрён в `#/dev/mqx`. Финансовые компоненты выделены в отдельную группу, чтобы их было проще найти.
