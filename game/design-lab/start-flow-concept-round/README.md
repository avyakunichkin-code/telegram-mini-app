# Старт «Твой ход» · вариант B

Вариант B без кубиков подключён в игре. Игровые экраны и Design Lab используют общий MqxStartFlow. В Lab откройте «Старт · Design Lab» в каталоге MQX (`#/dev/mqx/start` в локальном Vite). Данные там демонстрационные.

| Ветвь | Переходы |
|---|---|
| Новый гость | «Играть без аккаунта» → партия за Студента → знакомство с напарником → первый ход → возможность закрепить партию за аккаунтом |
| Вернувшийся гость | Восстановление гостевой сессии → «Продолжить игру» → существующая партия |
| Вход в аккаунт | Вход или регистрация → стартовое меню |
| Аккаунт без сохранений | «Новая игра» → автостарт за Студента → напарник → первый ход |
| Аккаунт с сохранениями | «Продолжить игру» → активная или первая партия. «Все сохранения» → список. «Новая игра» → выбор роли → напарник → первый ход. |

Сравниваем экран на 390 и 320 px. Данные примера: «Моя игра», Студент, ход 2, 21 000 ₽. Заголовки — Nunito, текст — Manrope. Для логотипа используем BrandLogo. В круглых кадрах оставляем волосы целиком и лицо близко к центру.
