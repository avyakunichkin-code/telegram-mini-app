# mqx-design

Только GAME. Пути к коду ниже указаны от Git root.

Пример: «новая карточка Dashboard», «сменить CTA». Не primary: опечатка, существующий токен или a11y-label без layout.
Следуй [DESIGN_WORKFLOW](../../../web/src/components/mqx/DESIGN_WORKFLOW.md). Сначала покажи картинку всей страницы. Для утверждённой картинки собери одно рабочее превью Design Lab на MQX. Варианты в Lab нужны только при отсутствии утверждённого дизайна на картинке и необходимости выбора. MQX не требует нескольких вариантов. До утверждения превью компонент доступен только в Lab и каталоге. Сравни скриншот Lab с картинкой при той же ширине. После явного утверждения превью → $frontend-implementation и canon sync. Крупный diff → mqx-ui-reviewer. Русский UI и состояния по области. Хаб генерируй из nav.manifest.json по [COMMANDS](../../../../docs/engineering/COMMANDS.md).

Перед показом открой результат сам. Для MQX-превью проверь в браузере основные действия и сравни скриншот с выбранной картинкой на той же ширине и в том же состоянии. Исправь заметные расхождения, открой результат снова и показывай только после повторной проверки. Подробности в разделе «Проверка перед показом» в DESIGN_WORKFLOW.

Общие границы и готовность: [AGENTS.md](../../../AGENTS.md). Читай только источники затронутой области.
