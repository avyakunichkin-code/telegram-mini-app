# Интерфейс «Твой ход» · MQX

[Канон экранов](../../../design/system/CURRENT_STYLE.md) связывает дизайн каждого экрана с утверждением, превью и игровой реализацией. Для новой работы используйте утверждение затронутого экрана и действующие компоненты MQX. Общие правила приложения описаны в [спецификации интерфейса](../../specs/SPEC_FRONTEND_UI.md).

- Логотип — общий `BrandLogo` с [утверждённым знаком](../../../design/system/assets/Logos/README.md).
- Для игровых разделов используйте общую навигацию и [канон меню](../../../design-lab/finance-game-round/MENU_APPROVED.md).
- Типографика — Nunito и Manrope. В интерфейсе используйте русские названия действий и обращение на «ты».
- Для нового макета покажите концепт, соберите MQX-превью, проверьте его на нужных ширинах и получите явное утверждение. При внедрении сверьте те же состояния в игре и обновите запись экрана. [Процесс MQX](../../../web/src/components/mqx/DESIGN_WORKFLOW.md)
