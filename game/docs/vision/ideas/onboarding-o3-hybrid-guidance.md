# O3 — гибридный онбординг (spine + триггеры)

## Проблема

O2 (3 периода, 8 beats) перегружает первую сессию: сухой текст, нет явного «нажми кнопку», подсветка не читается, доходы/расходы не объясняются до действий. Плейтест: ~5 мин чтения до самостоятельной игры.

## Решение

**Гибрид:**

1. **Spine (curriculum)** — жёсткий минимум первых ходов:
   - **Период 1:** 5 шагов (месяц → доходы/расходы → зарплата → подушка → закрытие).
   - **Период 2:** 1 шаг («новый месяц», зарплата снова, не забыть закрыть).
2. **Триггеры** — после spine, по контексту экрана или событию:
   - события, «Капитал» → Действия / Детали, потребности, прощание.
3. **Тон:** голос **Монетки** ([`CHARACTER_MONETKA.md`](../../reference/CHARACTER_MONETKA.md)), на каждом action-шаге явный CTA «**Нажми …**».

## Не делаем в O3

- Жильё в burn студента (tech debt).
- Частота событий.
- Рекомендуемые суммы вложений (idea).
- «Книжка ?» в модалке событий (отдельный эпик Event UX help).

## Контракт «текущий месяц»

Эффекты открытого периода (события, строки burn) участвуют в **закрытии этого же** `period_index`. См. [ADR-011](../../decisions/ADR-011-period-effects-at-close.md).

## Успех

- Q1/Q2 PA-T2: понятен цикл TB1 без «томика».
- Первый месяц ≤ ~3 мин guided steps; остальное — по мере захода в экраны.
- Нет регрессии P0: «Вложить» → Капитал / **Действия**.
