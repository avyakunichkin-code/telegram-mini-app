# Домашний сервер GAME

Домашний сервер предназначен для тестового стенда GAME с отдельными тестовыми данными. Игра ещё не развёрнута.

## Подключение

Подключайся по SSH из домашней сети с пользовательским ключом. Фактические имя пользователя, адрес и параметры машины хранятся в локальном файле `docs/ops/HOME_SERVER.local.md`, который исключён из Git. На другом компьютере получи эти параметры у владельца сервера.

```powershell
ssh <пользователь>@<адрес>
```

При смене адреса проверь список клиентов DHCP на роутере. При первом входе сверь отпечаток ключа хоста с отпечатком на консоли сервера.

## Стенд игры

Первый запуск обсуждаем отдельно. Рассматриваем Docker Compose для веб-сборки, FastAPI и отдельной PostgreSQL. Перед запуском выбираем срез исходников и проверяем миграции, `/api/health`, игровой цикл и сохранение после перезапуска. Первый срез использует текущие возможности игры и тестовые данные.
