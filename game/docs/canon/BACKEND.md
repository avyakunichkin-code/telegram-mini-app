# GAME · Источник утверждённых backend-решений

Этот файл — единственная точка актуальных решений слоя backend GAME. Запись
называет решение и ведёт к его основанию и проверяемому контракту; детали API,
миграций и домена остаются в соответствующих источниках. Порядок разрешения
расхождений — [ADR-018](../decisions/ADR-018-layer-decision-sources.md).

| Область | Утверждённое решение | Основание / проверяемый источник |
|---|---|---|
| Границы API и домена | Роутеры вызывают сценарии services, игровая логика принадлежит доменным пакетам GAME. | [Архитектура GAME](../../ARCHITECTURE.md), [ADR-007](../decisions/ADR-007-backend-domain-packages.md) |
| Общие расчёты | Чистые финансовые расчёты — в fincore; GAME преобразует свои модели через адаптеры. | [ADR-016](../../../docs/decisions/ADR-016-two-products-shared-fincore.md), [архитектура GAME](../../ARCHITECTURE.md) |
| Данные и миграции | Данные продуктов раздельны; baseline SQL содержит только DDL. | [Правила GAME](../../AGENTS.md), [миграции API](../../api/migrations/README.md) |
| Каталог событий | Содержимое событий ведётся в YAML-каталоге GAME. | [ADR-008](../decisions/ADR-008-events-catalog-single-source.md), [каталог](../../data/events/mvp11/) |
| Модель активов и долгов | Целевой кредит связан с активом; при продаже связанный долг погашается из выручки по правилам контракта. | [ADR-010](../decisions/ADR-010-liability-asset-insurance-graph.md), [спецификация графа](../specs/features/SPEC_debt-liability-capital-graph.md) |
| API игровой прогрессии | Правила победы и разблокировки принадлежат геймдизайну; backend исполняет и проверяет их на сервере. | [Канон геймдизайна](GAME_DESIGN.md), [ADR-004](../decisions/ADR-004-mechanics-unlock-victory-chain.md) |

Другие backend-решения добавляются сюда при подтверждении или проверенной
миграции существующих ADR. Отсутствие строки не отменяет действующий контракт:
проверь основание и зафиксируй пробел, не угадывая решение.


## Правила рекомендаций AN1

Утверждено пользователем 18.11.2026 в интервью. Backend — единый источник
правил, выбора и приоритета рекомендаций аналитики. Frontend отображает результат.
Продуктовые правила — [канон геймдизайна](GAME_DESIGN.md#аналитика-an1).
Контракт API и точные условия правил уточняются в [spec](../specs/SPEC_ANALYTICS.md#34-одна-приоритетная-рекомендация).
Реализация серверных правил остаётся открытой задачей AN1-012.
