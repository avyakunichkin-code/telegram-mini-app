# Дизайн ТВОЙ ХОД · единое хранилище

- **[Актуальная система](system/index.html)** — необрутализм «Чернильный край», логотип G1 с подписью, чиби-персонажи, напарники, новая Монетка, шрифты, иконки и примеры.
- **[Правила хранения](system/ASSET_STORAGE.md)** — где менять оригиналы, как экспортировать и проверять.
- **[Карта экспортов](asset-exports.json)** — файлы для приложения, лаба, лендинга и брендбука. Это производные, не самостоятельные оригиналы.
- **[Архив классической v3](archive/classic-v3/README.md)** — прежняя система и растровые персонажи. Сохранены для истории и совместимости уже существующих импортов приложения.

Источник персонажей — `system/illustrations/characters.js`, новой Монетки — `system/illustrations/monetka.js`. SVG в `system/assets/Characters/`, `Companions/`, `Monetka/` генерируются из этих источников; не редактировать их отдельно.

Команды из корня: `node scripts/design-assets.mjs` и `node scripts/design-assets.mjs --check`. Проверка отклоняет изменённые экспорты и незарегистрированные файлы в `game/web/src/assets`.

Лендинг и игра используют утверждённые портреты v3 из [Characters/landing-v3](system/assets/Characters/landing-v3/). Прежние иллюстрации победы с кубком и некоторые шрифты по-прежнему экспортируются из архива.

Актуальность исходников и перенос закрытых lab-раундов регулирует
[правило актуальности](../docs/README.md#актуальность-и-архив).
Сгенерированные `lab-base.css` и lab-хаб обновляются через генераторы.

CSS приложения редактируется в `system/runtime/`: `runtime/index.css` → `game/web/src/index.css`, `runtime/styles/` → `game/web/src/styles/`. Это байтовые экспорты, поэтому существующие CSS-импорты приложения работают без изменения внешнего вида. Старые шрифтовые подмножества и PNG, ещё нужные приложению, экспортируются из архива.
