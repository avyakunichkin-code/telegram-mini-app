Деньги хода: крупно «На счёте» с монетой и плитки 2×2 — подушка, зарплата за ход, расходы за ход.

**Когда:** на главной под потребностями; в Капитале — потоки «Доходы / Расходы» с итогом.

**Потребитель передаёт:** суммы (число, форматирует компонент: без копеек, U+00A0 перед ₽), подписи. Расход — нейтральный со знаком «−», не красный.

**Prod:** `MqxStatMini`, `MqxFinancePeriodBlock`, `MoneyText` (`decimals={0}` в игре).
