Четыре фишки действий хода: «Зарплата», «Пополнить», «Снять», «Вложить».

**Когда:** только на главной, под деньгами. Золотая (`hot`) — пока зарплата не забрана в этом ходе. Закрытая (`locked`) — механика ещё не открыта целью.

**Потребитель передаёт:** обработчики `onSalary`, `onContribute`, `onWithdraw`, `onInvest`; флаги `salaryHot`, `salaryDisabled`, `busy`.

**Правила:** подпись под иконкой обязательна; хит-зона ≥ 44×44; после выплаты — juice монеты и haptic `success`.

**Prod:** `MqxPeriodActions` (`components/mqx/layout/MqxPeriodActions.jsx`). Подписи «Пополнить / Снять» — открытый вопрос BG-1 (непонятно, куда).
