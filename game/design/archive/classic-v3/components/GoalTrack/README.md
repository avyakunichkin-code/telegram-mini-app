Дорожка к цели: шаги цепочки победы как точки, финиш — золотая клетка с монетой. Свёрнута — «Цель, шаг N из M» + точки; раскрыта — список шагов.

**Когда:** на главной под деньгами; в финале и ритуале — шаг, который сдвинулся. Путь = шаги `victory_config_json`, не счётчик ходов.

**Потребитель передаёт:** шаги `{title, status: done|now|todo}`, финиш (`min_period_index_for_victory`, если закрыт), `expanded`.

**Правила:** без процентов; текущий шаг — одна фиолетовая точка с кольцом; заполнение — `mq-dur-slow`, шаг цели — монета + `mq-ease-reward` + haptic `success`.

**Prod:** `MqxGoalDash`, `VictoryGoalItem` (G1 ★).
