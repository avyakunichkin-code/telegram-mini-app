Чипы последствий и дельт: деньги и потребности, всегда знак + стрелка + цвет.

**Когда:** под вариантом события, в ритуале конца хода, рядом с суммой после действия.

**Тоны:** нейтральный — обычный расход/платёж; `gain` — плюс; `risk` — потеря от риска, долг, просрочка; `coin` — награда; `warn` — «сгорит».

**Потребитель передаёт:** `impacts` (деньги) и `needsDelta` (потребности); текст собирает компонент: `−` U+2212, тысячи через U+00A0, без копеек; для скринридера — `aria-label` словами.

**Prod:** `EventChoiceImpacts`, `NeedsDeltaChips`, `eventImpactChips.js`.
