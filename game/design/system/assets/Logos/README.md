# Утверждённый знак «Финансы как игра»

Золотое название на сливовой основе и подпись «Финансы как игра» на золотой ленте. Сохраняйте пропорции, используйте знак целиком и проверяйте читаемость подписи в фактическом размере. Для favicon и маленького аватара используйте монограмму ТХ.

| Назначение | Файл |
|---|---|
| Мастер для новых композиций | [Прозрачный PNG 1536 × 1024](finance-game/logo-master.png) |
| Интерфейс шириной 120 px | [WebP 120 px](finance-game/logo-120.webp), [240 px для 2×](finance-game/logo-240.webp) |
| Крупные веб-блоки | [WebP 480 px](finance-game/logo-480.webp), [960 px](finance-game/logo-960.webp) |
| Favicon и маленький аватар | [ICO 16/32/48 px](finance-game/favicon.ico), [PNG 128 × 128](finance-game/avatar-tx-128.png) |
| Соцсети и квадратные превью | [PNG 512 × 512](finance-game/logo-social-512.png) |
| Горизонтальные обложки | [PNG 1200 × 400](finance-game/logo-banner-1200x400.png) |

Веб, лендинг и Design Lab получают копии через [реестр экспортов](../../../asset-exports.json). PNG для PWA и Apple Touch Icon лендинга пересобираются из монограммы [генератором иконок](../../../../web/scripts/generate-brand-icons.py). Прежний знак G1/G2 хранится в [архиве](../../../archive/legacy-logo-sources/). Веб-приложение использует новый знак во всех конфигурациях BrandLogo.

[Горизонтальный знак](finance-game/logo-horizontal.png) — утверждённый вариант для шапки лендинга.
