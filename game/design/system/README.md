# ТВОЙ ХОД · актуальная дизайн-система

Актуальное визуальное направление игры — «Финансы как игра». Состав решений и статус их восстановления в текущей ветке описаны в [дизайне приложения](CURRENT_STYLE.md). Для медиа используются [портреты ролей из старта B](CURRENT_STYLE.md#портреты-ролей-для-медиа). Прежняя система находится в [архиве](../archive/classic-v3/README.md).

## Входы

- [Визуальный каталог](index.html): утверждённый знак, актуальные примеры экранов, портреты и элементы.
- [Где хранить и редактировать](ASSET_STORAGE.md), [карта экспортов](../asset-exports.json), [общая структура](../README.md).
- [Актуальное направление и канон экранов](CURRENT_STYLE.md).
- [Токены](tokens.json), [рецепты](recipes.md).

## Источники

`runtime/` — CSS приложения; `tokens.json` — целевые токены v3 для примеров. Они не подменяют фактические runtime-значения до соответствующего переноса.

`illustrations/characters.js` — Студент/Студбилет, Профессионал/Зарплатная карта, Руководитель/Портфель, Предприниматель/Смартфон. `illustrations/monetka.js` — новая Монетка. `assets/` — портреты, знак «Финансы как игра», иконки и совместимые экспорты; `fonts/` — Nunito и Manrope.

Обновление: `node scripts/design-assets.mjs` из корня репозитория. `--check` проверяет совпадение без записи. Производные файлы у потребителей не редактируются отдельно.

## Подача

Для новых макетов используем действующие компоненты MQX и [канон стиля](CURRENT_STYLE.md).

Голос — «ты», главное действие — «Завершить ход». Новый layout проходит design-lab и явное утверждение человека. Выбранный набор графики не означает автоматического внедрения ещё не перенесённых экранов и голосов онбординга.
