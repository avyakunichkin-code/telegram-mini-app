Текущая подача — необрутализм «Чернильный край» (ink). Актуальные персонажи — чиби и их напарники. Прежняя система и растровые маскоты находятся в [архиве](../archive/classic-v3/README.md).

## Источники

`runtime/` — CSS приложения; `tokens.json` — целевые токены v3 для примеров. Они не подменяют фактические runtime-значения до соответствующего переноса.

`illustrations/characters.js` — Студент/Студбилет, Профессионал/Зарплатная карта, Руководитель/Портфель, Предприниматель/Смартфон. `illustrations/monetka.js` — новая Монетка. `assets/` — SVG-экспорты, G1/G2, иконки и анимация; `fonts/` — Nunito и Manrope.

Обновление: `node scripts/design-assets.mjs` из корня репозитория. `--check` проверяет совпадение без записи. Производные файлы у потребителей не редактируются отдельно.

## Подача

Нажимаемая фишка — чернильный край и жёсткая тень, при нажатии вдавливается. Главная карта — одна рамка и цветная тень. Статичные плитки — край без тени. Внутри карты нет вложенных рамок. Цвета сохраняют роли: фиолетовый — действие, золото — деньги, изумруд — рост, красный — риск. В тёмной теме чернила приглушены.

Голос — «ты», главное действие — «Завершить ход». Новый layout проходит design-lab и явное утверждение человека. Выбранный набор графики не означает автоматического внедрения ещё не перенесённых экранов и голосов онбординга.
