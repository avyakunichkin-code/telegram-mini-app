Клетка поля — фишка хода и шаг пути: состояния `done`, `now`, `goal`, `locked` на базе `mq-cell` + `mq-cell-edge`.

**Когда:** номер хода в шапке вкладки (`now`), клетки дорожки, финишная клетка (`goal`), закрытая механика (`locked`).

**Потребитель передаёт:** содержимое (номер хода, монета) и состояние. Номер — `cell-value` (Nunito 800, 18).

**Правила:** текущая клетка — одна на экран. Пройденная — без объёма (`done` не нажимается). Закрытая — пунктир, не прятать.

**Prod:** `turn-token` / `MqxPeriodChip` (шапка), `bg-cell` (BG-1).
