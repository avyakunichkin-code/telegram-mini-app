# MenuPage

[Утверждённая композиция и игровой снимок](../../../../design-lab/finance-game-round/MENU_APPROVED.md) · [Живое превью](../../../../design-lab/finance-game-round/menu-preview.html).

Компонент `MqxMenuPage` принимает описание партии, подсказку о числе сохранений и обработчики действий. Он собирает шапку с `BrandLogo`, карту партии с `MoneyText`, золотую кнопку продолжения, финансовые плитки и текстовую кнопку выхода. Состояние партии и обработчики поставляет игровой экран. Ассеты логотипа, кампуса и плиток публикуются через реестр экспортов.

Исходные стили: [menu.css](../../runtime/styles/mqx/menu.css). Общая нижняя навигация описана в [TabBar](../TabBar/README.md).
