# TabBar

Четыре постоянные вкладки в одном порядке: Главная, Капитал, Аналитика и Меню. Источник иконок — [общий лист Dashboard](../../assets/Dashboard/goal-nav-icons.png). Иконка декоративная, название вкладки доступно как текст. Активная вкладка задаётся через `aria-selected` и `aria-current`.

`BottomGameNav` использует один набор иконок на всех вкладках. Цвета поверхности и выделение активного пункта задаёт экран: на Меню тёмно-сливовая поверхность и золотая активная плитка. За верхними скруглениями виден фон страницы. Таббар находится в потоке оболочки и учитывает safe area.

[Канон и снимок](../../../../design-lab/finance-game-round/MENU_APPROVED.md). Источники стилей: [shell.css](../../runtime/styles/shell.css) и [menu.css](../../runtime/styles/mqx/menu.css).
