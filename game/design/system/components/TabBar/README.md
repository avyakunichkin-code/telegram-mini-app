Таббар из четырёх вкладок: Ход, Капитал, Аналитика, Меню. Светлая поверхность в обеих темах, активная вкладка — фиолетовая фишка.

**Когда:** на всех игровых экранах, кроме модалок и онбординг-диалогов. Высота `mq-tabbar-h` + safe-area.

**Потребитель передаёт:** активную вкладку (`aria-current="page"`), `onNavigate`.

**Правила:** иконка + подпись всегда; неактивная — `mq-board-ink-faint`; переключение — cross-fade `mq-dur-base`.

**Prod:** `.bottom-nav`, `--tma-tabbar-height: 64px`.
