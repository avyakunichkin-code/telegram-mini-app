**Когда:** на главной; в ритуале — дельта чипами (ImpactChips). Шкала — состояние, не кнопка.

**Потребитель передаёт:** `{label, value 0–100}` × 4. Зона: ≥50 — норма (`mq-gain`), 25–49 — низко (`mq-warn`), <25 — критично (`mq-risk`, число красным + слово «критично» в подписи для скринридера).

**Prod:** `MqxNeedsDash`, `MqxMetricBars`; справка — `MqxNeedsHelpSheet`.
